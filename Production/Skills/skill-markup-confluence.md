# Confluence Wiki Markup

## Назначение

Справочник синтаксиса Confluence Wiki Markup. Применяется при создании и редактировании документов в Confluence с использованием текстовой разметки.

---

## Самопроверка при подключении

При подключении вывести:

**Confluence Wiki Markup подключён**
Доступные элементы разметки:
- Заголовки, форматирование текста, списки
- Таблицы, ссылки, изображения
- Блоки кода, панели, макросы

---

## Краткий справочник синтаксиса

### Заголовки

| Синтаксис | Результат |
|-----------|-----------|
| `h1. Заголовок` | Заголовок 1 уровня |
| `h2. Заголовок` | Заголовок 2 уровня |
| `h3. Заголовок` | Заголовок 3 уровня |
| `h4. Заголовок` | Заголовок 4 уровня |
| `h5. Заголовок` | Заголовок 5 уровня |
| `h6. Заголовок` | Заголовок 6 уровня |

### Форматирование текста

| Синтаксис | Результат |
|-----------|-----------|
| `*жирный*` | **жирный** |
| `_курсив_` | *курсив* |
| `-зачёркнутый-` | ~~зачёркнутый~~ |
| `+подчёркнутый+` | подчёркнутый |
| `{{моноширинный}}` | `моноширинный` |
| `^верхний индекс^` | верхний индекс |
| `~нижний индекс~` | нижний индекс |
| `??цитата??` | цитата (с указанием источника) |

### Списки

**Маркированный список:**
```
* Пункт 1
* Пункт 2
** Вложенный пункт
** Ещё вложенный
* Пункт 3
```

**Нумерованный список:**
```
# Первый
# Второй
## Вложенный 2.1
## Вложенный 2.2
# Третий
```

**Смешанный список:**
```
# Нумерованный
#* Маркированный вложенный
#* Ещё один
# Продолжение нумерации
```

### Ссылки

| Синтаксис | Описание |
|-----------|----------|
| `[текст ссылки]` | Ссылка на страницу Confluence |
| `[текст\|Название страницы]` | Ссылка на страницу с текстом |
| `[текст\|SPACE:Страница]` | Ссылка на страницу в другом пространстве |
| `[текст\|https://example.com]` | Внешняя ссылка |
| `[mailto:email@example.com]` | Ссылка на email |
| `[#якорь]` | Ссылка на якорь на текущей странице |
| `[текст\|Страница#якорь]` | Ссылка на якорь на другой странице |

### Изображения

| Синтаксис | Описание |
|-----------|----------|
| `!image.png!` | Вставка изображения |
| `!image.png\|width=300!` | С указанием ширины |
| `!image.png\|thumbnail!` | Как миниатюра |
| `!image.png\|align=center!` | С выравниванием |
| `!https://example.com/img.png!` | Внешнее изображение |

**Параметры изображений:**
- `width=X` — ширина в пикселях
- `height=X` — высота в пикселях
- `align=left|center|right` — выравнивание
- `thumbnail` — показать как миниатюру
- `border=1` — добавить рамку

### Таблицы

**Базовый синтаксис:**
```
||Заголовок 1||Заголовок 2||Заголовок 3||
|Ячейка 1|Ячейка 2|Ячейка 3|
|Ячейка 4|Ячейка 5|Ячейка 6|
```

**С форматированием:**
```
||Колонка A||Колонка B||
|*жирный текст*|_курсив_|
|{{код}}|[ссылка|https://example.com]|
```

### Цитаты

**Блочная цитата:**
```
bq. Это цитата. Она выделяется отступом и особым стилем.
```

**Многострочная цитата:**
```
{quote}
Первая строка цитаты.
Вторая строка цитаты.
Третья строка цитаты.
{quote}
```

### Блоки кода

**Inline код:**
```
Используйте {{console.log()}} для отладки.
```

**Блок кода без подсветки:**
```
{noformat}
Текст без форматирования.
Сохраняются пробелы и переносы.
{noformat}
```

**Блок кода с подсветкой синтаксиса:**
```
{code:language=javascript|title=Пример|linenumbers=true}
function hello() {
  console.log("Hello, World!");
}
{code}
```

**Параметры {code}:**
- `language` — язык: javascript, python, java, sql, xml, json, bash, и др.
- `title` — заголовок блока
- `linenumbers=true|false` — нумерация строк
- `collapse=true` — свёрнутый по умолчанию

### Панели

**Информационная панель:**
```
{info:title=Заголовок}
Информационное сообщение.
{info}
```

**Панель заметки:**
```
{note:title=Обратите внимание}
Важная заметка для читателя.
{note}
```

**Панель предупреждения:**
```
{warning:title=Внимание}
Предупреждение о возможных проблемах.
{warning}
```

**Панель совета:**
```
{tip:title=Совет}
Полезный совет для пользователя.
{tip}
```

**Универсальная панель:**
```
{panel:title=Заголовок|borderStyle=solid|borderColor=#ccc|bgColor=#f0f0f0}
Содержимое панели с настраиваемым стилем.
{panel}
```

**Параметры {panel}:**
- `title` — заголовок
- `borderStyle` — стиль рамки: solid, dashed
- `borderColor` — цвет рамки
- `bgColor` — цвет фона
- `titleBGColor` — цвет фона заголовка

### Макросы

**Оглавление:**
```
{toc:minLevel=2|maxLevel=4}
```

Параметры:
- `minLevel` — минимальный уровень заголовков
- `maxLevel` — максимальный уровень заголовков
- `type=list|flat` — тип отображения

**Раскрывающийся блок:**
```
{expand:title=Нажмите, чтобы развернуть}
Скрытое содержимое, которое появится при клике.
{expand}
```

**Якорь:**
```
{anchor:имя-якоря}
```

Ссылка на якорь: `[Перейти к разделу|#имя-якоря]`

**Разделитель:**
```
----
```

### Специальные символы

| Синтаксис | Результат |
|-----------|-----------|
| `\\` | Принудительный перенос строки |
| `---` | Длинное тире (—) |
| `--` | Короткое тире (–) |
| `(c)` | Знак копирайта (©) |
| `(r)` | Знак зарегистрированной марки (®) |
| `(tm)` | Знак торговой марки (™) |
| `\*текст\*` | Экранирование (отменяет форматирование) |

| Синтаксис | Описание |

| `:)` | Улыбка |
| `:(` | Грусть |

## Правила

- ЕСЛИ нужно экранировать спецсимвол -> используй обратный слеш: `\*`, `\{`, `\[`
- ЕСЛИ нужен перенос строки внутри ячейки таблицы -> используй `\\`
- ВСЕГДА закрывай макросы: `{code}...{code}`, `{panel}...{panel}`
- ВСЕГДА используй двойные вертикальные черты `||` для заголовков таблиц
- НИКОГДА не оставляй незакрытые макросы — это сломает страницу

## Формат выдачи

При запросе на форматирование:
1. Предоставь готовый код разметки
2. При необходимости добавь краткое пояснение синтаксиса

## Примеры

### Пример 1: Документация с оглавлением и разделами

**Вход:** Создать структуру документа с оглавлением, разделами и примером кода.

**Выход:**
```
{toc:minLevel=2|maxLevel=3}

h2. Введение

Это документация по API сервиса.

h2. Установка

{code:language=bash}
npm install @company/api-client
{code}

h2. Использование

h3. Инициализация

{code:language=javascript}
import { ApiClient } from '@company/api-client';
const client = new ApiClient({ apiKey: 'your-key' });
{code}

h3. Методы

||Метод||Описание||Параметры||
|getUsers()|Получить список пользователей|limit, offset|
|getUser(id)|Получить пользователя по ID|id|

{note}
API-ключ необходимо хранить в переменных окружения.
{note}
```

### Пример 2: Таблица с форматированием и ссылками

**Вход:** Таблица со статусами задач, включая ссылки и форматирование.

**Выход:**
```
||Задача||Статус||Ответственный||
|[API-123\|https://jira.example.com/API-123]|*В работе*|@ivanov|
|[API-124\|https://jira.example.com/API-124]|_На ревью_|@petrov|
|[API-125\|https://jira.example.com/API-125]|-Отменена-|@sidorov|
```

### Пример 3: Информационные панели

**Вход:** Добавить предупреждение и совет.

**Выход:**
```
{warning:title=Важно}
Перед обновлением *обязательно* сделайте бэкап базы данных.
{warning}

{tip:title=Совет}
Используйте {{--dry-run}} для тестового запуска без изменений.
{tip}
```
