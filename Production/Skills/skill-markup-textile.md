# Textile Markup

## Назначение

Справочник синтаксиса Textile — легковесного языка разметки для форматирования текста в HTML. Применяется при создании контента для блогов, CMS и систем документации, поддерживающих Textile.

---

## Самопроверка при подключении

При подключении вывести:

**Textile Markup подключён**
Доступные элементы разметки:
- Заголовки, параграфы, форматирование текста
- Списки, таблицы, ссылки, изображения
- Блоки кода, цитаты, специальные символы

## Краткий справочник синтаксиса

### Заголовки

| Синтаксис | Результат |
|-----------|-----------|
| `h1. Заголовок` | Заголовок 1 уровня |
| `h2. Заголовок` | Заголовок 2 уровня |
| `h3. Заголовок` | Заголовок 3 уровня |
| `h4. Заголовок` | Заголовок 4 уровня |
| `h5. Заголовок` | Заголовок 5 уровня |
| `h6. Заголовок` | Заголовок 6 уровня |

### Параграфы и блоки

| Синтаксис | Описание |
|-----------|----------|
| `p. Текст` | Параграф (по умолчанию, можно опустить) |
| `bq. Текст` | Блочная цитата |
| `bc. Код` | Блок кода |
| `pre. Текст` | Преформатированный текст |
| `notextile. Текст` | Без обработки Textile |
| `###. Комментарий` | Комментарий (не выводится) |

**Расширенные блоки** (с пустыми строками внутри):
```
bc.. Первая строка кода

Вторая строка кода

p. Обычный параграф завершает расширенный блок
```

### Форматирование текста

| Синтаксис | Результат | HTML-тег |
|-----------|-----------|----------|
| `*жирный*` | **жирный** | `<strong>` |
| `**жирный**` | **жирный** | `<b>` |
| `_курсив_` | *курсив* | `<em>` |
| `__курсив__` | *курсив* | `<i>` |
| `-зачёркнутый-` | ~~зачёркнутый~~ | `<del>` |
| `+вставленный+` | вставленный | `<ins>` |
| `^верхний индекс^` | верхний индекс | `<sup>` |
| `~нижний индекс~` | нижний индекс | `<sub>` |
| `@код@` | `код` | `<code>` |
| `??цитата??` | цитата | `<cite>` |
| `%span%` | span | `<span>` |

**Комбинирование:**
```
_**-зачёркнутый жирный курсив-**_
```

**Отмена обработки:**
```
==*этот текст не станет жирным*==
```

### Списки

**Маркированный список:**
```
* Пункт 1
* Пункт 2
** Вложенный пункт
** Ещё вложенный
* Пункт 3
```

**Нумерованный список:**
```
# Первый
# Второй
## Вложенный 2.1
## Вложенный 2.2
# Третий
```

**Список определений:**
```
- Термин := Определение термина
- Другой термин := Его определение
```

### Ссылки

| Синтаксис | Описание |
|-----------|----------|
| `"текст":https://example.com` | Внешняя ссылка |
| `"текст":/path/to/page` | Локальная ссылка |
| `"текст(подсказка)":https://example.com` | Ссылка с title |
| `"$":https://example.com` | URL как текст ссылки |
| `"(class)текст":https://example.com` | Ссылка с CSS-классом |

**Алиасы ссылок:**
```
Это "ссылка на сайт":site и "ещё одна":site на тот же сайт.

[site]https://example.com/
```

### Изображения

| Синтаксис | Описание |
|-----------|----------|
| `!image.png!` | Вставка изображения |
| `!image.png(alt текст)!` | С alt и title |
| `!https://example.com/img.png!` | Внешнее изображение |
| `!image.png!:https://example.com` | Изображение-ссылка |

**Выравнивание изображений:**
| Синтаксис | Описание |
|-----------|----------|
| `!<image.png!` | По левому краю |
| `!>image.png!` | По правому краю |
| `!=image.png!` | По центру |

**Стили изображений:**
```
!{border:1px solid #333; padding:5px;}image.png!
!(classname)image.png!
```

### Таблицы

**Базовый синтаксис:**
```
| Ячейка 1 | Ячейка 2 | Ячейка 3 |
| Ячейка 4 | Ячейка 5 | Ячейка 6 |
```

**Заголовки таблицы:**
```
|_. Заголовок 1 |_. Заголовок 2 |_. Заголовок 3 |
| Ячейка 1 | Ячейка 2 | Ячейка 3 |
```

**С thead и tbody (HTML5):**
```
|^.
|_. Заголовок 1 |_. Заголовок 2 |
|-.
| Ячейка 1 | Ячейка 2 |
| Ячейка 3 | Ячейка 4 |
```

**С tfoot:**
```
|~.
|\2=. Футер на две колонки |
|-.
| Ячейка 1 | Ячейка 2 |
```

**Объединение ячеек:**
| Синтаксис | Описание |
|-----------|----------|
| `|\2. текст` | Объединение 2 колонок (colspan) |
| `|/3. текст` | Объединение 3 строк (rowspan) |

**Выравнивание в ячейках:**
| Синтаксис | Описание |
|-----------|----------|
| `|^. текст` | По верхнему краю |
| `|-. текст` | По центру (вертикально) |
| `|~. текст` | По нижнему краю |
| `|=. текст` | По центру (горизонтально) |
| `|>. текст` | По правому краю |
| `|<. текст` | По левому краю |

**Атрибуты таблицы:**
```
table(tableclass#tableid).
| Ячейка 1 | Ячейка 2 |
```

**Атрибуты строки:**
```
(rowclass). | Ячейка 1 | Ячейка 2 |
```

**Атрибуты ячейки:**
```
|{color:red}. стилизованная | обычная |
```

**Подпись таблицы:**
```
|=. Подпись таблицы
|_. Заголовок 1 |_. Заголовок 2 |
| Ячейка 1 | Ячейка 2 |
```

### Модификаторы форматирования

Применяются к блокам и inline-элементам:

| Синтаксис | Описание |
|-----------|----------|
| `(class)` | CSS-класс |
| `(#id)` | CSS id |
| `(class#id)` | Класс и id |
| `{style}` | Inline CSS-стили |
| `[lang]` | Атрибут языка |
| `<` | Выравнивание влево |
| `>` | Выравнивание вправо |
| `=` | Выравнивание по центру |
| `<>` | Выравнивание по ширине |
| `(` | Отступ слева (1em за каждую скобку) |
| `)` | Отступ справа (1em за каждую скобку) |

**Пример комбинирования:**
```
p>{font-size:0.8em}. Параграф справа мелким шрифтом.

h2(class#id){color:blue}[en]. Blue English Heading
```

## Правила

- ЕСЛИ нужно отменить обработку Textile -> оберни в `==текст==`
- ЕСЛИ нужен блок без обработки -> используй `notextile.` или `<notextile>...</notextile>`
- ЕСЛИ блок содержит пустые строки -> используй расширенный синтаксис с двумя точками (`bc..`, `bq..`)
- ВСЕГДА завершай расширенный блок другим блочным элементом (обычно `p.`)
- ВСЕГДА ставь пробел после точки в блочных сигнатурах (`h2. Текст`, не `h2.Текст`)
- НИКОГДА не забывай закрывающий `|` в строках таблицы

При запросе на форматирование:

2. При необходимости добавь краткое пояснение синтаксиса

## Примеры

### Пример 1: Статья с форматированием

**Вход:** Создать статью с заголовком, списком и цитатой.

**Выход:**
```
h1. Введение в Textile

Textile -- это *легковесный язык разметки* для форматирования текста.

h2. Основные возможности

* Простой синтаксис
* Автоматическая типографика
* Поддержка таблиц и списков

bq. Textile существует с 2002 года и поддерживается многими CMS.

p. Подробнее на "официальном сайте":https://textile-lang.com/.
```

### Пример 2: Таблица с форматированием

**Вход:** Таблица со статусами задач.

**Выход:**
```
table(tasks#task-list).
|=. Статусы задач
|^.
|_. Задача |_. Статус |_. Исполнитель |
|-.
| Разработка API |{color:green}. *Готово* | @ivanov |
| Тестирование |{color:orange}. _В работе_ | @petrov |
| Документация |-Отменено- | @sidorov |
```

### Пример 3: Edge-case — сложное форматирование

**Вход:** Изображение-ссылка с классом и стилями внутри таблицы.

**Выход:**
```
|_. Превью |_. Описание |
| !(thumbnail){border:1px solid #ccc}/images/product.png(Продукт)!:https://example.com/product | *Название продукта* \n Краткое описание товара |
```
