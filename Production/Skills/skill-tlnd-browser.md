# Ticketland Browser

## Назначение

Скилл описывает КАК получить доступ к ticketland.ru, а не ЧТО делать на сайте. Задачи могут быть любыми: парсинг данных, отладка UI, SEO-аудит, работа с личным кабинетом, тестирование функционала, создание скриншотов.

Сайт защищён от ботов — HTTP-клиенты (curl, fetch, WebFetch) возвращают пустую страницу. Работает только реальный браузер Chrome через MCP.

---

## Что НЕ работает

- `curl`, `fetch`, `WebFetch`, любой HTTP-клиент -> пустая страница или блок

**Единственный способ** — Chrome через MCP-инструменты.

---

## Требования

- Google Chrome запущен
- Расширение "Claude in Chrome" установлено и активно

### Если Chrome закрыт или расширение не работает

При вызове `tabs_context_mcp` вернётся ошибка подключения. Действия:

1. Сообщить пользователю: "Для работы с ticketland.ru нужен браузер Chrome с расширением Claude. Запустите Chrome и убедитесь, что расширение активно."
2. Дождаться подтверждения
3. Повторить `tabs_context_mcp`

## Алгоритм работы

### 1. Получить контекст табов

```
mcp__claude-in-chrome__tabs_context_mcp
  createIfEmpty: true
```

Запомнить `tabId` из ответа.

### 2. Создать вкладку (опционально)

```
mcp__claude-in-chrome__tabs_create_mcp
```

### 3. Навигация на URL

```
mcp__claude-in-chrome__navigate
  url: "https://ticketland.ru/..."
  tabId: [tabId]
```

### 4. Ожидание загрузки

```
mcp__claude-in-chrome__computer
  action: "wait"
  duration: 2
  tabId: [tabId]
```

ВАЖНО: Всегда ждать 2-3 секунды после навигации. Контент загружается динамически.

### 5. Действия на странице

Выбор инструмента зависит от задачи:

| Задача | Инструмент |
|--------|------------|
| Извлечение данных | `javascript_tool` |
| Визуальный анализ | `computer` -> screenshot |
| Структура страницы | `read_page` |
| Чтение консоли | `read_console_messages` |
| Анализ запросов | `read_network_requests` |
| Взаимодействие | `computer` -> click/type/scroll |

---

## Правила

### ВСЕГДА

- Использовать Chrome MCP для ticketland.ru
- Ждать 2-3 секунды после навигации
- Делать паузу 1-2 секунды между страницами при пакетной обработке

### НИКОГДА

- Не использовать curl/fetch/WebFetch для ticketland.ru

### ЕСЛИ

- Страница не загрузилась -> увеличить wait до 3-4 секунд
- 404 или редирект -> записать ошибку, продолжить
- Контент не весь виден -> scroll вниз, повторить

## Примеры

### Пример 1: Базовый доступ к странице

```
1. tabs_context_mcp -> tabId
2. navigate(url, tabId)
3. wait(2)
4. Выполнить задачу (screenshot/javascript/read_page)
```

### Пример 2: Обработка списка URL

```
1. tabs_context_mcp -> tabId
2. Для каждого URL:
   a. navigate(url, tabId)
   b. wait(2)
   c. Выполнить задачу
   d. wait(1) // пауза перед следующим
3. Вернуть результаты
```

### Пример 3: Страница пустая

```
1. wait(2) // дополнительное ожидание
2. Повторить действие
3. Если всё ещё пусто -> записать ошибку, продолжить
```
