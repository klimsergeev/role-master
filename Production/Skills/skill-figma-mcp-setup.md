# Figma MCP Setup

## Назначение

Пошаговая процедура подключения проекта к локальному Figma MCP серверу. Применяется при первоначальной настройке интеграции Claude Code с Figma Desktop.

---

## Предварительные требования

| Требование | Проверка |
|------------|----------|
| Figma Desktop установлен | Приложение Figma запущено |
| MCP-сервер включён в Figma | Developer mode → Enable MCP Server |

---

## Алгоритм

### Шаг 1: Проверить запуск MCP-сервера в Figma

Проверить статус: сервер должен слушать `http://127.0.0.1:3845/mcp`

### Шаг 2: Определить путь к проекту

Получить абсолютный путь к корню проекта:

```bash
pwd
```

Пример результата: `/Users/username/Projects/my-app`

### Шаг 3: Проверить, настроен ли проект

**Способ 1 — проверить доступность MCP-инструментов:**

Попробовать вызвать `mcp__figma-desktop__get_screenshot` (без параметров).

| Результат | Интерпретация | Следующий шаг |
|-----------|---------------|---------------|
| Инструмент выполнился (любой ответ от Figma) | Конфигурация есть, сессия подключена | Перейти к шагу 6 |
| "Unknown tool" или инструмент не найден | Конфигурация отсутствует ИЛИ сессия не знает о ней | Перейти к шагу 4 |

**Способ 2 — прочитать ~/.claude.json (если способ 1 неубедителен):**

Запросить у пользователя содержимое файла или попросить проверить наличие записи для текущего проекта.

### Шаг 4: Добавить конфигурацию (если отсутствует)

1. Открыть файл `~/.claude.json`
2. Найти или создать секцию `projects`
3. Добавить запись для текущего проекта:

```json
{
  "projects": {
    "[path to project]": {
      "mcpServers": {
        "figma-desktop": {
          "type": "http",
          "url": "http://127.0.0.1:3845/mcp"
        }
      }
    }
  }
}
```

**Важно для [path to project]:**
- Путь должен быть абсолютным (начинаться с `/`)
- Путь должен точно совпадать с рабочей директорией проекта
- JSON должен быть валидным (проверить запятые, кавычки)

### Шаг 5: Попросить пользователя перезапустить Claude Code

После изменения `~/.claude.json` пользователь должен перезапустить Claude Code, чтобы новая сессия загрузила конфигурацию.

**Важно:** Если конфигурация уже была в файле, но инструменты недоступны — перезапуск также необходим. Новая сессия не наследует знания о конфигурации от предыдущей.

### Шаг 6: Проверить подключение

Пользователь должен подтвердить, что в Figma открыт файл и нужный элемент выделен.

Выполнить в Claude Code:

```
Используй mcp__figma-desktop__get_design_context чтобы получить данные о выделенном элементе
```

**Ожидаемый результат:** Claude возвращает React+Tailwind код для выделенного элемента.

## Устранение проблем

### Проблема: "Unknown tool" в новой сессии (конфигурация была настроена ранее)

| Причина | Решение |
|---------|---------|
| Новая сессия не загрузила конфигурацию | Попросить пользователя перезапустить Claude Code |
| Конфигурация была удалена/изменена | Проверить `~/.claude.json`, восстановить запись |
| Путь проекта изменился | Обновить путь в `~/.claude.json` |

**Важно:** Каждая новая сессия Claude Code загружает конфигурацию при старте. Если инструменты недоступны, но конфигурация в файле есть — попросить пользователя перезапустить Claude Code.

### Проблема: "MCP server not found" или инструменты недоступны

| Причина | Решение |
|---------|---------|
| JSON невалиден | Проверить синтаксис: запятые, кавычки, скобки |
| Неправильный путь | Путь должен точно совпадать с `pwd` |
| Claude Code не перезапущен | Пользователь должен выйти и запустить Claude Code заново |

### Проблема: "Connection refused" или timeout

| Причина | Решение |
|---------|---------|
| MCP-сервер не запущен | Включить в Figma: Developer mode → Enable MCP Server |
| Figma Desktop закрыта | Запустить Figma Desktop |
| Другой порт | Проверить порт в настройках Figma (по умолчанию 3845) |

### Проблема: Инструмент возвращает пустой результат

| Причина | Решение |
|---------|---------|
| Ничего не выделено в Figma | Выделить элемент на canvas |
| Выделен неподдерживаемый элемент | Выделить frame, component или group |
| Файл не открыт | Открыть файл в Figma |

### Проблема: JSON-ошибка при редактировании ~/.claude.json

Типичные ошибки:

```json
// НЕПРАВИЛЬНО: лишняя запятая
{
  "projects": {
    "/path/to/project": { ... },  // <-- лишняя запятая
  }
}

// НЕПРАВИЛЬНО: одинарные кавычки
{
  'projects': { ... }  // <-- должны быть двойные
}

// ПРАВИЛЬНО
{
  "projects": {
    "/path/to/project": {
      "mcpServers": {
        "figma-desktop": {
          "type": "http",
          "url": "http://127.0.0.1:3845/mcp"
        }
      }
    }
  }
}
```

---

## Правила

- ЕСЛИ JSON невалиден -> исправить синтаксис перед тем, как просить пользователя перезапустить Claude Code
- ЕСЛИ путь содержит пробелы -> заключить в кавычки, экранировать при необходимости
- ЕСЛИ несколько проектов -> добавить отдельную запись для каждого
- ВСЕГДА использовать абсолютные пути (начинающиеся с `/`)
- ВСЕГДА просить пользователя перезапустить Claude Code после изменения конфигурации
- ПОСЛЕ редактирования ~/.claude.json попросить пользователя перезапустить Claude Code, чтобы изменения вступили в силу

---

## Формат выдачи

После успешной настройки сообщить пользователю:

```
Figma MCP подключён.

Проверка: выдели элемент в Figma и попроси "сверстай этот компонент".

Доступные инструменты:
- get_design_context — код по макету
- get_screenshot — скриншот элемента
- get_metadata — структура макета
- get_variable_defs — токены дизайн-системы
```

## Примеры

### Пример 1: Первичная настройка

**Вход:** Пользователь хочет подключить проект `/Users/dev/my-react-app` к Figma

**Выход:**

1. Добавлена конфигурация в `~/.claude.json`:
```json
{
  "projects": {
    "/Users/dev/my-react-app": {
      "mcpServers": {
        "figma-desktop": {
          "type": "http",
          "url": "http://127.0.0.1:3845/mcp"
        }
      }
    }
  }
}
```

2. Пользователь перезапустил Claude Code
3. Подключение проверено через `get_design_context`

### Пример 2: Добавление к существующей конфигурации

**Вход:** В `~/.claude.json` уже есть другие проекты

**Выход:**

```json
{
  "projects": {
    "/Users/dev/existing-project": {
      "allowedTools": ["Edit", "Write"]
    },
    "/Users/dev/new-figma-project": {
      "mcpServers": {
        "figma-desktop": {
          "type": "http",
          "url": "http://127.0.0.1:3845/mcp"
        }
      }
    }
  }
}
```

### Пример 3: Конфигурация есть, но новая сессия не видит инструменты

**Вход:** Пользователь ранее настроил проект. Запускает новую сессию Claude Code и просит "сверстай компонент из Figma". Агент пытается вызвать `mcp__figma-desktop__get_screenshot` — получает "Unknown tool".

**Действия агента:**

1. Сообщить пользователю: "MCP-инструменты недоступны в этой сессии. Возможно, конфигурация есть, но сессия её не загрузила."
2. Попросить проверить `~/.claude.json` — есть ли запись для текущего проекта
3. ЕСЛИ запись есть -> попросить перезапустить Claude Code
4. ЕСЛИ записи нет -> выполнить шаг 4 (добавить конфигурацию)

**Выход:** После перезапуска инструменты доступны, задача выполняется.

## Самопроверка при подключении

При подключении скилла агент должен:

1. Прочитать `~/.claude.json`
2. Проверить наличие конфигурации для текущего проекта
3. Попробовать вызвать `mcp__figma-desktop__get_screenshot` для проверки связи
4. Вывести сообщение:

```
Скилл подключён: Figma MCP Setup

Назначение: Процедура подключения Figma Desktop к Claude Code.

Статус подключения:
• ~/.claude.json: [найден/не найден]
• Конфигурация проекта: [есть/нет]
• MCP-сервер: [доступен/недоступен]
```
