# Настройка NekoBox на Android

## Назначение

Процедура настройки VPN-клиента NekoBox for Android с WireGuard-сервером и раздельной маршрутизацией: российские домены идут напрямую, весь остальной трафик — через VPN-туннель.

---

## Самопроверка при подключении (ОБЯЗАТЕЛЬНО)

```
При подключении вывести:

**NekoBox Android proxy подключён**
Ключевые принципы:
- NekoBox 1.4.x: WireGuard профиль создаётся вручную (импорт .conf может не работать)
- Split tunneling: маршрут с domain_suffix .ru → обход, всё остальное через VPN по умолчанию
- geosite:ru в NekoBox может НЕ работать (ошибка rule-set not found), использовать domain_suffix .ru
- Пользовательская конфигурация с route.final может сломать встроенные правила (hijack-dns, fakeip)
- Включить «Анализ трафика» → «перехватывать результат для анализа» для работы маршрутов по доменам
```

## Алгоритм

### Шаг 1: Установка NekoBox

1. Скачать APK с GitHub: `github.com/MatsuriDayo/NekoBoxForAndroid/releases`
2. Установить последнюю stable версию (НЕ из Google Play — там фейк)
3. Открыть NekoBox

### Шаг 2: Создание WireGuard профиля

Импорт `.conf` файла может не работать (NekoBox показывает ошибку «не найден прокси»). В этом случае создать вручную:

1. Нажать **«+»** → выбрать тип **WireGuard**
2. Заполнить поля:

| Поле NekoBox | Значение из .conf |
|---|---|
| Сервер | Endpoint host (например, 88.210.20.207) |
| Удалённый порт | Endpoint port (например, 51820) |
| Частный адрес | Address (например, 10.8.0.18/24) |
| Закрытый ключ | PrivateKey |
| Открытый ключ сервера | PublicKey из [Peer] |
| Пароль сервера | PresharedKey из [Peer] |
| MTU | 1420 |

3. Сохранить (✓)
4. Выбрать профиль на главном экране → нажать ▶ для подключения

### Шаг 3: Обновление геобаз

1. Меню (☰) → **Ресурсы**
2. Нажать **Обновить** для geoip.db и geosite.db
3. Дождаться завершения

### Шаг 4: Создание маршрута для .ru доменов

1. Меню (☰) → **Маршруты** → создать новый маршрут
2. Заполнить:
   - **Название маршрута**: `ru-direct`
   - **domain**: `.ru` (суффикс — точка в начале обязательна)
   - **outbound**: **обход** (direct)
3. Сохранить (✓)
4. **Включить** маршрут (переключатель)

### Шаг 5: Включение анализа трафика

1. **Настройки** → **Включить анализ трафика** → выбрать **«перехватывать результат для анализа»**
2. Без этого NekoBox не сможет определять домены и маршрутизировать по ним

### Шаг 6: Подключение и проверка

1. Главный экран → выбрать WireGuard профиль → нажать ▶
2. Должен появиться значок VPN в статус-баре
3. Открыть youtube.com — должен работать через VPN
4. Открыть любой .ru сайт — должен работать напрямую

## Правила

- ЕСЛИ импорт .conf не работает → создавать профиль WireGuard вручную через «+» → WireGuard
- ЕСЛИ `geosite:ru` выдаёт ошибку `rule-set not found` или `code ru not exists` → использовать domain_suffix `.ru` вместо geosite
- ЕСЛИ ошибка `failed to read geosite code ru` → обновить геобазы в Ресурсах, ИЛИ отключить маршрут с geosite
- ЕСЛИ пользовательская конфигурация `{"route":{"final":"direct"}}` ломает VPN → она перезаписывает встроенные правила NekoBox (hijack-dns, fakeip). НЕ использовать route в пользовательской конфигурации
- ЕСЛИ весь трафик идёт через VPN несмотря на маршрут → проверить что маршрут **включён**, проверить «Анализ трафика»
- ЕСЛИ нужен split tunneling и по доменам, и по приложениям → домены в поле `domain` маршрута, приложения в поле `Приложения` того же маршрута
- ВСЕГДА подключать профиль (▶) — маршруты без активного VPN-туннеля не работают
- ВСЕГДА проверять что маршрут включён в списке маршрутов
- ВСЕГДА обновлять геобазы после установки NekoBox
- НИКОГДА не ставить NekoBox из Google Play (фейк)
- НИКОГДА не добавлять `route` в пользовательскую конфигурацию — это перезаписывает встроенные правила

## Примеры

### Пример 1: Базовая настройка (VPN для всего, .ru напрямую)

**Вход:** WireGuard `.conf`:
```
[Interface]
PrivateKey = xxx
Address = 10.8.0.18/24
DNS = 1.1.1.1

[Peer]
PublicKey = CPX4...
PresharedKey = yyy
AllowedIPs = 0.0.0.0/0, ::/0
Endpoint = 88.210.20.207:51820
```

**Выход:**
1. Профиль WireGuard: сервер=88.210.20.207, порт=51820, адрес=10.8.0.18/24, ключи из .conf
2. Маршрут: domain=`.ru`, outbound=обход
3. Анализ трафика: включён
4. Результат: youtube.com через VPN, sberbank.ru напрямую

### Пример 2: Добавление дополнительных доменов в bypass

**Вход:** Нужно чтобы vk.com и yandex.com тоже шли напрямую

**Выход:** В маршруте `ru-direct` в поле domain добавить через запятую: `.ru, vk.com, yandex.com`

### Пример 3: Split tunneling по приложениям

**Вход:** Telegram и YouTube-приложение должны идти через VPN

**Выход:** Создать маршрут: Приложения → выбрать Telegram, YouTube; outbound → выбрать WG-профиль. Для доменов использовать отдельный маршрут.

## Что НЕ входит в scope

- Настройка WireGuard сервера на VPS
- Генерация ключей WireGuard
- Настройка VPN на роутере
- Изоляция приложений через Island/Shelter (отдельная задача, часто не работает на Xiaomi)
- Скрытие tun0 от приложений (невозможно без root или VPN на роутере)
- Настройка Karing на macOS (см. skill-proxy-singbox-macos)
