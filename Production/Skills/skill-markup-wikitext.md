# Wikitext Markup

## Назначение

Справочник синтаксиса Wikitext для создания и редактирования страниц в MediaWiki. Применяется при работе с Wikipedia, внутренними wiki-системами и любыми проектами на MediaWiki.

---

## Самопроверка при подключении (ОБЯЗАТЕЛЬНО)

При подключении вывести:

**Wikitext Markup подключён**
Основные категории синтаксиса:
- Форматирование текста (жирный, курсив, заголовки)
- Списки (маркированные, нумерованные, описания)
- Ссылки (внутренние, внешние, файлы, категории)
- Таблицы (wikitable)
- Шаблоны и магические слова

## Краткий справочник

| Элемент | Синтаксис | Результат |
|---------|-----------|-----------|
| Жирный | `'''текст'''` | **текст** |
| Курсив | `''текст''` | *текст* |
| Жирный курсив | `'''''текст'''''` | ***текст*** |
| Заголовок H2 | `== Заголовок ==` | Раздел |
| Заголовок H3 | `=== Заголовок ===` | Подраздел |
| Маркированный список | `* пункт` | * пункт |
| Нумерованный список | `# пункт` | 1. пункт |
| Внутренняя ссылка | `[[Страница]]` | Страница |
| Внутренняя с текстом | `[[Страница\|текст]]` | текст |
| Внешняя ссылка | `[http://url текст]` | текст |
| Горизонтальная линия | `----` | --- |
| Перенос строки | `<br/>` | перенос |
| Код | `<code>код</code>` | `код` |
| Комментарий | `<!-- текст -->` | (скрыт) |

## Форматирование текста

### Заголовки

```wikitext
= H1 (не используется в статьях) =
== H2 — Основной раздел ==
=== H3 — Подраздел ===
==== H4 — Под-подраздел ====
===== H5 =====
====== H6 ======
```

**Правило:** H1 зарезервирован для заголовка страницы. Начинай разделы с H2.

### Начертание

| Синтаксис | Результат |
|-----------|-----------|
| `''курсив''` | *курсив* |
| `'''жирный'''` | **жирный** |
| `'''''жирный курсив'''''` | ***жирный курсив*** |

### Специальное форматирование

```wikitext
<code>inline код</code>
<pre>
блок
преформатированного текста
</pre>
<nowiki>[[не обрабатывается как ссылка]]</nowiki>
<small>мелкий текст</small>
<big>крупный текст</big>
<sup>верхний индекс</sup>
<sub>нижний индекс</sub>
<s>зачёркнутый</s>
<u>подчёркнутый</u>
```

## Списки

### Маркированные списки

```wikitext
* Первый пункт
* Второй пункт
** Вложенный пункт
** Ещё вложенный
*** Третий уровень
* Третий пункт
```

### Нумерованные списки

```wikitext
# Первый пункт
# Второй пункт
## Вложенный 2.1
## Вложенный 2.2
# Третий пункт
```

### Смешанные списки

```wikitext
# Нумерованный
#* Маркированный внутри
#* Ещё один
# Продолжение нумерации
```

### Списки описаний (definition lists)

```wikitext
; Термин
: Определение термина

; Термин 2
: Определение 2
: Дополнительное определение
```

### Отступы

```wikitext
: Один отступ
:: Двойной отступ
::: Тройной отступ
```

## Ссылки

### Внутренние ссылки

```wikitext
[[Название страницы]]
[[Название страницы|отображаемый текст]]
[[Название страницы#Раздел]]
[[Название страницы#Раздел|текст]]
```

### Внешние ссылки

```wikitext
[https://example.com]
[https://example.com Текст ссылки]
https://example.com (автоматическая ссылка)
```

### Ссылки на файлы и изображения

```wikitext
[[File:Example.png]]
[[File:Example.png|thumb|Подпись]]
[[File:Example.png|200px]]
[[File:Example.png|thumb|right|200px|Подпись справа]]
[[File:Example.png|link=Страница]]
```

**Параметры изображений:**

| Параметр | Описание |
|----------|----------|
| `thumb` | Миниатюра с рамкой |
| `frame` | Рамка без масштабирования |
| `frameless` | Без рамки |
| `border` | Тонкая рамка |
| `NNNpx` | Ширина в пикселях |
| `left/right/center/none` | Выравнивание |
| `alt=текст` | Альтернативный текст |

### Категории

```wikitext
[[Category:Название категории]]
[[Category:Название категории|Ключ сортировки]]
```

### Интервики-ссылки

```wikitext
[[en:English page title]]
[[de:German page title]]
```

## Таблицы

### Базовая структура

```wikitext
{| class="wikitable"
|-
! Заголовок 1 !! Заголовок 2 !! Заголовок 3
|-
| Ячейка 1 || Ячейка 2 || Ячейка 3
|-
| Ячейка 4 || Ячейка 5 || Ячейка 6
|}
```

### Элементы таблицы

| Синтаксис | Назначение |
|-----------|------------|
| `{|` | Начало таблицы |
| `|}` | Конец таблицы |
| `|-` | Новая строка |
| `!` | Ячейка заголовка |
| `!!` | Следующая ячейка заголовка (в одной строке) |
| `|` | Ячейка данных |
| `||` | Следующая ячейка данных (в одной строке) |
| `|+` | Заголовок таблицы (caption) |

### Атрибуты ячеек

```wikitext
{| class="wikitable"
|+ Заголовок таблицы
|-
! scope="col" | Колонка 1
! scope="col" | Колонка 2
|-
| style="background: #eee;" | Серый фон
| colspan="2" | Объединённые ячейки
|-
| rowspan="2" | Вертикальное объединение
| Ячейка
|-
| Ячейка
|}
```

### Классы таблиц

```wikitext
{| class="wikitable sortable"        <!-- Сортируемая -->
{| class="wikitable mw-collapsible"  <!-- Сворачиваемая -->
{| class="wikitable plainrowheaders" <!-- Простые заголовки строк -->
```

## Шаблоны

### Вызов шаблонов

```wikitext
{{Шаблон}}
{{Шаблон|параметр}}
{{Шаблон|параметр1|параметр2}}
{{Шаблон|name=value|name2=value2}}
{{Шаблон
 |параметр1 = значение1
 |параметр2 = значение2
}}
```

### Подстановка (substitution)

```wikitext
{{subst:Шаблон}}      <!-- Вставляет содержимое шаблона -->
{{safesubst:Шаблон}}  <!-- Безопасная подстановка -->
{{msgnw:Шаблон}}      <!-- Показывает исходный код шаблона -->
```

## Сноски и ссылки

### Сноски

```wikitext
Текст<ref>Содержимое сноски.</ref> продолжение.

Текст<ref name="имя">Сноска с именем.</ref> для повторного использования.

Повторная ссылка<ref name="имя" /> на ту же сноску.

<ref group="note">Сноска в группе "note".</ref>

== Примечания ==
{{reflist}}
<!-- или -->
<references />
```

### Цитаты

```wikitext
{{quote|Текст цитаты|Автор|Источник}}
<blockquote>Текст цитаты</blockquote>
```

## Специальные элементы

### Горизонтальная линия

```wikitext
----
```

### Переносы и пробелы

```wikitext
<br/>                     <!-- Перенос строки -->
<br clear="all"/>         <!-- Перенос с очисткой обтекания -->
&nbsp;                    <!-- Неразрывный пробел -->
```

### Комментарии

```wikitext
<!-- Этот текст не отображается на странице -->
```

### Отключение обработки

```wikitext
<nowiki>[[Не ссылка]] '''не жирный'''</nowiki>
<nowiki />Отключает только следующий элемент
<pre>
Преформатированный блок
без обработки wiki-разметки
</pre>
```

### HTML-сущности

```wikitext
&amp;   <!-- & -->
&lt;    <!-- < -->
&gt;    <!-- > -->
&quot;  <!-- " -->
&nbsp;  <!-- неразрывный пробел -->
&mdash; <!-- — -->
&ndash; <!-- – -->
```

## Магические слова

### Управление поведением

| Слово | Описание |
|-------|----------|
| `__TOC__` | Вставить оглавление здесь |
| `__NOTOC__` | Скрыть оглавление |
| `__FORCETOC__` | Принудительно показать оглавление |
| `__NOEDITSECTION__` | Скрыть ссылки редактирования разделов |
| `__NEWSECTIONLINK__` | Добавить ссылку «+» для новой темы |
| `__NOGALLERY__` | Отключить галерею в категории |

### Переменные страницы

| Переменная | Описание |
|------------|----------|
| `{{PAGENAME}}` | Название страницы |
| `{{FULLPAGENAME}}` | Полное название с пространством имён |
| `{{BASEPAGENAME}}` | Базовое название (без подстраницы) |
| `{{SUBPAGENAME}}` | Название подстраницы |
| `{{NAMESPACE}}` | Пространство имён |
| `{{TALKPAGENAME}}` | Название страницы обсуждения |

### Переменные даты и времени

| Переменная | Описание |
|------------|----------|
| `{{CURRENTYEAR}}` | Текущий год |
| `{{CURRENTMONTH}}` | Текущий месяц (01-12) |
| `{{CURRENTMONTHNAME}}` | Название месяца |
| `{{CURRENTDAY}}` | День месяца |
| `{{CURRENTDOW}}` | День недели (0-6) |
| `{{CURRENTTIME}}` | Время (HH:MM) |
| `{{CURRENTTIMESTAMP}}` | Timestamp (YYYYMMDDHHmmss) |

### Переменные сайта

| Переменная | Описание |
|------------|----------|
| `{{SITENAME}}` | Название wiki |
| `{{SERVER}}` | URL сервера |
| `{{SERVERNAME}}` | Имя сервера |
| `{{NUMBEROFPAGES}}` | Количество страниц |
| `{{NUMBEROFARTICLES}}` | Количество статей |
| `{{NUMBEROFUSERS}}` | Количество пользователей |

## Парсерные функции

### Условия

```wikitext
{{#if: условие | тогда | иначе }}
{{#ifeq: строка1 | строка2 | равны | не равны }}
{{#ifexist: Страница | существует | не существует }}
{{#switch: значение
 | вариант1 = результат1
 | вариант2 = результат2
 | #default = по умолчанию
}}
```

### Работа со строками

```wikitext
{{lc: ТЕКСТ}}         <!-- текст (нижний регистр) -->
{{uc: текст}}         <!-- ТЕКСТ (верхний регистр) -->
{{lcfirst: ТЕКСТ}}    <!-- тЕКСТ -->
{{ucfirst: текст}}    <!-- Текст -->
{{#len: строка}}      <!-- длина строки -->
{{#sub: строка | 0 | 3 }}  <!-- подстрока -->
{{#replace: строка | что | чем }}
```

### Форматирование чисел

```wikitext
{{formatnum: 1234567}}      <!-- 1 234 567 -->
{{#expr: 2 + 2 * 3}}        <!-- 8 -->
{{#time: d.m.Y | 2024-01-15 }}  <!-- 15.01.2024 -->
```

## Примеры

### Пример 1: Типичная статья

**Задача:** Создать структуру wiki-статьи

**Wikitext:**

```wikitext
'''Название темы''' — краткое определение.

== История ==
Текст об истории<ref>Источник информации.</ref>.

== Особенности ==
Основные характеристики:
* Первая особенность
* Вторая особенность
** Детализация

== Примеры ==
{| class="wikitable"
|-
! Название !! Описание
|-
| Пример 1 || Описание примера 1
|-
| Пример 2 || Описание примера 2
|}

== См. также ==
* [[Связанная статья]]
* [[Другая статья]]

== Примечания ==
{{reflist}}

[[Category:Основная категория]]
```

### Пример 2: Инфобокс с параметрами

**Задача:** Использовать шаблон инфобокса

**Wikitext:**

```wikitext
{{Infobox
 |title    = Заголовок
 |image    = [[File:Example.png|200px]]
 |caption  = Подпись к изображению
 |label1   = Параметр 1
 |data1    = Значение 1
 |label2   = Параметр 2
 |data2    = Значение 2
}}
```

### Пример 3: Сложная таблица

**Задача:** Таблица с объединёнными ячейками и стилями

**Wikitext:**

```wikitext
{| class="wikitable" style="text-align: center;"
|+ Заголовок таблицы
|-
! rowspan="2" | Категория
! colspan="2" | Группа A
! colspan="2" | Группа B
|-
! Подгруппа 1 !! Подгруппа 2 !! Подгруппа 1 !! Подгруппа 2
|-
| style="background: #f0f0f0;" | '''Строка 1'''
| 10 || 20 || 30 || 40
|-
| style="background: #f0f0f0;" | '''Строка 2'''
| 15 || 25 || 35 || 45
|}
```

## Что НЕ входит в scope

- Создание и редактирование шаблонов (Lua-модули)
- Администрирование MediaWiki (настройки, расширения)
- CSS-стилизация wiki (скины, TemplateStyles)
- Ботописание и API MediaWiki
- Специфичные расширения (VisualEditor, Wikibase)
