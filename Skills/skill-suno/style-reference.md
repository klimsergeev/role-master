# Style Reference

## Назначение

Справочник по полю Style в Suno AI: формула построения, правила, дескрипторы, конфликтные пары, негативный промптинг. Все данные для построения и валидации Style-промпта.

> **В интерфейсе поле называется `Styles`** (во множественном числе), рядом — `Lyrics` и `Song Title (Optional)`. В этом файле «Style» используется как краткое имя того же поля.

## Лимиты поля Styles

| Параметр | Значение |
|---|---|
| Жёсткий лимит | 1000 символов |
| Оптимум (консенсус сообщества) | 100-300 символов |
| Количество дескрипторов | 4-7 штук |
| Менее 4 дескрипторов | Модель «заливает» дефолтами |
| Более 7-10 дескрипторов | Конфликтуют, «мутный компромисс» |
| Текст сверх лимита | Обрезается молча — критичные дескрипторы ставить в начало |
| Exclude Styles | 1000 символов |

> **Лимит 1000 подтверждён дважды и не зависит от тарифа** (проверено 25.09.2026): константа `MAX_STYLE_CHARS_LONG = 1000` в продакшн-бандле `suno.com` и независимый замер счётчика в живом интерфейсе (`552/1000`). Ветка на 200 символов в том же коде относится к выключенным моделям — в старых руководствах расхождения именно отсюда. Поле Exclude Styles несёт `maxlength="1000"` (константа `MAX_NEGATIVE_STYLE_CHARS`). Suno лимиты полей нигде не публикует: в справочном центре их нет ни в одной статье.
>
> **Источники правил построения промпта** (не лимитов): Blake Crosley, HookGenius, MusicSmith, gist jsadeli, smithery suno-song — кросс-подтверждено 5+ источниками.

## Формула Style

Основная формула (кросс-подтверждённая):

```
Genre, Subgenre, Tempo/Energy, Key Instruments, Vocal Style, Production Quality, Mood
```

Альтернативная формула GMIV (более краткая):

```
Genre, Mood, Instruments, Vocals
```

Русскоязычная схема (из Habr):

```
жанр, настроение, язык, тип вокала, темп, инструменты, назначение, характер припева
```

Все формулы сводятся к одному: **жанр первым, затем по убыванию важности**.

## Позиционное взвешивание

Первый дескриптор влияет сильнее остальных. По оценкам сообщества — до 30-60% веса приходится на первый тег (источники расходятся в точных цифрах, но единогласны в принципе: порядок имеет значение).

**Правило:** жанр — всегда первый дескриптор. Далее — по убыванию важности для конкретного запроса.

**Пример влияния порядка:**

| Style | Результат |
|---|---|
| `Jazz, electronic elements, smooth` | Джазовый трек с электронными вставками |
| `Electronic, jazz influences, smooth` | Электронный трек с джазовым оттенком |

## Правила поля Style

### Обязательные

- Ключевые слова через запятые — описательные предложения запрещены (`a song that sounds like summer evening...`), но допустимы структурные метки для разделения категорий дескрипторов. Формат: `<жанр, инструменты, продакшн, bpm>. Lead vocalist: <регистр, тембр, подача>. Chorus: <тип хука, бэки>.` Метка `Lead vocalist:` не даёт модели «размазать» вокальные дескрипторы по инструментам (например, `gravelly` по ошибке применится к гитаре). Приём выведен на прежних моделях (V4.5, V5.5); они выключены, на v6 он не перепроверялся — держать как рабочий по умолчанию и смотреть по результату
- Квадратные скобки `[]` запрещены — вызывают артефакты/игнор; скобки только в Lyrics
- Жанр — первый дескриптор
- BPM как цифра (`128 BPM`) работает лучше слов (`fast-paced`), но воспринимается как ориентир, не метроном
- Style и метатеги — всегда на английском, даже если текст песни на другом языке

### Запрещённые приёмы

| Приём | Почему плохо | Замена |
|---|---|---|
| Имена артистов (`like Adele`) | Ненадёжно, фильтруется | Описание стиля: `powerful female vocal, piano-driven pop ballad` |
| Описательные предложения (`a song that sounds like...`) | Модель ожидает ключевые слова | Ключевые слова через запятые. Допустимы структурные метки (`Lead vocalist:`, `Chorus:`) |
| Квадратные скобки (`[rock]`) | Артефакты в генерации | Без скобок: `rock` |
| Технические термины сведения (`sidechain compression`, `EQ boost`) | Модель игнорирует | Описание результата: `punchy bass, crisp highs` |
| Негации (`no drums`) вместо Exclude Styles | Работают, но слабее выделенного поля | Exclude Styles, если контрол доступен; негации в Styles — когда нет |

## Конфликтные пары дескрипторов

ЕСЛИ два дескриптора из одной пары присутствуют в Style -> убрать один, оставить более важный для задачи.

| Дескриптор A | Дескриптор B | Почему конфликт |
|---|---|---|
| Very Slow | High Energy | Противоречие темпа и энергии |
| Minimal | Orchestral | Минимализм vs максимум инструментов |
| Acoustic | Heavy Electronic | Физический звук vs синтетический |
| Lo-fi | Crystal Clear Production | Грязь vs чистота |
| Whisper vocals | Powerful belt | Тихий vs громкий вокал |
| Gentle / Soft | Aggressive / Intense | Мягкость vs агрессия |

## Жанровые якоря

Отдельные дескрипторы, которые непропорционально сильно утягивают генерацию в конкретный жанр. Использовать осознанно; при нежелательном эффекте — убрать якорь или добавить жанр в Exclude.

| Якорь в Style | Куда утягивает |
|---|---|
| `accordion`, `gravelly`/`smoky` тембр, `weathered man`, `over beer`, `drunken`, `tavern` | Русский шансон / блатняк |
| `four-on-the-floor`, `youthful`, `festival`, `indie`, `synth stabs`, `fun` | Молодёжный поп-панк / дэнс |
| `boom-bap drums`, `turntable scratches`, `head-nodding groove`, `mature and confident`, ~95 BPM | Рэп-хоп |
| `fingerpicked guitar`, `campfire` | Бард / акустика |

**Практика:** жанр тонко настраивается набором якорей + Exclude на якоря нежелательного жанра. `mature and confident` — противоядие от «молодёжности» вокала.

> Данные проверены на практике (несколько итераций генерации в Suno на V4.5/V5.5 — модели выключены, на v6 якоря не перепроверялись). Якорь — наблюдение о том, куда тянет дескриптор, а не свойство конкретной версии: проверять по результату первого прогона.

## Тональность и гармония

### Тональность (key) — надёжно

Конкретная тональность в Style работает как сильный дескриптор настроения и держит гармоническую окрестность (лад), но не конкретную последовательность аккордов:

- `A minor key, melancholic` — минор + настроение, связка надёжнее каждого по отдельности. Слово `key` помогает модели трактовать `A minor` как тональность, а не как аккорд
- `Key: D Major, uplifting` — формат с меткой `Key:` тоже распознаётся
- Тональность ставить рядом с жанром (позиционное взвешивание)

### Прогрессии аккордов — направление, не точные аккорды

Suno НЕ следует точной прогрессии: текст задаёт максимум общее **гармоническое направление**, но не конкретные аккорды, инверсии и голосоведение (voicings). Официального механизма нет. Что работает и насколько:

| Приём | Где | Надёжность (оценка комьюнити) |
|---|---|---|
| Тональность + настроение (`A minor key, melancholic`) | Style | Высокая — держит лад/окрестность |
| Именованная формула (`12-bar blues`, `flamenco progression`) | Style | Средняя — частотные формулы модель «знает» из обучающей выборки |
| Буквенная прогрессия (`Am-F-C-G progression`) | Style | Низкая — берёт направление, регармонизирует (упрощает, заменяет аккорды) |
| Скобочные аккорды построчно (`[Am] текст [F] текст`) | Lyrics | Низкая для точности; основная польза — защита от пропевания аккордов вслух |
| Аккорды в тексте БЕЗ скобок (`Am F G Em`) | Lyrics | ЗАПРЕЩЕНО — модель споёт названия аккордов вслух (lyrical contamination) |
| Аудио-референс + Audio Influence 75–90% | Upload Audio → Cover / Remix | Высокая — единственный способ задать конкретную гармонию |

### Практика

- **Точную прогрессию задаёт только аудио-референс.** Текст (формула, тональность, скобочные аккорды) — ориентир направления, не конкретные аккорды/инверсии/voicings. Детали аудио-метода — в [platform-workflow.md](platform-workflow.md)
- Модель тяготеет к частотным прогрессиям обучающей выборки: I-V-vi-IV, vi-IV-I-V, 12-bar blues. Назвать узнаваемую формулу словами — реалистично; заставить играть нестандартную буквенную последовательность текстом — нет
- Именованные ходы работают лучше буквенных: `12-bar blues`, `flamenco progression`, `circle of fifths` вместо перечисления аккордов
- Скобочные аккорды в Lyrics (`[Am] текст [F] текст` для песни / `[Am] [F] [G] [Em]` для инструментала) — ориентир + защита от пропевания, НЕ способ задать гармонию. Подробнее — в [lyrics-formatting.md](lyrics-formatting.md) и [metatags-reference.md](metatags-reference.md)
- Модуляции (смена тональности), сложная джаз-гармония и конкретные каденции текстом не контролируются — честно предупреждать пользователя

## Негативный промптинг

### Exclude Styles

Выделенное поле в Advanced Options (лимит 1000 символов). Исключает инструменты, стили, тип вокала.

> **Доступность на Free не установлена.** Страница тарифов описывает Free как «Standard features only» и не перечисляет состав; ни справка, ни страница тарифов не говорят, есть ли там Exclude Styles. Поэтому: не утверждать ни доступность, ни недоступность, а собирать промпт так, чтобы он работал и без этого поля (негации прямо в Styles). Подробности — в [platform-workflow.md](platform-workflow.md).

- До ~5 исключений — дальше выход «худеет»
- Формат: ключевые слова (отображаются с префиксом `-`, например `-piano`). Официально: «Excluded styles shown as "-" prefix». Практики побайтово показали, что Suno дописывает исключения к отображаемому стилю со знаком минус, **не меняя введённый текст стиля** — введённое остаётся точным префиксом того, что показывает интерфейс
- Исключения — «руководство, не запрет»: модель учитывает, но не гарантирует
- **Связка Style + Exclude эффективнее**, чем просто убрать триггеры из Style: «Style тянет → Exclude отрезает» — держит жанр с двух сторон
- Действует на одну генерацию — у каждого трека свой список
- После стабилизации жанра сокращать список до 3-4 главных пунктов — длинный список даёт обезличенную «кашу»
- **Список составлять от рисков конкретного трека, а не общими словами.** Спрашивать, куда утянет именно эта тема и именно этот жанр: тема пьянки — в шансон, современный рэп по умолчанию — в trap, рэпкор перелетает в pop punk и metalcore, melodic hooks утекают в EDM
- **Исключение может задушить то, что просили в теге секции.** `metalcore` в Exclude работает против `dirty overdriven` соло в теге. При разборе неудачного прогона Exclude Styles — подозреваемый наравне со Style

**Паттерны использования:**

| Задача | Exclude Styles |
|---|---|
| Убрать пианино | `piano` |
| Чистый инструментал | `vocals` (+ режим лирики Instrumental) |
| Женский вокал без мужского | `male vocals` |
| Убрать электронику | `synth, electronic, EDM` |

### Негации в Style (`no X`)

Работают, но выделенное поле Exclude Styles надёжнее. Когда Exclude Styles в форме нет — негации в Styles остаются единственным вариантом и работают на любой модели поколения v6.

**Пример:** `Indie rock, mid-tempo, no piano, no synth, raw guitar, raspy male vocals`

### Инструментал

Для чистого инструментала — комбинация:
- Режим лирики Instrumental в форме Advanced (главный механизм)
- `no vocals, instrumental` в Style (подкрепление)
- `vocals` в Exclude Styles (дополнительная гарантия, если контрол есть в форме)

## Слайдеры

> **Caveat:** Suno не публикует числовые шкалы слайдеров. Рекомендации ниже — на основе наблюдений сообщества.
>
> **Перед слайдерами — Variety.** В v6 в форме появился слайдер Variety, который переписывает само поле Styles: «adjusting and updating your style prompts», и «if you'd like to retain full control of your style tags, reduce the Variety slider to 0». Пока Variety поднят, всё, что написано в этом файле про точность дескрипторов и порядок, теряет силу — модель работает с переписанным стилем. Полный перечень контролов формы (Variety, Max Mode, Personalize, Mumble Mode, Replace Mode) — в [platform-workflow.md](platform-workflow.md).

### Weirdness (Safe <-> Chaos)

| Значение | Когда использовать |
|---|---|
| Low (Safe) | Коммерческая музыка, фоновая, джинглы, стандартные жанры |
| Medium | Авторские треки, лёгкие эксперименты |
| High (Chaos) | Жанровые гибриды, авангард, экспериментальная музыка |

### Style Influence (Loose <-> Strong)

| Значение | Когда использовать |
|---|---|
| Strong | Точный промпт, знаешь чего хочешь |
| Medium | Промпт задаёт направление, детали на усмотрение модели |
| Loose | Нужен сюрприз, промпт как намёк |

### Audio Influence

Степень влияния загруженного референс-аудио. Актуально для Covers, Remixes, Add Vocals/Instrumentals.

## Примеры Style-промптов

### Pop

```
Synth-pop, upbeat, 120 BPM, catchy synth hooks, bright female vocals, polished production, fun and carefree
```

### Rock

```
Alternative rock, mid-tempo, distorted electric guitar and driving drums, raspy male vocals, raw production, melancholic and defiant
```

### Hip-Hop

```
Trap, aggressive, 140 BPM, heavy 808 bass, hi-hats, confident male rap, dark and intense
```

### Инди-фолк

```
Indie folk, slow tempo, acoustic guitar and banjo, warm female vocals, lo-fi production, intimate and nostalgic
```

### Электроника

```
Deep house, groovy, 122 BPM, warm synth pads, deep bass, no vocals, instrumental, hypnotic and atmospheric
```

### Джаз

```
Smooth jazz, relaxed, saxophone and upright bass, sultry female vocals, warm production, late-night mood
```

### Русский рок

```
Russian rock, mid-tempo, electric guitar and bass, gritty male vocals, raw production, emotional and sincere
```

> Для русского рока текст в Lyrics — на русском, Style и метатеги — на английском. Подробнее — в [lyrics-formatting.md](lyrics-formatting.md).

### Кинематографический инструментал

```
Cinematic orchestral, epic, slow build, strings and brass, no vocals, powerful drums, grand and heroic
```

### Колыбельная

```
Lullaby, very slow, gentle acoustic guitar, soft female vocals, minimal production, warm and soothing
```
