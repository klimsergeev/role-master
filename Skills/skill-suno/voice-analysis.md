# Voice Analysis

## Назначение

Процедура описания голоса референса для Suno через акустический анализ кодом (librosa + praat-parselmouth), когда Claude не может слушать аудио напрямую. Результат — набор вокальных дескрипторов для поля Style.

## Подготовка аудио

Конвертация в формат, пригодный для анализа:

```bash
ffmpeg -i in.ogg -ar 22050 -ac 1 out.wav
```

- Моно, 22050 Гц — стандарт для librosa/Praat
- Входной формат: любой (ogg, mp3, m4a, wav)

## Таблица метрик → дескрипторов

| Метрика | Инструмент | Перевод в дескриптор |
|---|---|---|
| F0 медиана (pyin) | librosa | <110 Гц → `bass-baritone`, 110-130 → `low baritone`, 130-160 → `baritone`, >160 → `tenor` |
| F0 диапазон 10-90 перц. | librosa | узкий (<7 полутонов) → `narrow melodic range, deadpan delivery` |
| HNR | Praat | <12 дБ → `raspy/hoarse`, 12-20 → норма, >20 → `clean smooth` |
| Джиттер >1.5% / шиммер >6% | Praat | `gravelly rough texture` |
| Спектральный центроид | librosa | <1500 Гц → `dark chesty timbre`, >2500 → `bright` |
| Onset-пики / активная речь | librosa | >5 слог/сек → `punchy bursts, fast phrasing`; доля пауз → `lazy phrasing` |

## Оговорки (обязательно сообщать пользователю)

- **Компрессия мессенджеров** (Telegram voice = opus low bitrate) завышает джиттер/шиммер → «хрипотца» в метриках может быть преувеличена. Закладывать ручку отката: `gravelly` → `slightly raspy`
- **Текстовое описание даёт типаж, не клон.** Для клона — загрузка аудио в Suno (Covers / Personas), это всегда точнее слов
- **Права на голос.** Учитывать, что у пользователя может не быть права использовать чужой голос — предупредить

## Рабочий процесс

1. Получить аудиофайл от пользователя
2. Конвертировать в WAV (ffmpeg)
3. Запустить анализ librosa (F0, спектральный центроид, onset-пики) + Praat (HNR, джиттер, шиммер)
4. Перевести метрики в дескрипторы по таблице выше
5. Собрать вокальный стек для Style (2-3 дескриптора)
6. Сообщить пользователю оговорки (компрессия, типаж vs клон, права)
7. Включить дескрипторы в секцию Style промпта

## Формат результата

В промпте добавить секцию:

```
**Голос вокалиста:**
- Регистр: [дескриптор] (из F0 медиана: [значение] Гц)
- Тембр: [дескриптор] (из HNR: [значение] дБ, центроид: [значение] Гц)
- Текстура: [дескриптор] (из джиттер: [значение]%, шиммер: [значение]%)
- Фразировка: [дескриптор] (из onset-пики: [значение] слог/сек)
⚠ Метрики получены из сжатого аудио — возможно преувеличение хрипотцы
```

> Данные проверены на практике (несколько итераций генерации в Suno с описанием голоса по метрикам).
