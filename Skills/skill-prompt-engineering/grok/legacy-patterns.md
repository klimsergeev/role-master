# Grok: каталог устаревших приёмов

## Назначение

Справочник приёмов, устаревших, вредных или ненужных для покрываемых моделей Grok: по какому признаку их найти, почему приём устарел и чем его заменить. Используется при аудите, проверке готового промпта и переносе на другую версию модели.

## Как читать таблицу

- «Что искать» — примеры формулировок и признаков для поиска (`grep -n -i`, `rg -i`). Совпадение — повод прочитать место целиком, а не вывод: та же строка может стоять внутри официального блока, вставленного дословно, или в цитате.
- «Модели» — для каких моделей это установлено.
- Большая часть строк касается кода запроса и ведения истории, а не формулировок: официальных указаний xAI о формулировках текста промпта для текстовых моделей мало ([principles.md](principles.md)).
- Сверено 2026-11-13.

## Каталог

| Приём | Что искать | Почему устарел | Замена | Модели |
|---|---|---|---|---|
| Chat Completions вместо Responses API | `/v1/chat/completions`, `chat.completions`, массив `messages` в запросах к API xAI | Эндпоинт устарел и не передаёт зашифрованное рассуждение; результаты через него занижают возможности рассуждающих моделей, особенно на нескольких ходах и с вызовами инструментов | Responses API ([parameters.md](parameters.md), раздел «Поверхности») | Все покрываемые модели |
| Отключение рассуждения у Grok 4.5–4.7 | `reasoning_effort: "none"`, `"effort": "none"`, инструкции, рассчитанные на модель без рассуждения | Рассуждение у этих моделей не отключается | Уровень `low`, если нужна меньшая задержка; какие модели семейства работают без рассуждения — раздел «Общее для всех моделей» в [models.md](models.md) | Grok 4.7, 4.6, 4.5 |
| Штрафы за повторы и стоп-последовательности при рассуждении | `presencePenalty`, `presence_penalty`, `frequencyPenalty`, `frequency_penalty`, `stop` в запросе | Запрос с ними к рассуждающей модели возвращает ошибку | Убрать | Рассуждающие модели: Grok 4.7, 4.6, 4.5, Grok 4.3 на уровне выше `none`, рассуждающий вариант Grok 4.20 |
| Вероятности токенов | `logprobs`, `top_logprobs` | Молча игнорируются | Убрать и не строить на них логику | Grok 4.20 и более новые модели, то есть все покрываемые |
| Нестандартные `temperature` и `top_p` | `temperature` и `top_p` со значениями, отличными от 0.7 и 0.95; температура выше 1 | Модели Grok плохо отзываются на другие настройки сэмплирования, и качество обычно падает; температура выше 1 сэмплируется как 1 | `temperature` 0.7 и `top_p` 0.95; нужное поведение — текстом промпта ([parameters.md](parameters.md), раздел «Параметры сэмплирования») | Все покрываемые модели |
| Пересборка истории между ходами | `output_text`, добавленный в историю обычным сообщением ассистента; правка, перестановка или фильтрация элементов вывода перед отправкой назад; пересборка беседы в массив `messages` между ходами | Теряются рассуждение и кеш | Возвращать элементы вывода ровно в полученном виде, весь массив вместе с вызовами функций ([parameters.md](parameters.md), раздел «История и рассуждение между ходами») | Рассуждающие модели |
| Текущее время в начале системного промпта | `current time`, `today is`, `{{now}}`, `datetime` в первых строках системного промпта | Ломает кеш и удорожает беседу | В начало последнего сообщения пользователя ([parameters.md](parameters.md), раздел «Кеш и порядок частей») | Все покрываемые модели |
| Системный промпт перед элементом сжатия или в `instructions` при сжатии | Код, который ставит системный промпт во вводе до элемента сжатия или передаёт его в `instructions` вместе со сжатием | API отбрасывает всё до элемента сжатия, включая `instructions`; в замере xAI на Grok 4.7 модель теряла справочник и выдумывала детали | Элемент сжатия первым, системный промпт — после него во вводе ([parameters.md](parameters.md), раздел «Сжатие контекста») | Все покрываемые модели; замер — на Grok 4.7 |
| Устаревшее имя модели в тексте | `grok-4-0709`, `grok-4-fast`, `grok-4-1-fast`, `grok-code-fast`, `grok-3`, «You are Grok 4» | Модели выведены из API 15.05.2026. `grok-code-fast-1`, `grok-code-fast` и `grok-code-fast-1-0825` числятся алиасами `grok-build-0.1`, которая вне охвата; о перенаправлении `grok-code-fast-1` источники расходятся ([migrations.md](migrations.md)) | Имя покрываемой модели из [models.md](models.md) | Все |

## Поиск по колонке «Что искать»

Поиск без учёта регистра по всем файлам охвата, например:

```bash
rg -n -i "chat/completions|chat\.completions|\"messages\"|reasoning_effort|\"effort\"|presence_?penalty|frequency_?penalty|\"stop\"|logprobs|temperature|top_p|output_text|current time|today is|\{\{now\}\}|datetime|compaction|grok-4-0709|grok-4-fast|grok-4-1-fast|grok-code-fast|grok-3([^.0-9]|$)|you are grok 4([^.0-9]|$)" "<путь>"
```
