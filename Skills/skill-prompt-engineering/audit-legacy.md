# Аудит промптов и скиллов на устаревшие приёмы

## Назначение

Процедура поиска в готовых промптах и текстах агентной среды приёмов, устаревших или вредных для текущих моделей Claude или Gemini. Результат — таблица находок с причиной и заменой.

Файлы семейства лежат в папке `claude/` или `gemini/`; ниже они названы по имени файла, папку задаёт семейство.

## Шаг 1. Определить охват

- Перечень файлов или каталогов — абсолютными путями.
- Семейство и целевая модель для каждого файла. Семейство определяется по целевой модели файла. ЕСЛИ модель не задана, но семейство ясно (например, CLAUDE.md или `GEMINI.md`) → проверять по всем покрываемым моделям семейства и в каждой находке указывать, к каким моделям она относится. ЕСЛИ семейство не определяется → запросить.
- Входят ли в задачу правки. ЕСЛИ правки не заказаны → аудит заканчивается отчётом, файлы не меняются.

## Шаг 2. Найти кандидатов поиском

По колонке «Что искать» в `legacy-patterns.md` семейства выполнить поиск без учёта регистра по всем файлам охвата; пример команды — раздел «Поиск по колонке «Что искать»» того же файла: [claude/legacy-patterns.md](claude/legacy-patterns.md) или [gemini/legacy-patterns.md](gemini/legacy-patterns.md).

Перед поиском посмотреть две-три строки реального текста файлов: шаблон пишется под их язык и формат. Нулевой результат поиска означает только, что шаблон не совпал.

## Шаг 3. Найти то, что поиском не находится

- Чрезмерная предписанность и многословие: длинные перечни поведений по именам, микрошаги на каждое действие, списки граничных случаев вместо примеров — строки `legacy-patterns.md` семейства о таких приёмах.
- Противоречия между инструкциями внутри файла и между файлами одного охвата (раздел «Противоречия внутри промпта» в `principles.md` семейства).
- Для текстов агентной среды — правила формата из файла текстов агентной среды семейства: [claude/claude-code-artifacts.md](claude/claude-code-artifacts.md) или [gemini/gemini-cli-artifacts.md](gemini/gemini-cli-artifacts.md) (длина файлов, описания, ссылки на несуществующие файлы).
- Для Gemini: описания функций и поля схем — по [gemini/agents-and-tools.md](gemini/agents-and-tools.md); код запросов — параметры, которые модель игнорирует или отвергает, по [gemini/parameters.md](gemini/parameters.md).

## Шаг 4. Разобрать каждого кандидата

Открыть место и прочитать его в контексте. Каждого кандидата отнести к одному исходу:

| Исход | Признак | В отчёт |
|---|---|---|
| Находка | Приём из каталога, и целевая модель есть в колонке «Модели» | Да |
| Часть официального блока | Текст совпадает с блоком в `official-blocks.md` семейства, вставленным дословно (у Claude — капс в `investigate_before_answering`, `NEVER` в `frontend_aesthetics`; у Gemini — `MUST` и выделение в шаблонах Google) | Нет; блок проверяется на условие применения, а не на капс |
| Цитата или описание приёма | Приём упомянут как пример, запрет или документация, а не как инструкция модели | Нет |
| Другая модель | Строка каталога относится к модели, на которой промпт не работает | Нет; отметить отдельно, если промпт могут перенести |

## Шаг 5. Записать отчёт

| Файл:строка | Приём (строка каталога) | Текст | Почему устарел | Замена | Модели |
|---|---|---|---|---|---|

После таблицы — число находок по строкам каталога и перечень файлов без находок.

## Шаг 6. Внести правки, если они заказаны

- ЕСЛИ правки входят в задачу → внести замены из колонки «Замена» точечно; официальные блоки — дословно из `official-blocks.md` семейства.
- После правок повторить поиск шага 2 по исправленным файлам и сверить, что изменились ровно места из отчёта.

## Пример (Claude)

**Вход:** аудит каталога скиллов Claude Code на устаревшие приёмы, целевая модель не задана.

**Ход:** поиск шага 2 даёт 14 совпадений. Три — `MUST` внутри вставленного дословно блока `investigate_before_answering` (исход «Часть официального блока»). Одно — строка документации скилла, перечисляющая запрещённые фразы (исход «Цитата»). Десять — находки: шесть «Капс и нагнетание», три «Просьба выписать рассуждение в ответ» (модели Fable 5.1, Opus 5.5, Sonnet 5.5), одна «Подстёгивание „не ленись“». Шаг 3 добавляет одну находку: в CLAUDE.md раздел с деревом каталогов.

**Результат:** таблица из одиннадцати строк и перечень файлов без находок; правки не вносились, потому что не были заказаны.

Пример иллюстративный.
