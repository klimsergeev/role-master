# GPT: каталог устаревших приёмов

## Назначение

Справочник приёмов, устаревших, вредных или ненужных для покрываемых моделей GPT: по какому признаку их найти, почему приём устарел и чем его заменить. Используется при аудите, проверке готового промпта и переносе на другую версию модели.

## Как читать таблицу

- «Что искать» — примеры формулировок и признаков для поиска (`grep -n -i`, `rg -i`). Совпадение — повод прочитать место целиком, а не вывод: та же фраза может стоять внутри официального блока, вставленного дословно, или в цитате.
- «Модели» — для каких моделей это установлено.
- «Замена» ссылается на блоки из [official-blocks.md](official-blocks.md) по их заголовкам.
- Сверено 2026-11-11.
