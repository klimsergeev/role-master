# Claude: переходы между версиями

## Назначение

Таблица переходов между версиями моделей Claude: что меняется в тексте промпта при переносе на текущую модель. Используется на шаге поиска перехода в [../migrate-prompt.md](../migrate-prompt.md); поведение целевой модели — в [models.md](models.md), устаревшие приёмы — в [legacy-patterns.md](legacy-patterns.md).

Сверено 2026-11-09.

## Переходы

| Переход | Что меняется в тексте |
|---|---|
| Opus 5 → Opus 5.5 | Промпты работают без изменений, паттерны Opus 5 остаются отправной точкой; инструкции, настроенные под поведение Opus 5, могут быть уже не нужны. ЕСЛИ промпт писался под выключенное мышление → убрать инструкции, заменявшие мышление записью рассуждения в ответе; убрать правило «не думай»; перепроверить, нужен ли блок «Промпты под отключённое мышление». Перепроверить обходные приёмы для зрения. Дальше — строки раздела Opus 5.5 в models.md по задаче |
| Opus 4.8 и старше → Opus 5.5 | Всё из строки Opus 5 → Opus 5.5, плюс строки «паттерн Opus 5» раздела Opus 5.5 в models.md: краткость, длина документов, удаление инструкций перепроверки, ограничение объёма, делегирование, поправки, ревью кода. С Opus 4.6 и старше — убрать каркас принудительных статусов (Opus 4.7 даёт сообщения о ходе работы сам). С Opus 4.5 и старше — убрать опору на заданное начало ответа (не поддерживается с моделей 4.6; текстовые замены в legacy-patterns.md). Для промптов, писавшихся под модели до Opus 4.5 и 4.6, — смягчить «CRITICAL / MUST» и подстёгивание «не ленись» (Opus 4.5 и 4.6 чувствительнее к системному промпту, модели 4.6 проактивнее) |
| Fable 5 → Fable 5.1 | Промпты работают без изменений. Проверить по поведению, изменившемуся с Fable 5: пакетные вызовы, прогресс-сообщения (убрать «hold all findings»), поиск на низком уровне усилия, плотность прозы, форматирование в чате (убрать антиформатирование), цитаты без пометки, переписывание файлов целиком |
| Opus 5, Opus 4.8 и старше → Fable 5.1 | Всё из строки Fable 5 → Fable 5.1, плюс: найти и убрать просьбы выписать или показать ход мышления, сократить слишком предписывающие инструкции и скиллы; строки раздела Fable 5.1 в models.md по задаче |
| Sonnet 5 → Sonnet 5.5 | Промпты работают без изменений, паттерны Sonnet 5 остаются отправной точкой. Убрать правила «не думай». Проверить размещение сообщений пользователя посреди хода. Дальше — строки раздела Sonnet 5.5 в models.md по задаче |
| Sonnet 4.6 и старше → Sonnet 5.5 | Всё из строки Sonnet 5 → Sonnet 5.5, плюс строки «паттерн Sonnet 5»: явный охват инструкций (буквальное следование), краткость, удаление каркаса принудительных статусов, тон и разнообразие инструкциями вместо параметра, дизайн, ревью кода. С Sonnet 4.5 и старше — убрать опору на заданное начало ответа (Sonnet 4.5, Haiku 4.5 и старше его принимают, Sonnet 4.6 и новее — нет) |
| Haiku 4.5 → Haiku 5.5 | Промпты работают без изменений. С инструментом поиска — дать дату и при длинном промпте подсказку искать; не ставить общей инструкции искать всегда. Строки раздела Haiku 5.5 в models.md по задаче. Убрать опору на заданное начало ответа и на встроенный счётчик контекста |
| Между линиями (например, Opus → Sonnet, Sonnet → Haiku) | Отдельных официальных правил о тексте промпта для такого перехода нет. Убрать блоки и формулировки, написанные под поведение исходной модели, которого у целевой не описано; применить раздел целевой модели в models.md и правило шага 2 процедуры переноса о приёмах, измеренных на конкретной модели |
