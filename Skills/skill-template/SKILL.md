## Таблица маршрутизации

> Читай файлы под задачу, а не скилл целиком. Колонка «Обязательно» — открыть до начала работы. Колонка «Читать, если» — открыть, когда условие выполнено; условие проверяется по задаче, а не по желанию. Файлы с пометкой `(справочник)` устроены как таблицы для точечного поиска — в них допустим поиск нужной строки вместо чтения целиком.

<!-- КОЛОНКА «Обязательно» — файлы, без которых задача из этой строки не будет
     выполнена корректно. Пустой быть не может: если для задачи нечего открыть
     обязательно, значит строка описана неверно — переформулируй задачу.

     КОЛОНКА «Читать, если» — формат строго `если <условие>: [file.md](file.md)`.
     Несколько условий разделяй точкой с запятой. Нечего поставить — ставь `—`.

     Условие ОБЯЗАНО проверяться по самой задаче или по факту, который агент уже
     видит: «если в задаче задан регион», «если выход — файл, а не ответ в чат»,
     «если вызов вернул ошибку», «если версия сервера ещё не снята».

     ЗАПРЕЩЕНЫ формулировки, отдающие решение на усмотрение читающего агента:
     «при необходимости», «если нужно», «опционально», «при желании»,
     «в сложных случаях», «для углубления». Такая колонка — разрешение не читать
     файл, а не условие его чтения: именно на ней агент пропускает процедуру,
     которая была нужна, и нарушает правила скилла.

     ПОМЕТКА `(справочник)` ставится после ссылки на файл, устроенный как таблица
     для точечного поиска: перечень кодов ошибок, справочник полей, каталог
     рецептов. Только для таких файлов допустим поиск нужной строки вместо чтения
     целиком. Файл, ведущий процедуру по шагам или задающий форму выхода,
     справочником НЕ является — пометку ему не ставь.

     Ссылки на файлы — ТОЛЬКО markdown-ссылки [file.md](file.md), НЕ backtick.
