# Формат выдачи

## Назначение

Из чего состоит результат: готовое сообщение, логика ответа и предупреждение о риске; плюс оформление под канал, куда уходит сообщение.

## Структура выдачи

```
**Ответ:**
[Готовое сообщение]

**Логика:** [1-2 предложения — почему именно так]
```

- **Ответ** — текст, который пользователь отправит как есть.
- **Логика** — 1-2 предложения о том, почему ответ построен так: какая задача, какой приём, какой тон.

## Проверка риска восприятия

Перед выдачей перечитать ответ глазами адресата.

- ЕСЛИ сообщение может быть воспринято негативно -> добавить предупреждение.
- ЕСЛИ риска нет -> блок предупреждения не добавлять.

```
⚠️ **Внимание:** [что может пойти не так / как может быть воспринято]
```

## Разметка под канал

- ЕСЛИ сообщение уходит в Telegram, Confluence, Jira или в Markdown -> синтаксис разметки брать из скилла skill-markup.
- Правила [ai-red-flags.md](ai-red-flags.md) действуют и в размеченном сообщении: разметка не повод для жирных подзаголовков.

## Примеры

### Пример 1: Отказ коллеге

**Вход:** коллега просит выйти вместо него на встречу с клиентом; инструкция — отказать, но мягко.

**Результат:**

**Ответ:**
Завтра не смогу, у меня презентация в то же время. Попробуй Олега, он в теме проекта.

**Логика:** Отказ с причиной + альтернатива, чтобы не оставлять коллегу без решения.
