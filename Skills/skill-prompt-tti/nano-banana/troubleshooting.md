# Nano Banana: неудачный результат

## Назначение

Таблица «симптом в результате → причина → что изменить» для моделей Nano Banana.

## Симптомы

| Симптом в результате | Причина | Что изменить |
|---|---|---|
| Ответ текстом, изображения нет | промпт неоднозначен для мультимодальной модели | просить изображение явно (`Generate an image of …`, `create an image of …`); в API — `response_modalities=['Image']` |
| Нужен был текст, а модель нарисовала его картинкой | модель может создать текст как изображение | явно просить текстовый ответ (`generate narrative text along with illustrations`) |
| Изображений не столько, сколько просили | модель не всегда выдаёт точное число изображений | просить изображения по одному (`generate one at a time`) |
| Черты персонажа уплывают после многих правок | накопление изменений в длинном диалоге | новый диалог с подробным описанием персонажа |
| Поза исходного объекта сохранилась при правке | известное ограничение Nano Banana 2.1 | описать новую позу подробнее; приложить референс позы |
| Перепутаны лево и право | известное ограничение Nano Banana 2.1 | обходной путь не описан; предупредить пользователя об ограничении |
| Мелкий текст размыт | известное ограничение Nano Banana 2.1, особенно в 1K | обходной путь не описан; предупредить пользователя об ограничении |
| Текст с ошибками | сложный или длинный текст в одном запросе; многоязычный текст может содержать грамматические ошибки | сначала получить текст, потом попросить изображение с ним; текст — в кавычках |
| Нарисован белый или иной фон вместо прозрачного | прозрачный фон не поддерживается | просить белый фон |
| Ошибка запроса при `imageSize` | строчная `k`, `512K` вместо `512`, значение не поддерживается моделью | `1K`, `2K`, `4K` с заглавной K, `512` без K; сверить с моделью в [parameters.md](parameters.md) |
| Ошибка 400 в многошаговом диалоге | не возвращены подписи рассуждения (в Google Cloud при `MINIMAL`) | возвращать подписи рассуждения без изменений; в SDK — режим чата |
| Ошибка API у 2.1 в Google Cloud | переданы `seed`, `topK`, `logprobs`, `temperature` или `topP` | убрать эти параметры |
| Модель остановилась, не закончив | известное поведение | повторить запрос или изменить промпт |
| Появилось то, что было запрещено через `no X` | отрицание в промпте | описать желаемую сцену утвердительно |

## Примеры

### Пример 1: картинки нет

**Вход:** «попросил „кот в шляпе на крыше“, а Gemini ответил стихотворением».

**Результат:** промпт начинается с `Generate an image of a cat wearing a top hat sitting on a tiled rooftop at sunset`; в API — `response_modalities=['Image']`.

### Пример 2: слово на вывеске с ошибкой

**Вход:** «на вывеске „Булочная“ ошибка в букве».

**Результат:** сначала в диалоге получить и утвердить текст вывески, затем попросить изображение с этим текстом в кавычках.
