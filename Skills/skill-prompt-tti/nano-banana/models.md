# Nano Banana: модели

## Назначение

Какие модели семейства Nano Banana (встроенная генерация изображений Gemini) покрывает скилл, их идентификаторы, статусы, различия возможностей и расхождения сведений о них.

Состояние на 2026-11-09.

- Модели изображений Gemini 3 перед генерацией рассуждают над сложными промптами.
- Nano Banana 2.1 улучшает качество изображения, отрисовку текста, согласованность в многошаговом диалоге и привязку к поиску Google в 1K, 2K и 4K; исправлены артефакты повторяющихся фрагментов на пропорциях 1:4, 4:1, 1:8, 8:1 при 2K и 4K.

## Nano Banana 2.1 и правила промпта

- Отдельных правил промпта для 2.1 нет: правила общие для семейства и лежат в [prompt-anatomy.md](prompt-anatomy.md).
- 2.1 отличается параметрами: три уровня рассуждения, нет 512px, в Google Cloud не поддерживаются `seed`, `topK`, `logprobs`, `temperature`, `topP` — любой из них возвращает ошибку API.
- Ограничения 2.1:
  - мелкий текст, длинные абзацы и целые страницы текста отрисовываются плохо, мелкий текст часто размыт в 1K;
  - модель иногда путает расположение, например лево и право;
  - при правке изредка сохраняется поза исходного объекта.

## Какая модель отвечает в приложении Gemini

Источники расходятся:

- одна позиция — Nano Banana 2 Lite, когда выбрана модель Gemini Flash-Lite; Nano Banana 2, когда выбрана модель Flash или Pro; Nano Banana Pro — для Redo with Pro с тарифом Google AI; Nano Banana 2.1 не названа;
- другая позиция — пользователям тарифов Google AI Pro, Plus и Ultra доступна Nano Banana 2.1 и перегенерация через Nano Banana Pro; бесплатно — Nano Banana 2.

Приложение Gemini названо среди каналов распространения Nano Banana 2.1. Какая модель отвечает конкретному пользователю — не установлено.

## Расхождения

| Предмет | Одна позиция | Другая позиция |
|---|---|---|
| Лимиты референсов у Nano Banana 2 | до 4 персонажей и до 10 объектов | до 5 персонажей и до 14 объектов |
| Пропорции 1:4, 4:1, 1:8, 8:1 у Pro | не поддерживаются: новые пропорции добавляют только 2.1 и 3.1 Flash Image, у Pro десять пропорций | поддерживаются: у Pro 14 пропорций, включая эти четыре |
| Отключение рассуждения у `gemini-3.1-flash-image` | рассуждение включено по умолчанию и в API не отключается | для поиска по картинкам указана работа и с включённым, и с выключенным рассуждением. Параметр отключения не показан нигде |
| Уровни рассуждения у Pro | только `HIGH`, по умолчанию `HIGH` (Google Cloud) | уровни для Pro не перечислены, умолчание зависит от модели (Gemini API) |
| 512px у Nano Banana 2 Lite | поддерживается | только 1K |
| Число пропорций у Nano Banana 2 Lite | заявлен набор из 14 пропорций | перечислены десять: `1:1`, `3:2`, `2:3`, `3:4`, `4:3`, `4:5`, `5:4`, `9:16`, `16:9`, `21:9` |

## Примеры

### Пример 1: модель названа по продукту

**Вход:** «промпт для Nano Banana Pro через API».

**Результат:** модель `gemini-3-pro-image`; уровень рассуждения не задаётся значением, отличным от `HIGH`, потому что допустимые уровни Pro расходятся между поверхностями; пропорции 1:4–8:1 не используются без оговорки о расхождении.

### Пример 2: приложение Gemini без уточнения тарифа

**Вход:** «напиши промпт для Nano Banana в приложении Gemini».

**Результат:** какая модель ответит, зависит от выбранной модели Gemini и тарифа, и сведения об этом расходятся; промпт пишется по общим правилам семейства из [prompt-anatomy.md](prompt-anatomy.md), без возможностей, которые есть не у всех моделей-кандидатов (512px, стилевые референсы, пропорции 1:4–8:1).
