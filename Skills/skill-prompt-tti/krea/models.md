# Krea: модели

## Назначение

Какие собственные модели Krea покрывает скилл — Krea 1, Krea 2 (Medium, Large, Turbo) и Krea 3, — чем они различаются, какая модель работает по умолчанию и какие сведения о них расходятся.

Состояние на 2026-11-09.

## Покрываемые модели

| Модель | Назначение | Где доступна |
|---|---|---|
| Krea 1 | самая креативная модель с поддержкой LoRA; сильна в художественном фотореализме и реалистичных текстурах | приложение; в API адреса нет |
| Krea 2 Medium | стабильный универсальный результат: иллюстрация, аниме, живопись, экспрессивные стили | приложение и API |
| Krea 2 Large | фотореализм, сырые текстуры, смаз движения, самый богатый результат; медленнее Medium | приложение и API |
| Krea 2 Turbo (Medium Turbo) | быстрый недорогой перебор экспрессивных иллюстраций и концептов | приложение и API |
| Krea 3 | новейшая модель Krea и модель по умолчанию в приложении; генерирует и правит в нативном 2K, сохраняя продукты, персонажей и текст | приложение (по умолчанию) и API |

- ЕСЛИ модель в приложении не названа -> по умолчанию Krea 3. В приложении есть режим Auto, который выбирает модель сам и может выбрать стороннюю; ЕСЛИ модель выбирает Auto -> какая модель ответит, не установлено.
- В API модель задаётся адресом запроса (в [surfaces.md](surfaces.md)); модели по умолчанию нет.
- Сторонние модели в приложении Krea (Nano Banana, Seedream, Flux, Qwen, Wan и другие) скиллом не описываются. FLUX.1 Krea убрана из приложения 2 ноября 2026 и не покрывается.

## Чем различаются

| Возможность | Krea 1 | Krea 2 Medium / Large | Krea 2 Turbo | Krea 3 |
|---|---|---|---|---|
| Логика промпта | скорее креативна, чем буквальна | естественный язык; расширение промпта регулирует Creativity | краткие промпты со стилем, палитрой и композицией | редактор по инструкции: изменение плюс фраза о сохранении |
| Нативное разрешение | позиции ниже | 1K | 1K | 2K |
| Изображений за генерацию | до 4 | до 4 | до 4 | у `ultra` — одно; для других режимов не указано |
| Стилевые референсы | до 3, ползунок веса стиля | до 4, сила каждого | до 4 | нет: стилевые референсы и LoRA из API Krea 2 пока не поддерживаются |
| Мудборды, генеративные ползунки | нет | да | да | нет |
| Референсы для правки | Image prompt | Image prompt | — | до 8 (позиции ниже), называются по содержанию |
| Управление буквальностью | переключатель Raw | Creativity: Raw, Low, Medium, High | Creativity | `thinking_mode`: `fast`, `high`, `ultra` |
| Негативный промпт | не описан | нет | нет | позиции в [parameters.md](parameters.md) |

- Krea 2 Medium против Large: Medium меньше и быстрее, сильное дообучение делает результат особенно стабильным от генерации к генерации; Large больше Medium более чем вдвое, дообучение мягче, результат сырее, фактурнее и гибче — сильнее всего в фотореализме, сыром виде (смаз, зерно, низкий динамический диапазон) и экспрессивных стилях.
- Krea 2 Turbo уступает Medium и Large, когда важнее всего точное следование стилю и чистовая отделка.
- Krea 1 не подходит, когда нужны точные структурированные композиции с точной анатомией, фотографический реализм без художественной интерпретации или буквальный технический результат.
- Krea 3 унаследовала от Krea 2 чувство стиля: работает с живописью, векторной графикой и рисунками тушью и оставляет их в собственной технике. Krea 3 быстрая, но пока не в реальном времени.

## Одноимённые настройки Raw

- Raw у Krea 1 — переключатель вкл/выкл, ослабляющий эстетическое смещение модели (описание — в [parameters.md](parameters.md)).
- Raw у Krea 2 — значение Creativity без расширения промпта: модель рисует только явно описанное.
- Связаны ли эти механизмы — не установлено.

## Расхождения

| Предмет | Одна позиция | Другая позиция |
|---|---|---|
| Разрешение Krea 1 | нативно 1.5K с увеличением до 4K | максимум 4096 |
| Число референсов Krea 3 | до 6 на правку | до 8 |
| Разрешение Krea 3 | в приложении — 1K или 2K | в API — `1K`, `2K`, `4K`; `4K` получается из 2K увеличением в 2 раза |
| Варианты Krea 2 в API | два варианта — Medium и Large | три адреса, включая `krea-2/medium-turbo` |
| Перенос стиля | только у Krea 1 | до 4 стилевых референсов у всех вариантов Krea 2 |
| Флагманская модель | Krea 1 названа флагманом | Krea 3 — модель по умолчанию |

## Примеры

### Пример 1: модель не названа

**Вход:** «промпт для Krea: поменять фон у фото товара».

**Результат:** в приложении по умолчанию Krea 3 — промпт пишется как инструкция правки по правилам Krea 3 из [prompt-anatomy.md](prompt-anatomy.md).

### Пример 2: Krea 3 со стилевым референсом

**Вход:** «Krea 3 с моим стилевым референсом на 60 %».

**Результат:** стилевых референсов у Krea 3 нет; взвешенный стилевой референс есть у Krea 2 (подробности в [style-controls.md](style-controls.md)); у Krea 3 картинка подаётся как референс правки с объяснением, что из неё взять.
