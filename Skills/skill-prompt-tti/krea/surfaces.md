# Krea: поверхности

## Назначение

Где работают собственные модели Krea — приложение Krea и API Krea, — что меняется на каждой поверхности, как поверхность обрабатывает промпт и в какой форме выдаётся готовый результат.

## Приложение Krea

- Инструмент Image — генерация; инструмент Edit — правка (подробности в [editing.md](editing.md)).
- Модель по умолчанию — Krea 3; режим Auto сам выбирает модель под промпт и тариф.
- Промпт может быть коротким или подробным; для большинства моделей описание объекта, обстановки, света и настроения даёт более точный результат.
- Настройки по моделям:

| Модель | Настройки |
|---|---|
| Krea 1 | Aspect ratio, Image style, Style, Image prompt, Raw |
| Krea 2 Turbo | Aspect ratio, Image style, Style |
| Krea 3 | Aspect ratio, Image prompt, Character reference |

- Image prompt: в большинстве моделей композиция, цвет и стиль загруженного изображения смешиваются с текстовым промптом; в моделях с рассуждением на изображение ссылаются прямо в промпте. У Krea 3 изображения — референсы правки, на них ссылаются в промпте по содержанию.
- Share parameters создаёт ссылку, по которой другие точно воспроизведут генерацию.
- Поле негативного промпта для Krea 1 и Krea 2 в приложении не описано.

## API Krea

- Адреса собственных моделей: `/generate/image/krea/krea-2/medium`, `/generate/image/krea/krea-2/large`, `/generate/image/krea/krea-2/medium-turbo`, `POST /generate/image/krea/krea-3`. Адреса для Krea 1 нет.
- У Krea 3 неподдерживаемые поля (`model`, `steps`, `fast`) возвращают ошибку `422` с `Unrecognized key`; поля `loras` и `style_urls` тоже возвращают `422` — LoRA и стилевые референсы в API Krea 3 пока не поддерживаются.
- У Krea 3 обязательны `resolution` или пара `width` и `height`; без них ответ — `Provide resolution or width and height.`
- Параметры по моделям — в [parameters.md](parameters.md).

## Что делает поверхность с промптом

- Krea 2: перед генерацией короткий промпт расширяется языковой моделью. Если промпт короткий или расплывчатый, модель достраивает недостающее — стиль, композицию, ракурс, палитру, — а `creativity` задаёт, насколько свободно (`raw` — без расширения).
- Krea 3: перед генерацией интерпретирует промпт; `thinking_mode` задаёт объём планирования. При `fast` промпт быстро расширяется, затем идёт генерация.
- Krea 1: в строке промпта есть инструмент translate prompts; что он делает, не установлено.

## Форма готового результата

| Поверхность | Форма |
|---|---|
| Приложение, Krea 1 и Krea 2 | текст промпта плюс настройки: соотношение сторон, Raw (Krea 1) или Creativity (Krea 2), стилевые референсы, мудборд, ползунки |
| Приложение, Krea 3 | текст инструкции плюс референсы и соотношение сторон, разрешение 1K или 2K |
| API, Krea 2 | JSON: `prompt`, `aspect_ratio`, `resolution`, `creativity`, при необходимости `image_style_references`, `moodboards`, `intensity`, `complexity`, `movement`, `seed` |
| API, Krea 3 | JSON: `prompt`, `image_urls`, `resolution` (или `width` и `height`), `aspect_ratio`, `thinking_mode`, при необходимости `regions`, `regional_edit` |

## Примеры

### Пример 1: Krea 2 через API

**Вход:** «иллюстрация 16:9 через API Krea 2 Medium, точно по промпту».

**Результат:** адрес `/generate/image/krea/krea-2/medium`, `{"prompt": "...", "aspect_ratio": "16:9", "resolution": "1K", "creativity": "raw"}`.

### Пример 2: Krea 3 без разрешения

**Вход:** запрос к Krea 3 только с `prompt` и `image_urls`.

**Результат:** добавлен `resolution` (`1K`, `2K` или `4K`) — без него или без `width` и `height` запрос отклоняется.
