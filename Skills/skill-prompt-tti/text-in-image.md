# Текст на изображении

## Назначение

Общее для пяти моделей правило записи текста, который должен появиться на изображении, и перечень отклонений отдельных моделей со ссылками на их файлы.

## Общее правило

1. Текст для изображения пишется дословно — теми словами и буквами, которые должны быть на картинке.
2. Текст пишется на том языке, на котором он должен быть на изображении: надпись по-русски — кириллицей, по-японски — японскими знаками.
3. Текст берётся в кавычки.
4. Промпт вокруг текста остаётся английским.

Пример: `a vintage tin sign on a brick wall that says "Свежий хлеб"`

## Отклонения моделей

| Модель | Отклонение | Где подробности |
|---|---|---|
| Midjourney | только двойные кавычки, одинарные не работают; латиница надёжнее; короткие слова и фразы точнее | [midjourney/prompt-anatomy.md](midjourney/prompt-anatomy.md) |
| Nano Banana | сначала получить текст, потом изображение с ним; многоязычный текст может содержать грамматические ошибки; шрифт описанием или названием | [nano-banana/prompt-anatomy.md](nano-banana/prompt-anatomy.md) |
| GPT Image | кавычки или ЗАГЛАВНЫЕ; редкие слова по буквам; сколько раз текст должен появиться; запрет лишнего текста; для мелкого текста — `quality` `medium` или `high` | [gpt-image/prompt-anatomy.md](gpt-image/prompt-anatomy.md) |
| Seedream | двойные кавычки; языки текста на изображении у 5.0 pro; мелкий текст — ограничение 5.0 pro | [seedream/prompt-anatomy.md](seedream/prompt-anatomy.md) |
| Krea | текст прописывать явно; у Krea 3 нативный 2K улучшает текст, в 1K мелкий текст теряется | [krea/prompt-anatomy.md](krea/prompt-anatomy.md) |

## Примеры

### Пример 1: надпись на английском

**Вход:** «постер с надписью SUMMER SALE».

**Результат:** `... a bold poster with the words "SUMMER SALE" at the top ...`; дальше — правила текста выбранной модели из таблицы отклонений.

### Пример 2: надпись на русском

**Вход:** «упаковка чая с надписью «Иван-чай»».

**Результат:** промпт на английском, надпись дословно кириллицей в кавычках: `a kraft paper tea package with the label text "Иван-чай"`; предупреждения о надёжности нелатинского или многоязычного текста — по файлу выбранной модели.
