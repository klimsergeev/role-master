# GPT Image: неудачный результат

## Назначение

Таблица «симптом в результате → причина → что изменить» для моделей GPT Image.

## Симптомы

| Симптом в результате | Причина | Что изменить |
|---|---|---|
| Сохраняемые детали дрейфуют от правки к правке | повторные правки могут менять сохраняемое | повторять список сохраняемого в каждом промпте, одно изменение за раз; для пиксельной неизменности — вклеить одобренную правку в оригинал |
| Вместо прозрачности нарисован фон | описание фона в промпте важнее `background="transparent"` | убрать описание фона, описать изолированный объект, явно попросить прозрачный фон; `png` или `webp` |
| Вместо прозрачности нарисована шахматка | нарисованная шахматка — не прозрачность | явно запретить шахматку (`no checkerboard`), проверить, есть ли в файле прозрачные пиксели |
| Прозрачность не получилась при `jpeg` | `jpeg` прозрачность не поддерживает | `output_format` `png` или `webp` |
| Мелкий текст нечитаем при верной раскладке | недостаточно деталей отрисовки | сравнить `quality` (`medium`, `high`, у 2.5 и 2.6 — `xhigh`, `max`) при той же `complexity` |
| Лишний текст на изображении | не задан запрет | `No extra text`, точный текст в кавычках с числом повторений |
| Правка вышла за выделенную область в ChatGPT | выделение не всегда точно | назвать область словами в промпте и перечислить, что вокруг не меняется |
| Маска не удержала границу | маска — ориентир, а не трафарет | описать в промпте всё итоговое изображение и сохраняемое; для пиксельной точности — вклейка в оригинал |
| Правка затронула не то изображение | маска и разметка применяются к первому входному изображению | поставить правимое изображение первым |
| Модель перерисовала персонажа в новой сцене | постоянство персонажей между генерациями удерживается не всегда | эталонное изображение персонажа на входе, повтор определяющих черт, `Do not redesign the character` |
| Промпт в Responses API получился не таким, как отправлен | основная модель переписывает промпт | сверить `revised_prompt`; для неизменного промпта — Image API |
| Ошибка запроса из-за параметра | переданы `input_fidelity` (модели 2 и новее), `style`, `response_format`, `complexity` не модели 2.6, `markup` вместе с `mask`, принудительный `edit` без изображения | сверить с [parameters.md](parameters.md) |
| Неточные числа и подписи на графике или слайде | сгенерированный график — растровая картинка | проверять каждое число и подпись; для точной отчётности строить графики программно |

## Примеры

### Пример 1: у товара появился серый фон

**Вход:** «просил прозрачный фон, а пришёл серый».

**Результат:** из промпта убрано описание студийного фона; промпт описывает только изолированный товар и явно просит `fully transparent background`; `background="transparent"`, `output_format="png"`.

### Пример 2: логотип на банке изменился после третьей правки

**Вход:** «после серии правок буквы логотипа поплыли».

**Результат:** в каждом промпте правки повторяется `preserve the logo and label text exactly`; после одобрения область логотипа вклеивается в исходник.
