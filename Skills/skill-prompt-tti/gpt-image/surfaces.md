# GPT Image: поверхности

## Назначение

Где работают модели GPT Image на собственных площадках OpenAI — Image API, Responses API, ChatGPT, Codex, — как на каждой задаются модель, параметры и референсы, переписывается ли промпт и в какой форме выдаётся результат.

## Image API

- Два метода: генерация с нуля по тексту (`/v1/images/generations`) и правка существующих изображений целиком или частично (`/v1/images/edits`).
- Модель изображений ставится прямо в поле `model`.
- Для одного изображения по одному промпту лучший выбор — Image API.
- Правка принимает JSON: поле `images` (и необязательное `mask`) со ссылками `image_url` или `file_id`.
- Правка по разметке `markup` — только в Image API, методом `/v1/images/edits`.
- Переписывание промпта: поле ответа `revised_prompt` моделями GPT Image не возвращается. Переписывается ли промпт — не установлено.
- С маской сервер добавляет к промпту свои инструкции, помогающие направить правку.
- Ответ — всегда base64.

## Responses API (инструмент `image_generation`)

- Для диалогового редактирования изображений — Responses API.
- На верхний уровень ставится основная языковая модель, модель изображений — в поле `model` инструмента. Модели `gpt-5` и новее должны поддерживать инструмент генерации изображений.
- С инструментом в запросе основная модель сама решает, когда и как генерировать изображения. Принудительный вызов — `tool_choice` = `{"type": "image_generation"}`.
- `action`: `auto` (по умолчанию) — модель выбирает между генерацией и правкой; `generate` или `edit` — принудительно. Принудительный `edit` без изображения в контексте даёт ошибку.
- Переписывание промпта: основная языковая модель автоматически переписывает промпт; переписанный промпт возвращается в поле `revised_prompt` вызова генерации. Параметра для отключения переписывания нет.
- Пример переписывания: исходный `Generate an image of gray tabby cat hugging an otter with an orange scarf` превращён в `A gray tabby cat hugging an otter. The otter is wearing an orange scarf. Both animals are cute and friendly, depicted in a warm, heartwarming style.` Переписанный промпт добавил оценки стиля, которых в исходном не было.
- Многошаговая правка: передать результат вызова в контекст, сослаться на ID изображения или использовать `previous_response_id`.
- Входные изображения: полный URL, data URL в base64 или ID файла (Files API).
- Локальная правка — маской `input_image_mask`; правка по разметке в Responses API не описана.
- Модели 2.6 в инструменте — расхождение, позиции в [models.md](models.md).

## ChatGPT

- Продукт — ChatGPT Images 2.6; какая модель API за ним стоит, не установлено ([models.md](models.md)).
- Описанного способа отключить переписывание промпта в ChatGPT нет.
- Режим с размышлением добавляет к генерации рассуждение и инструменты: веб-поиск, несколько изображений из одного промпта, доработку простого промпта до продуманного изображения. Режим доступен на тарифах Plus, Pro и Business.
- Правка двумя способами: выделить часть изображения и описать изменение в чате или описать правку прямо в диалоге без выделения. ЕСЛИ правка касается определённой области -> назвать её в промпте.
- Выделение не всегда точно, правка может выйти за его пределы.
- В приложении в Canvas view есть комментарии к одному или нескольким изображениям (Comment) и множественный выбор (Multi-select).
- Сохранённый референс: загрузить фото, попросить сохранить его как референс и в другом чате вызывать через @ и имя, например `Make a watercolor portrait of @Pepper`.
- Эскиз (мобильное приложение): в поле сообщения набрать @ и выбрать Sketch; пример промпта — `Turn this sketch into a watercolor painting of a red house surrounded by trees.`
- Шаблоны (постер, логотип и другие) дают отправную точку для изображения.
- Пропорции выбираются переключателем или пишутся в промпте.
- Генерация может занять несколько минут в зависимости от сложности запроса.

## Codex

- `$imagegen` в промпте явно вызывает генерацию изображения.
- В CLI изображение прикладывается флагом `-i` или `--image`.
- Модель в Codex — расхождение, позиции в [models.md](models.md).

## Форма готового результата

| Поверхность | Форма |
|---|---|
| Image API, генерация | `model`, `prompt` и параметры запроса (`size`, `quality`, `complexity`, `background`, `output_format`) |
| Image API, правка | то же плюс `images`, при необходимости `mask` или `markup` |
| Responses API | основная модель, текст сообщения с промптом, инструмент `{"type": "image_generation", "model": …, параметры}`, при необходимости `tool_choice` и `action` |
| ChatGPT, Codex | текст промпта; пропорции — словами или переключателем; референсы — вложением или @имя |

## Примеры

### Пример 1: промпт без переписывания

**Вход:** «нужно, чтобы промпт ушёл в модель как есть».

**Результат:** Image API с моделью в `model`: `revised_prompt` моделями GPT Image не возвращается; в Responses API промпт переписывает основная модель, и отключить это параметром нельзя — результат проверяется по `revised_prompt`.

### Пример 2: правка по пометке в Responses API

**Вход:** «обвёл область красным и хочу отправить через Responses API как `markup`».

**Результат:** правка по разметке описана только для `/v1/images/edits` в Image API; в Responses API локальная правка делается маской `input_image_mask`.
