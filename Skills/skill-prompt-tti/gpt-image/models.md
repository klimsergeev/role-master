# GPT Image: модели

## Назначение

Какие модели GPT Image покрывает скилл, их идентификаторы и статусы, чем различаются Sunburst и Flare, что появилось в каждой версии и какие сведения о моделях расходятся.

Состояние на 2026-11-09.

## Покрываемые модели

| Модель | Назначение | Снимок по умолчанию | Выпуск |
|---|---|---|---|
| `gpt-image-2.6-sunburst` | генерация и правка для детальной визуальной работы | `gpt-image-2.6-sunburst` | 4 ноября 2026 |
| `gpt-image-2.6-flare` | генерация и правка для быстрой итерации | `gpt-image-2.6-flare` | 4 ноября 2026 |
| `gpt-image-2.5-sunburst` | самая способная модель генерации и правки версии 2.5 | `gpt-image-2.5-sunburst-2026-09-08` | 8 сентября 2026 |
| `gpt-image-2.5-flare` | быстрая качественная повседневная генерация | `gpt-image-2.5-flare-2026-09-08` | 8 сентября 2026 |
| `gpt-image-2` | модель генерации изображений второго поколения | `gpt-image-2-2026-04-21` | 21 апреля 2026 |

- Не покрываются: `gpt-image-1.5`, `gpt-image-1-mini`, `chatgpt-image-latest` (выводятся из API 1 декабря 2026), `gpt-image-1` (выключена 23 октября 2026), DALL·E 2 и DALL·E 3 (выведены 12 мая 2026). Синтаксис и значения для них здесь не приводятся.
- ЕСЛИ в Image API модель не названа -> в правке (`/v1/images/edits`) по умолчанию `gpt-image-2.5-sunburst`; в генерации (`/v1/images/generations`) модель указывается явно; в инструменте `image_generation` Responses API по умолчанию `gpt-image-2`.

## Sunburst и Flare

- Sunburst — для задач, где важнее всего точность правки; Flare — для быстрой качественной повседневной генерации.
- В версии 2.6 Sunburst даёт более качественную генерацию и лучше сохраняет детали при правке на среднем или высоком уровне качества; Flare оптимизирована под более быструю генерацию.
- Выбор между Sunburst и Flare делается полем `model` и описан только для API.

## Что появилось по версиям

| Возможность | `gpt-image-2` | 2.5 Sunburst и Flare | 2.6 Sunburst и Flare |
|---|---|---|---|
| Гибкие размеры `WIDTHxHEIGHT` | да | да | да |
| Входные изображения всегда в высокой точности (`input_fidelity` не передаётся) | да | да | да |
| Прозрачный фон | в предварительном режиме с 20 августа 2026 | да | да |
| `quality` `xhigh` и `max` | нет | да | да |
| Правка по разметке `markup` | нет | да (добавлена 4 ноября 2026) | да |
| `complexity` — объём планирования | нет | нет | да |

Генерация SVG и анимированных GIF у моделей 2.6 скиллом не покрывается.

## ChatGPT Images 2.6

- В ChatGPT работает продукт ChatGPT Images 2.6: он генерирует быстрее и лучше удерживает детали от правки к правке.
- Какая модель API (`gpt-image-2.6-sunburst` или `gpt-image-2.6-flare`) работает в ChatGPT и как выбирается — не установлено. Выбор Flare или Sunburst описан только для API.
- В чате пользователь управляет усилием рассуждения через выбор модели — это меняет скорость генерации и правки.

## Расхождения

| Предмет | Одна позиция | Другая позиция |
|---|---|---|
| Модель в Codex | Images 2.6 доступна в ChatGPT и Codex | встроенная генерация изображений в Codex использует `gpt-image-2` |
| Модели 2.6 в инструменте `image_generation` Responses API | перечислены среди допустимых моделей инструмента, вместе с параметром `complexity` | в перечне моделей инструмента 2.6 нет, возможности моделей 2.6 описаны только для Image API; у моделей 2.6 строка Responses отмечена как неподдерживаемая (та же отметка стоит у 2.5, которая в инструменте работает) |

## Примеры

### Пример 1: модель названа продуктом

**Вход:** «промпт для GPT Image 2.6 через API, нужна точная правка этикетки».

**Результат:** модель уточняется у пользователя — `gpt-image-2.6-sunburst` или `gpt-image-2.6-flare`; назначение Sunburst — точность правки, но выбор модели остаётся за пользователем.

### Пример 2: запрос под выводимую модель

**Вход:** «промпт для `gpt-image-1.5` с `input_fidelity: high`».

**Результат:** `gpt-image-1.5` скиллом не покрывается (выводится 1 декабря 2026); синтаксис моделей 2 и новее за синтаксис 1.5 не выдаётся.
