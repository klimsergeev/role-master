# Seedream: неудачный результат

## Назначение

Таблица «симптом в результате → причина → что изменить» для Seedream 5.0 pro и 5.0 flash.

## Симптомы

| Симптом в результате | Причина | Что изменить |
|---|---|---|
| Элемент из промпта пропал | промпт перегружен: слишком длинный промпт рассеивает информацию, модель упускает детали и держится главного | краткий точный промпт вместо нагромождения; не больше 600 английских слов |
| Текст не тот или с ошибками | текст не выделен | нужный текст дословно в двойных кавычках |
| Мелкий текст неразборчив | ограничение 5.0 pro в отрисовке мелкого текста | предупредить пользователя об ограничении |
| Правка задела лишнее | не сказано, что сохранить | прямо назвать, что не менять (`keeping its pose unchanged`, `Keep the composition unchanged`) |
| Правка задела соседний объект в рамке | в рамке несколько объектов | назвать цель внутри рамки (`the person on the left`), остальное защитить рамкой с `keep unchanged` |
| Правка ушла не туда при местоимении | расплывчатое местоимение (`that one`) | назвать объект признаками (`the tallest panda`) |
| Пометки от руки остались на результате | промпт не просит их убрать | добавить `Remove all sketch lines` |
| Параметр не сработал или запрос отклонён | перенесён синтаксис других моделей (`--ar`, `--seed`, негативный промпт, веса референсов) — в API их нет | соотношение сторон — словами в промпте или `size`; остальное убрать |
| Серия не получилась одним запросом | серии у 5.0 pro и flash не поддерживаются | отдельные запросы с референсом персонажа |
| Изображение выглядит не так, как описано списком слов | промпт из ключевых слов через запятую | заменить связным описанием «объект + действие + окружение» |
| Ссылка на результат не открывается | ссылка `url` живёт 24 часа | скачивать сразу или запрашивать `b64_json` |
| Разложение на слои упало целиком | не получился один из слоёв или запрошено больше 16 слоёв | меньше слоёв, проверить вход (png или jpeg, от 512×512) |

## Примеры

### Пример 1: потерялись предметы на полке

**Вход:** «в длинном промпте про витрину пропали половина предметов».

**Результат:** промпт сокращён до объекта, действия и окружения; предметы перечислены по полкам с положением (`Top shelf: on the left…`).

### Пример 2: `--ar 16:9` в промпте

**Вход:** «написал в конце `--ar 16:9`, а картинка квадратная».

**Результат:** `--ar` в API Seedream нет; соотношение написано словами (`A 16:9 horizontal …`) при `size` = `2K`.
