# Seedream: параметры

## Назначение

Параметры API BytePlus ModelArk и Volcano Engine для Seedream 5.0 pro и 5.0 flash: значения, умолчания, размеры, входные изображения и параметры, которых у этих моделей нет.

Состояние на 2026-11-09.

## Параметры запроса

| Параметр | Тип и умолчание | Значения и правила |
|---|---|---|
| `model` | string, обязателен | идентификатор модели или эндпоинта (в [models.md](models.md)) |
| `prompt` | string | обязателен для генерации; необязателен для разложения на слои |
| `image` | string или string[] | URL или `data:image/<image format>;base64,<Base64 encoding>` (формат строчными); до 10 изображений |
| `size` | string | метод 1 — уровень `1K`, `1.5K`, `2K` (по умолчанию `2K`); метод 2 — `widthxheight`; методы смешивать нельзя |
| `optimize_prompt_options.mode` | string, `standard` | `standard`, `fast`; `fast` — только 5.0 pro, у 5.0 flash пока не поддерживается |
| `output_format` | string, `jpeg` | `png`, `jpeg` |
| `background` | string, `opaque` | `transparent`, `opaque`; только при генерации по одному входному изображению с альфа-каналом, вывод `png` |
| `layer_decomposition` | boolean, `false` | `true` включает разложение на слои (подробности в [editing.md](editing.md)) |
| `response_format` | string, `url` | `url` — ссылка действует 24 часа после генерации, изображение нужно скачать сразу; `b64_json` |

## Размер

### Метод 1: уровень разрешения

- Задаётся уровень разрешения, а соотношение сторон, форма или назначение описываются в промпте словами; итоговый размер выбирает модель.
- Соответствие размеров (выборка): 1K 1:1 — 1024x1024, 1K 16:9 — 1424x800, 1.5K 1:1 — 1536x1536, 1.5K 16:9 — 2048x1152, 2K 1:1 — 2048x2048, 2K 16:9 — 2816x1584, 2K 21:9 — 3136x1344. Поддерживается больше соотношений, чем перечислено.
- Уровень `1.5K` даёт лучшее качество изображения, чем `1K`.

### Метод 2: `widthxheight`

- Общее число пикселей — от `1280x720` (921,600) до `2048x2048x1.1025` (4,624,220); соотношение сторон — от 1/16 до 16.
- Умолчание для этого метода — позиции в [models.md](models.md).

## Входные изображения

- Форматы: jpeg, png, webp, bmp, tiff, gif, heic, heif.
- Соотношение сторон — от 1/16 до 16; ширина и высота больше 14 пикселей; размер файла до 30 МБ; общее число пикселей от 196 до `6000×6000` (36,000,000).
- Для разложения на слои — только png и jpeg, от `512×512` пикселей, ровно одно изображение.

## Чего у 5.0 pro и flash нет

- Серии, потоковый вывод и поиск в интернете не поддерживаются: `sequential_image_generation`, `sequential_image_generation_options`, `stream`, `tools` не передаются.
- Отдельного параметра соотношения сторон, сида, негативного промпта, весов референсов, `guidance_scale` нет.

## Расхождения

- Умолчание размера в методе 2 у 5.0 pro и разрешение 4K у серии 5.0 — позиции в [models.md](models.md).

## Примеры

### Пример 1: квадрат в 1.5K

**Вход:** «квадратная карточка товара, Seedream 5.0 flash».

**Результат:** `"size": "1.5K"`, в промпте `square 1:1 product card …`; `"output_format": "png"`.

### Пример 2: запрос с `seed`

**Вход:** «зафиксируй `seed: 42`, чтобы повторить результат».

**Результат:** параметра сида у 5.0 pro и flash нет; `seed` не передаётся, а число в тексте промпта сидом не является.
