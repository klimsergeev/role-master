# Seedream: модели

## Назначение

Какие модели Seedream покрывает скилл — 5.0 pro и 5.0 flash, — их идентификаторы на BytePlus ModelArk и Volcano Engine, различия возможностей и расхождения сведений о них.

Состояние на 2026-11-09.

## Покрываемые модели

| Модель | BytePlus ModelArk | Volcano Engine | Назначение |
|---|---|---|---|
| Seedream 5.0 pro | `dola-seedream-5-0-pro-260628` (название — Dola Seedream 5.0 pro) | `doubao-seedream-5-0-pro-260628` (название — Doubao Seedream 5.0 pro) | более высокое качество изображения |
| Seedream 5.0 flash | `dola-seedream-5-0-flash-260915` | `doubao-seedream-5-0-flash-260915` | быстрее и дешевле |

- Seedream 5.0 pro выпущена 08.07.2026.
- В поле `model` запроса передаётся идентификатор модели или идентификатор эндпоинта; модели по умолчанию нет — модель задаётся явно.
- Не покрываются: Seedream 5.0 lite, 5.5, 4.5, 4.0, 3.0 и более ранние. Синтаксис и значения для них здесь не приводятся.

## Возможности 5.0 pro и 5.0 flash

| Возможность | 5.0 pro | 5.0 flash |
|---|---|---|
| Разрешения (`size`, уровень) | `1K`, `1.5K`, `2K` | `1K`, `1.5K`, `2K` |
| Интерактивная правка по координатам и пометкам | да | да |
| Разложение на слои (`layer_decomposition`) | да | да |
| Формат вывода | `png`, `jpeg` | `png`, `jpeg` |
| Режим `fast` у `optimize_prompt_options` | да | нет |
| Входные изображения | до 10 | до 10 |
| Языки промпта | китайский, английский и ещё 14 | китайский, английский и ещё 14 |
| Серии изображений, поиск в интернете, потоковый вывод | пока не поддерживаются | пока не поддерживаются |

- Направления 5.0 pro: сложная визуализация информации; интерактивная точная правка — свободное сочетание выбора точкой, лассо, отрисовки по наброску, замены цвета и материала, разделения на слои и смешения нескольких изображений; реалистичность и текстура кожи; нативный ввод и генерация на нескольких языках.
- Ограничения 5.0 pro: отрисовке мелкого текста и согласованности правок на уровне пикселей ещё есть куда расти.

## Доработка промпта

- В API есть `optimize_prompt_options` — настройки оптимизации промпта, режимы `standard` (по умолчанию) и `fast` (только 5.0 pro).
- Для Seedream 4.0 описана отдельная модель доработки промпта: она выбирает тип задачи, переписывает промпт (с автоматическим рассуждением) и подбирает оптимальное соотношение сторон. Распространяется ли она на 5.0 pro и flash — не установлено.

## Расхождения

| Предмет | Одна позиция | Другая позиция |
|---|---|---|
| Разрешение 4K у серии 5.0 | у 5.0 pro и flash уровни `1K`, `1.5K`, `2K` | серия Dola-Seedream-5.0 теперь выдаёт изображения 4K, без уточнения, о какой модели серии речь |
| Умолчание размера в формате `widthxheight` у 5.0 pro | `1024x1024` | умолчание для этого формата не названо; для уровня разрешения — `2K` |

## Примеры

### Пример 1: модель названа без варианта

**Вход:** «промпт для Seedream 5.0 через API BytePlus».

**Результат:** в охвате два варианта — 5.0 pro (`dola-seedream-5-0-pro-260628`) и 5.0 flash (`dola-seedream-5-0-flash-260915`); вариант уточняется у пользователя; промпт пишется по общим для обоих правилам, без режима `fast`, который есть только у pro.

### Пример 2: серия кадров

**Вход:** «сделай через Seedream 5.0 pro серию из шести кадров комикса одним запросом».

**Результат:** серии у 5.0 pro не поддерживаются; `sequential_image_generation` не передаётся; кадры делаются отдельными запросами, персонаж удерживается референсами и правкой (подробности в [references.md](references.md)).
