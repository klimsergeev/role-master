# Midjourney: параметры

## Назначение

Параметры Midjourney V8.1 и V8.2 со значениями, умолчаниями и оговорками, правила их записи, перестановки и повторы.

Состояние на 2026-11-09.

## Правила записи

1. Параметры идут после текста промпта.
2. Между текстом и дефисами — пробел.
3. В параметрах нет запятых, точек и другой пунктуации.

| Ошибка | Почему ошибка |
|---|---|
| `vibrant California poppies--ar 2:3` | нет пробела перед дефисами |
| `vibrant California poppies - - ar 2:3` | лишний пробел между дефисами |
| `vibrant California poppies --ar 2:3,` | пунктуация в параметре |
| `vibrant California --ar 2:3 poppies` | текст после параметров |

## Параметры V8.1 и V8.2

| Параметр | Значения и умолчание | Оговорки |
|---|---|---|
| `--aspect` / `--ar` | по умолчанию 1:1; формат `#:#`; большее первое число — горизонталь, большее второе — вертикаль | дробные числа не принимаются: `139:100` вместо `1.39:1`; 1920:1080 упрощается до 16:9; очень широкие и высокие соотношения экспериментальны и могут давать непредсказуемый результат; максимум 14:1, для HD — 4:1 |
| `--stylize` / `--s` | по умолчанию 100, диапазон 0–1000 | низкий — ближе к промпту; высокий — больше художественной свободы, изображение может отойти от деталей промпта; при персонализации и мудбордах управляет их силой; в Discord есть пресеты, по умолчанию Stylize med |
| `--chaos` / `--c` (на сайте — Variety) | по умолчанию 0, диапазон 0–100 | чем выше, тем сильнее различаются четыре изображения и тем слабее держится промпт |
| `--weird` / `--w` | по умолчанию 0, до 3000 | экспериментальный; не полностью совместим с seed; на сайте Alpha ползунок исправлен: 50 % соответствует 228, а не 1500 |
| `--raw` | флаг или раздел Model в настройках | выключает творческий штрих Midjourney: с простыми промптами чаще фотоподобный результат, с подробными стилистическими — точнее контроль вида |
| `--no` | перечень через запятую | равен весу −0,5; на сайте Alpha ввод вида `--no a, b` теперь читает весь список |
| `--seed` | целое от 0 до 4294967295; без него каждый раз случайный | в V8.X результат с тем же seed идентичен примерно на 99 %; не сохраняет стиль, персонажа или внешность между разными промптами; может вести себя непредсказуемо между сессиями |
| `--tile` | флаг | одна плитка бесшовного узора; швы между плитками в V8.1 и V8.2 убраны; апскейл часто ломает бесшовность; несовместим с моделью редактирования; при прикреплённом изображении сайт сообщает о несовместимости |
| `--exp` | поддерживается в V8.1 и V8.2 | диапазон, умолчание и взаимодействие со `--stylize` для V8 не установлены; на сайте Alpha закрепляется как умолчание папки |
| `--hd` / `--sd` | HD — 2048 px, SD — 1024 px (для 1:1 в V8.2: 2048 × 2048 и 1024 × 1024) | в HD максимум соотношения 4:1; дорисовка HD-изображения даёт SD |
| `--draft` | флаг или кнопка Draft | источники расходятся о Draft в V8.2 — позиции в [models.md](models.md); где Draft работает: один промпт — 24 изображения 512 × 512 px, Vary и Remix перерисовывают выбранное в SD или HD по настройкам; только на сайте |
| `--fast`, `--relax` | скорость GPU на один промпт | в Relax не работают перестановки и `--repeat` |
| `--turbo` | — | источники расходятся о Turbo в V8 — позиции в [models.md](models.md) |
| `--repeat` / `--r` | Basic 2–4, Standard 2–10, Pro и Mega 2–40 | только Fast и Turbo; параметр вырезается из итогового промпта |
| `--iw` | по умолчанию 1; в V8.1 — 0–3 | диапазон для V8.2 отдельно не установлен; подробности в [references.md](references.md) |
| `--sref` | URL изображения, код или `random` | подробности в [references.md](references.md) |
| `--sw` | 0–1000, по умолчанию 100 | несовместим с мудбордами |
| `--sv` | значения и умолчание для V8.1 и V8.2 не установлены | несовместим с мудбордами; подробности в [references.md](references.md) |
| `--profile` / `--p` | без значения — профили по умолчанию; `--p pID`, `--p mID` | подробности в [references.md](references.md) |
| `--edit` | URL изображений (Discord) или Attach to prompt (сайт), до четырёх изображений | подробности в [editing.md](editing.md) |
| `--version` / `--v` | номер версии | без параметра — версия по умолчанию из настроек |
| `--stealth`, `--public` | флаги | видимость изображений |

Не действуют в V8.1 и V8.2: `--quality` / `--q`, `--oref` / `--ow`, `--cref` / `--cw`, `--style`, `--stop`, `--niji`, мультипромпты `::`. Параметры видео (`--video`, `--motion`, `--loop`, `--end`, `--bs`) скиллом не покрываются.

## Перестановки `{}`

- Варианты в фигурных скобках через запятую: `a {red, green, yellow} bird` даёт три промпта.
- Максимум промптов: Basic 4, Standard 10, Pro и Mega 40; только Fast и Turbo.
- Несколько наборов: `a {red, green} bird in the {jungle, desert}` — четыре промпта; вложенные наборы допустимы.
- Перестановки параметров: `--ar {1:1, 2:3, 3:5}`.
- Запятая внутри варианта экранируется обратной косой чертой: `{red, pastel \, yellow} bird`.
- Перестановки работают в пользовательских суффиксах и наборах опций.

## Примеры

### Пример 1: вертикальный кадр ближе к промпту

**Вход:** «вертикальный кадр, поменьше художественной свободы, V8.1».

**Результат:** `... --ar 2:3 --stylize 50 --v 8.1` — `--stylize` ниже умолчания 100 держит изображение ближе к промпту.

### Пример 2: запрос `--exp 25`

**Вход:** «добавь `--exp 25`, как в V7».

**Результат:** `--exp` в V8.1 и V8.2 поддерживается, но его диапазон и умолчание для V8 не установлены; значение из описания V7 за значение V8 не выдаётся — пользователь предупреждается, что шкала для V8 не описана.
