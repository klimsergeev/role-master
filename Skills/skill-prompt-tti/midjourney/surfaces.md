# Midjourney: поверхности

## Назначение

Где работает Midjourney V8.1 и V8.2 — сайт Midjourney и Discord, — чем различается работа с промптом на каждой поверхности и в какой форме выдаётся готовый результат.

## Сайт Midjourney

- Строка промпта показывает параметры «пилюлями» (pills). После отправки текст очищается, а пилюли и изображения-референсы остаются для следующего запуска.
- Умолчания параметров задаются в настройках (Settings → Advanced → Your defaults) или кнопкой Set current pills as default; параметры сохраняются для папки.
- Соотношение сторон, версия, Raw, Stylize, Variety (это `--chaos`) задаются в панели настроек или параметрами в тексте промпта.
- Изображение в строке промпта получает одну из ролей: Edit Model Reference (Attach to prompt) — референс модели редактирования, Style Reference — референс стиля, Image Prompt — изображение в промпте; роль Animate относится к видео и скиллом не покрывается.
- Несколько srefs в промпте показываются одной пилюлей стиля с миниатюрами.
- Загрузка изображений ограничена 20 MB.
- Draft в V8.1 и V8.2 доступен только на сайте (позиции о Draft в V8.2 — в [models.md](models.md)).
- Editor — правка областей и расширение холста, подробности в [editing.md](editing.md).
- Боковая панель Styles показывает текущий промпт в разных стилях с помощью быстрых моделей; превью строятся только по тексту промпта.

### Разговорный режим

- Пользователь описывает идею обычным языком, а промпт пишет ИИ сервиса. ЕСЛИ пользователь работает в разговорном режиме -> текст для строки промпта не нужен: промпт напрямую не пишется.
- Есть только на сайте; на изображения можно ссылаться как `image 1`, `image 2`; голосовой вариант требует Draft.
- Совместимость с V8.2 не установлена (позиции — в [models.md](models.md)).

### Сайт Alpha

- На сайте Alpha `--exp` можно закрепить как умолчание для папки.
- На сайте Alpha тестируется режим Rerun (Thinking): задания V8.2 (обычные и правки) можно перезапустить с рассуждением — модель смотрит на изображение, находит, где промпт не выполнен (не те объекты, раскладка, анатомия, текст), и генерирует заново.

## Discord

- URL изображений для Image Prompts ставятся в начало текстового промпта через пробел; изображение должно быть уже в сети.
- `--sref` и URL изображений стиля ставятся в конце промпта, несколько — через пробел.
- `--edit` и URL изображений через пробел — модель редактирования.
- `/settings` — умолчания, в том числе версия и пресеты Stylize; по умолчанию пресет Stylize med.
- `/shorten` — присылает предложения, как сократить длинный промпт.
- `/describe` — четыре промпта по изображению, подробности в [references.md](references.md).
- Vary Region — правка выделенной области.
- Draft в V8.1 и V8.2 в Discord пока недоступен.

## Обработка промпта самой поверхностью

- В V8.1 появился сократитель промпта (Prompt Shortener): он срабатывает каждый раз, когда промпт превышает предел длины. Числовой предел и его единица не установлены.
- В разговорном режиме промпт пишет ИИ сервиса.
- Другого переписывания промпта в обычной строке не описано.

## Форма готового результата

Одна строка: сначала текст промпта, затем параметры через пробел.

- Сайт: строка текста с параметрами; изображения-референсы прикрепляются в панели изображений с выбранной ролью и в строку не пишутся.
- Discord: `[URL изображений для Image Prompts] текст промпта --параметры`; URL для `--sref` и `--edit` идут после соответствующего параметра.

## Примеры

### Пример 1: сайт

**Вход:** промпт для V8.2 на сайте, горизонтальный кадр, без референсов.

**Результат:** `Colored pencil illustration of bright orange California poppies --ar 3:2`

### Пример 2: Discord с изображением в промпте

**Вход:** промпт для V8.1 в Discord с одним изображением-референсом, загруженным в сеть.

**Результат:** строка начинается с URL изображения, затем текст, описывающий всё итоговое изображение, затем `--v 8.1`.
