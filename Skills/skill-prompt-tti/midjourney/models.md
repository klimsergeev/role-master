# Midjourney: версии модели

## Назначение

Какие версии Midjourney покрывает скилл, какая версия работает по умолчанию, чем различаются V8.1 и V8.2 и какой синтаксис прежних версий в них не работает.

Состояние на 2026-11-09.

## Покрываемые версии

| Версия | Статус | Даты |
|---|---|---|
| V8.2 | версия по умолчанию | выпущена как версия по умолчанию 24.07.2026 |
| V8.1 | доступна, выбирается явно | выпущена 14.04.2026, была версией по умолчанию с 10.06.2026 по 23.07.2026 |

- Версия задаётся параметром `--version` или `--v` в конце промпта либо умолчанием в настройках: на сайте — кнопка настроек в строке промпта, в Discord — команда `/settings`.
- ЕСЛИ версия в запросе не названа -> V8.2 на сайте и в Discord.
- V8.0 Alpha больше не доступна для генерации.
- V7, V6.1, V6, более ранние версии и линейка Niji скиллом не покрываются: синтаксис и значения для них здесь не приводятся.
- Источники расходятся: одна позиция — версия по умолчанию V8.2; другая — текущей версией по умолчанию названа V7.

## Что изменилось между V8.1 и V8.2

| Что | V8.1 | V8.2 |
|---|---|---|
| Акцент версии | стандартные задания рендерятся примерно в 4–5 раз быстрее прежних версий; модель лучше читает промпт и удерживает мелкие детали; для ещё большей точности следования промпту — включить Raw | эстетика, качество изображения и персонализация; изображения смелее и креативнее; низкокачественных результатов должно стать заметно меньше |
| Следование промпту | лучше держится подробных промптов и лучше рисует текст | отдельно не описано |
| Персонализация | может понадобиться разблокировать глобальный профиль персонализации V7/V8 | персонализация лучше понимает вкус, особенно при большом числе оценок в профиле |
| Модель редактирования `--edit` | поддерживается | поддерживается; заменяет Omni Reference, Character Reference и инструмент Retexture |

Общее для V8: модель гораздо лучше следует подробным указаниям; новая модель может потребовать иного стиля промптов, чем прежние версии.

## Совместимость функций V8.1 и V8.2

Функции отмечены одной отметкой для обеих версий; где сведения расходятся, приведены обе позиции.

| Функция | V8.1 и V8.2 |
|---|---|
| Максимальное соотношение сторон | 14:1; для HD — 4:1 |
| HD (2048 px) | да |
| Personalization, Moodboards, Remix, Variations | да |
| Модель редактирования (Edit Model) | да |
| Omni Reference и Omni Reference Weight | нет |
| Style Reference, коды стилей, Style Weight | да |
| Image Prompts, Image Weight | да |
| Мультипромпты (Multi-Prompting) | нет |
| `--no` | да |
| Quality (`--q`) | нет |
| Seed | да; результат с тем же seed идентичен примерно на 99 % |
| Chaos, Raw, Stylize, Tile, Weird | да |
| `--exp` | да |
| Niji | нет |
| Relax, Fast | да |
| Draft | источники расходятся: одна позиция — Draft есть в V8.1 и V8.2, один промпт даёт сетку из 24 изображений, только на сайте; другая — Draft для V8.1 и V8.2 не поддерживается, а `--draft` описан как функция V7 |
| Turbo | источники расходятся: одна позиция — Turbo не поддерживается ни в V8.1, ни в V8.2; другая — Turbo доступен в версиях 5 и новее, но там же сказано, что в V8.1 он пока не поддерживается. Отдельного утверждения о Turbo именно в V8.2 нет — не установлено |
| Разговорный режим (Conversational Mode) | источники расходятся: одна позиция — поддерживается в V8.1 и V8.2 общей отметкой; другая — совместим с версиями 7 и 8.1, V8.2 не названа. Совместимость с V8.2 не установлена |

- `--exp` поддерживается в V8.1 и V8.2; его диапазон, умолчание и взаимодействие со `--stylize` для V8 не установлены — подробности в [parameters.md](parameters.md).
- Значения `--sv` для V8.1 и V8.2 не установлены — подробности в [references.md](references.md).

## HD и SD

- HD — изображения 2K без апскейла; SD — 1024 px. Включаются в разделе Version панели настроек или параметрами `--hd` и `--sd`.
- Для соотношения 1:1 в V8.2: HD — 2048 × 2048, SD — 1024 × 1024.
- Максимальное соотношение сторон в HD — 4:1.
- Инструменты дорисовки (Pan, Zoom Out, Edit и Vary Region) на HD-изображении дают результат в SD.

## Синтаксис прежних версий, который в V8 не работает

| Прежний синтаксис | Где работал | Что в V8.1 и V8.2 |
|---|---|---|
| `--style raw` | V5, V6 | `--raw` |
| `--quality` / `--q` | V6 (0.5, 1, 2), V7 (1, 2, 4) | не поддерживается |
| Мультипромпты `::` и веса частей (`space::2 ship`) | версии 1, 2, 3, 4, Niji 4, 5, Niji 5, 6, Niji 6, 6.1 | не работают |
| `--cref` / `--cw` (Character Reference) | V6 и Niji 6 | персонаж переносится моделью редактирования `--edit` |
| `--oref` / `--ow` (Omni Reference) | только V7 | заменён моделью редактирования |
| `--stop` | версии 6 и ранее | не работает |
| `--niji` | линейка Niji | в V8 Niji нет |

## Примеры

### Пример 1: версия не названа

**Вход:** «промпт для Midjourney: маяк в шторм» без указания версии и поверхности.

**Результат:** промпт пишется под V8.2 — версию по умолчанию; `--v` не добавляется.

### Пример 2: запрос с синтаксисом V6

**Вход:** «сделай промпт для V8.1 с `--style raw` и `--q 2`».

**Результат:** в V8.1 вместо `--style raw` пишется `--raw`; `--q` в V8.1 не поддерживается и в промпт не включается.
