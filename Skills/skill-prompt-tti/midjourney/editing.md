# Midjourney: правка готового изображения

## Назначение

Как править готовое изображение в Midjourney V8.1 и V8.2: модель редактирования `--edit`, Editor и Vary Region — как формулировать изменение, что сохраняется и какие ограничения действуют.

## Модель редактирования `--edit`

### Что умеет

1. Правка существующего изображения письменными инструкциями.
2. Генерация по 1–4 изображениям-референсам — замена Omni Reference и Character Reference.
3. Правка областей (inpainting) и расширение холста (outpainting) в Editor.

### Совместимость

- Совместима с V8.1 и V8.2, с изображениями в промпте, Style References, мудбордами, персонализацией и `--hd`.
- Несовместима с `--tile`; результаты несовместимы с Remix.

### Как подать изображения

- Discord: `--edit` и URL изображений через пробел.
- Сайт: раздел Attach to prompt в панели изображений, до четырёх изображений.

### Соотношение сторон

- Модель редактирования пытается взять соотношение сторон первого загруженного изображения.
- Соотношение сторон по умолчанию из настроек не применяется.
- Источники расходятся: одна позиция — соотношение меняется явным `--ar` в промпте; другая (для сайта Alpha) — правки сохраняют соотношение исходного изображения, и случайный `--ar` в промпте результат не растянет. Меняет ли явный `--ar` соотношение на сайте Alpha, не установлено.

### Как формулировать

- Обычно промпт Midjourney описывает сцену без указаний, но в модели редактирования конкретные инструкции допустимы, как в разговорном режиме.
- Работают оба стиля — инструкция и описание итога; при неудаче одного пробовать другой.
- ЕСЛИ признаки нескольких персонажей смешиваются -> объединить персонажей в одно изображение-референс.
- ЕСЛИ используются Style References или мудборды -> описать стиль и в тексте промпта, чтобы эстетика надёжнее проявилась.
- ЕСЛИ нужен точный контроль -> добавить `--raw`: он снижает творческий налёт, который добавляет модель.

### Примеры промптов

| Задача | Промпт |
|---|---|
| Сделать персонажа реальным | `make this girl into a real character` |
| Несколько персонажей | `a boy meeting a monster in the wilderness` |
| Объединить изображения | `make this silver knight ride the horse of fire holding the sword of flowers` |
| Сменить ракурс | `let's see this image from the front` / `let's see this image from behind` |
| Сменить стиль | `hand drawn pencil sketch of this image --sref 2708276657` |

## Editor и Vary Region

- Editor на сайте — правка выделенных областей (inpainting), расширение холста (outpainting).
- Vary Region в Discord — правка выделенной области.
- Точечная правка меняет только выделенные пиксели, поэтому изображение можно править многократно без потери качества.
- Мелкие огрехи текста на изображении правятся в Editor или Vary Region.
- Дорисовка HD-изображения (Pan, Zoom Out, Edit и Vary Region) даёт результат в SD.

## Примеры

### Пример 1: смена ракурса

**Вход:** изображение персонажа в профиль, нужен вид спереди, V8.2 на сайте.

**Результат:** изображение прикреплено в Attach to prompt; промпт `let's see this image from the front --raw`; соотношение берётся с изображения.

### Пример 2: правка с `--tile`

**Вход:** «отредактируй мой бесшовный узор через `--edit` и оставь `--tile`».

**Результат:** модель редактирования несовместима с `--tile`; в одном промпте их не сочетать.
