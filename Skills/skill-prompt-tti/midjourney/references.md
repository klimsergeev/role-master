# Midjourney: входные изображения и стиль по референсу

## Назначение

Как в Midjourney V8.1 и V8.2 работают изображения в промпте, Style Reference, персонализация, мудборды и Describe, и чем удерживать персонажа и стиль между кадрами.

## Общее правило

- Изображения и референсы служат вдохновением, а не копируются точно. Для точных правок своего изображения — Editor (подробности в [editing.md](editing.md)).
- Роли изображения на сайте: Edit Model Reference (Attach to prompt), Style Reference, Image Prompt.

## Image Prompts и `--iw`

- Изображение в промпте влияет на содержание, композицию и цвета; модель смотрит на его основные элементы.
- Три способа:
  1. Одно изображение плюс текст: текст описывает всё, что нужно в итоге, а не инструкции по изменению референса.
  2. Несколько изображений без текста — смешение, как Blend в Discord.
  3. Несколько изображений плюс текст — текст уточняет то, чего на референсах не видно.
- Нужно либо несколько изображений, либо одно изображение и текст.
- Форматы: .png, .gif, .webp, .jpg, .jpeg.
- Изображение обрезается под соотношение сторон итогового изображения.
- Промпт только из изображений без текста несовместим с `--stylize` и `--weird`.
- В Discord URL изображений — в начале промпта, через пробел.
- `--iw` — вес изображения: по умолчанию 1, диапазон в V8.1 — 0–3; диапазон для V8.2 отдельно не установлен.

## Style Reference: `--sref`, `--sw`, `--sv`

### Что переносит

- Общий стиль — цвета, технику, фактуры, свет; объекты и людей не копирует.
- Текстовый промпт со Style Reference обязателен.
- Сочетается с референсами модели редактирования и изображениями в промпте.

### Как писать текст при Style Reference

- Держать текст простым: не добавлять стилевых слов, конфликтующих с референсом.
- Добавлять стилевые слова выборочно: если стиль не получается, дописать слова, описывающие стиль референса.
- Описывать содержание, а не инструкции: текст говорит, что изобразить, а не как изменить референс.
  - Плохо: `the look of this image but a dog`, `copy this style and make a bunny`
  - Хорошо: `detailed portrait of a dog`, `ballpoint pen sketch of a bunny`

### Вес `--sw`

- От 0 до 1000, по умолчанию 100.
- Несовместим с мудбордами.

### Коды стиля

- `--sref <код>` — стиль из внутренней библиотеки стилей.
- `--sref random` после отправки превращается в конкретный код; при перезапуске и вариациях код сохраняется; с перестановками, `--repeat` или Draft V8.1 каждое изображение получает свой код.
- Коды можно смешивать между собой и сочетать с изображениями.
- Создать код из загруженного изображения нельзя.
- В Discord отдельным референсам можно давать веса: `--sref URL1::2 URL2::1 URL3::1`.
- Style Explorer — витрина кодов на странице Explore (вкладка Styles) с поиском по словам (`photographic`, `anime`).
- Style Creator создаёт собственный код по выбору картинок из сетки; промпт в Style Creator задаёт только превью и не направляет сам подбор; превью генерируются на V7; при входе с промптом, где уже есть код, новый код добавляется вторым, и для того же вида оба кода используются вместе.

### Версии алгоритма `--sv`

- Значения `--sv` и умолчание для V8.1 и V8.2 не установлены.
- Для V8 Alpha: новая версия алгоритма sref и мудбордов стала умолчанием, старую можно вызвать `--sv 6`; номер новой версии не назван. Переносится ли это на V8.1 и V8.2, не установлено.
- `--sv` несовместим с мудбордами.
- Старые коды стиля в другой версии алгоритма могут давать другой стиль.

## Персонализация `--p`

- Изучает вкус по выбранным и лайкнутым изображениям. Перед использованием нужно разблокировать глобальный профиль выбором изображений из сетки.
- Глобальный профиль V7 работает в V8.1 и V8.2; профили V8 пока несовместимы с V7. Глобального профиля V8 нет; дополнительные профили V8.X создавать можно.
- `--p` применяет профили по умолчанию; `--p pID` — конкретный профиль; при отправке ID превращается в код (`--p code`), код фиксирует состояние профиля, а сам профиль со временем меняется.
- Лайки чужих изображений на Explore влияют на глобальные профили соответствующей версии.
- `--stylize` при персонализации управляет её силой: ниже — слабее, выше — сильнее; 0–1000, по умолчанию 100. Чтобы проявить персонализацию в V8, предлагалось поднимать `--stylize` до 1000.

## Мудборды

- Вид персонализации по подобранным изображениям. Мудборд передаёт более широкий эстетический диапазон, чем Style References, которые точнее.
- Несовместимы с `--sv` и `--sw`.
- Вызов `--p mID`, при отправке превращается в код. Можно выбрать несколько мудбордов по умолчанию.
- `--stylize` управляет силой мудборда так же, как силой персонализации.

## Describe

- Инструмент «изображение в текст»: анализирует загруженное изображение и предлагает четыре промпта; для V8.1 и V8.2 даёт более длинные и подробные промпты.
- Предложенные промпты не воспроизводят изображение точно; повтор на том же изображении даёт другой набор.

## Персонаж и стиль между кадрами

- `--seed` не сохраняет стиль, персонажа или внешность между разными промптами.
- Стиль между кадрами держат Style Reference, коды стиля, персонализация и мудборды.
- Персонажа и объект между кадрами переносит модель редактирования `--edit` с 1–4 изображениями-референсами (подробности в [editing.md](editing.md)).

## Примеры

### Пример 1: серия в одном стиле

**Вход:** три иллюстрации в стиле одного референса, V8.2.

**Результат:** одно и то же изображение стиля как Style Reference во всех трёх промптах; текст каждого промпта описывает только содержание кадра (`detailed portrait of a dog`, а не `the look of this image but a dog`).

### Пример 2: старый код стиля

**Вход:** «код sref из V6 даёт в V8.2 другой стиль, верни как было через `--sv`».

**Результат:** значения `--sv` для V8.2 не установлены — номер версии алгоритма не подставляется; стиль задаётся изображением-референсом вместо кода.
