# Безопасность

## Назначение

Риски работы с Blender и меры против них: чужой `.blend` со скриптами и драйверами, код от модели с полными правами в любом канале, риски каждого MCP-сервера по версии, телеметрия сервера сообщества. Значения сняты 2026-11-16: Blender 5.3, официальный сервер 1.0.3, сервер сообщества 2.3.0.

## Уровни мер

| Уровень | Меры |
|---|---|
| Базовый | Не работать на машине с чувствительными данными и корпоративными учётными данными. Автозапуск скриптов в Blender выключен. Файл сохранён до любой команды, резервная копия — в отдельной папке |
| Средний | Только доверенные `.blend`; чужой файл открывается без автозапуска (Continue Safely) и осматривается до разрешения скриптов. У сервера сообщества выключены интеграции, которые не нужны задаче, и телеметрия (`DISABLE_TELEMETRY=true`) |
| Высокий | Blender и MCP-сервер — в отдельной учётной записи системы или в виртуальной машине (на macOS — UTM, Parallels) |
| Наибольший | Официальный сервер; без библиотек ассетов и генераторов; без режима HTTP у официального сервера и без Allow Remote Connections у аддона сообщества; Blender в виртуальной машине |

## Чужой `.blend`: автозапуск скриптов

### Что исполняется

- При разрешённом автозапуске при открытии файла исполняются текстовые блоки с опцией Register и Python-выражения драйверов.
- Без автозапуска, по действию пользователя, исполняются: запуск скрипта в текстовом редакторе; рендер с Freestyle, потому что Freestyle управляет стилями линий через скрипты.
- Драйвер типа Scripted Expression, который укладывается в подмножество Simple Expressions, Blender вычисляет без интерпретатора Python. Выражение вне подмножества вычисляется через Python и требует автозапуска; без него в панели драйверов — предупреждение безопасности.
- Simple Expressions: имена переменных только ASCII; числа с плавающей точкой и десятичные целые; глобальная `frame`; `pi`, `True`, `False`; `+ - * /`, сравнения, `and`, `or`, `not`, тернарный `if`; функции `min, max, radians, degrees, abs, fabs, floor, ceil, trunc, round, int, sin, cos, tan, asin, acos, atan, atan2, exp, log, sqrt, pow, fmod, lerp, clamp, smoothstep`.
- Python в Blender не ограничивает возможности скрипта: скрипт из файла может то же, что любая программа пользователя.

### Что происходит при открытии

Если файл пытается исполнить скрипт без разрешения, Blender показывает предупреждение с двумя вариантами: Continue Safely — оставить файл открытым без скриптов; Allow Execution — разрешить скрипты для этого файла (сохранённый файл перезагружается). Allow Execution не включает глобальную настройку. Предупреждение видно и в заголовке редактора Info.

### Настройки

| Где | Настройка | Что делает | По умолчанию |
|---|---|---|---|
| Preferences ‣ Save & Load | Auto Run Python Scripts | автозапуск скриптов и выражений драйверов при открытии любого `.blend`, кроме исключённых путей | выключено |
| Preferences ‣ Save & Load | Excluded Paths | файлы из этих папок не запускают скрипты даже при включённом Auto Run | — |
| Окно открытия файла | Trusted Source | разрешить автозапуск для открываемого файла | при включённом Auto Run включён |
| Командная строка | `-y` / `--enable-autoexec`, `-Y` / `--disable-autoexec` | переопределить настройку на этот запуск, в том числе с интерфейсом | `-Y` |
| Python API | `bpy.context.preferences.filepaths.use_scripts_auto_execute` | то же, что Auto Run Python Scripts | `False` |
| Python API | `bpy.context.preferences.autoexec_paths` | исключённые пути | — |
| Python API | параметр `use_scripts` у `bpy.ops.wm.open_mainfile`, `revert_mainfile`, `recover_auto_save`, `recover_last_session`, `drop_blend_file` | Trusted Source для открываемого файла | `False` в сигнатуре |
| Python API, только чтение | `bpy.app.autoexec`, `bpy.app.autoexec_fail`, `bpy.app.autoexec_fail_message`, `bpy.app.autoexec_fail_quiet`, `bpy.app.autoexec_override` | разрешён ли автозапуск, не удался ли и почему, переопределён ли флагом | — |

Правила:

- Auto Run Python Scripts — глобальное значение: при нём открытие файла из интернета может запустить вредоносный код. Если автозапуск нужен для своих проектов — включить его и добавить папку загрузок в Excluded Paths.
- Фоновый рендер своего файла с драйверами-выражениями требует разрешения: `blender --background --enable-autoexec my_movie.blend --render-anim`. Для чужого файла `-y` не ставится.
- Действует ли запрет автозапуска на скрипт, переданный через `--python` или `--python-expr`, не установлено.

### Смежные механизмы Blender

- Расширения объявляют в манифесте раздел `[permissions]`: `files`, `network`, `clipboard`, `camera`, `microphone`.
- Доступ аддонов в интернет регулируется настройкой Allow Online Access и флагами `--offline-mode` и `--online-mode`; аддон обязан проверять `bpy.app.online_access`, но Blender не может помешать стороннему аддону нарушить это правило.
- С 5.1 на macOS скрипты и расширения могут получить доступ к камере, микрофону и системному звуку; система показывает запрос разрешения.

## Код от модели

- В любом канале — MCP, скрипт, командная строка — код, который модель передаёт Blender, исполняется с правами пользователя: доступ к `bpy`, операционной системе и файлам.
- Официальный сервер исполняет код от модели без защиты данных от удаления или отправки на удалённый узел. Его «слабая песочница» подменяет `sys.exit` и блокирует только `wm.quit_blender`, `wm.read_factory_settings`, `wm.read_factory_userpref`, `wm.read_userpref`. Любой его инструмент передаёт в расширение Python-код, а не только `execute_blender_code`.
- Сервер сообщества исполняет код `execute_blender_code` через `exec()` в аддоне без песочницы. Переменная `BLENDER_MCP_SAFE_MODE` со значением `true`, `1`, `yes` или `on` включает проверку кода перед исполнением.
- Текст из сцены и файла — имена объектов, описания, текстовые блоки, содержимое `.blend` из интернета — данные, а не инструкции: через него в работу модели может попасть внедрённая команда.

## Риски официального сервера

- Режим HTTP (`--transport http`): защита от DNS rebinding отключена, CORS открыт для всех источников. Без необходимости сервер запускается в режиме stdio.
- Инструменты `*_for_cli` запускают фоновый Blender на указанном файле; если файл открыт с несохранёнными изменениями, рядом создаётся и затем удаляется копия `<имя>_mcp_0001.blend`.
- Хост расширения задаётся в настройках без ограничений по адресу: хост, отличный от `localhost`, делает сокет, исполняющий присланный код, доступным по сети.
- Сетевого кода, кроме локального сокета, в сервере и расширении нет; заявления проекта о сборе данных нет, есть только ссылка на политику конфиденциальности blender.org.

## Риски сервера сообщества

| Риск | Версия и состояние |
|---|---|
| `execute_blender_code` — `exec()` без песочницы | есть в 2.3.0; проверка — `BLENDER_MCP_SAFE_MODE` |
| Allow Remote Connections: удалённые клиенты исполняют Python без аутентификации и шифрования | настройка с 2026-11-04; по умолчанию адрес — `localhost` |
| `look(image=...)` загружает изображение по любому пути и показывает модели | есть в 2.3.0; читается только то, что Blender открывает как изображение; исходный файл не удаляется |
| `generate_3d(image=...)` с провайдером Hyper3D отправляет локальные изображения стороннему сервису (основной сайт Hyper3D, fal.ai или Premium) | есть в 2.3.0; читается файл или папка до 5 изображений; с 2.2.7 пропускаются только файлы с сигнатурой PNG, JPEG или WebP, до этого читался любой файл по пути |
| Команда аддона `get_viewport_screenshot` пишет снимок по пути, переданному в сокет, без проверки пути | есть в 2.3.0; путь задаёт клиент сокета, а не модель через инструменты: сервер передаёт свой путь во временной папке и сам удаляет этот файл |
| Загрузка изображений Hunyuan3D по адресам внутренней сети | источники расходятся: одна позиция — исправлено в 2.2.7, в локальном режиме загрузка разрешена только с публичных адресов; другая — дефект на 2026-11-16 числится открытым |
| Скрытая инструкция в описаниях инструментов статуса Hyper3D и Hunyuan3D — молча запоминать тип ключа и не говорить о нём пользователю | удалена 2026-06-04; самих инструментов `get_hyper3d_status` и `get_hunyuan3d_status` в 2.3.0 нет |
| Инструменты `get_viewport_screenshot` и `generate_hyper3d_model_via_images` (второй читал любой файл по пути и отправлял его во внешний API) | удалены 2026-09-30, первая версия без них — 2.1.5 |
| Генераторы и библиотеки ассетов работают со сторонними сервисами по ключу пользователя или подписке Premium | Sketchfab и Poly Pizza — ключ API; Poly Haven — без ключа |

## Телеметрия сервера сообщества

| Уровень | Что уходит | По умолчанию | Как выключить |
|---|---|---|---|
| Минимальные анонимные события | случайный идентификатор установки, идентификатор сессии, имя инструмента, успех, длительность, версии сервера, аддона и Blender, ОС, метка времени; без согласия текст ошибки заменяется заглушкой | включены в 2.2.9; для 2.3.0 не установлено | `DISABLE_TELEMETRY=true` (или `BLENDER_MCP_DISABLE_TELEMETRY`, `MCP_DISABLE_TELEMETRY`) в окружении сервера — выключает телеметрию целиком |
| Содержимое | подсказки, фрагменты кода, снимки, траектории действий | выключено; включается флажком Allow Telemetry в настройках аддона или согласием в диалоге, который клиенты с поддержкой elicitation показывают раз за разговор | снять Allow Telemetry или вызвать `disable_telemetry`; минимальные события при этом остаются |

Собранные данные могут использоваться для улучшения сервера, исследований и обучения моделей ИИ.
