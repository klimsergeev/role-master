# Устранение проблем подключения MCP

## Назначение

Порядок проверки, когда Blender не подключается по MCP, и таблица проблем канала с симптомом, решением и отметкой сервера. Значения сняты 2026-11-16; опознание аддона, инструменты и порты серверов — в [mcp-servers.md](mcp-servers.md), сценарии и переменные — в [mcp-setup.md](mcp-setup.md).

## Порядок проверки «не подключается»

1. Определить установленный аддон по разделу «Как опознать установленный аддон» в [mcp-servers.md](mcp-servers.md).
2. Сверить зарегистрированный сервер с аддоном: `claude mcp get blender` или запись в `claude_desktop_config.json`. Какая команда запускает какой сервер — раздел «Устройство канала» в [mcp-servers.md](mcp-servers.md).
3. Проверить, что сервер в Blender запущен. Официальный: Preferences → Add-ons → MCP, статус «Server is running». Сообщество 2.3.0: вкладка «MCP for Blender», надпись «Connected on <хост>:<порт>». Признак того, что на порту никто не слушает и сервер в Blender не запущен: у официального сервера ответ «Cannot connect to Blender at <хост>:<порт>. Ensure Blender is running with the MCP addon enabled and the server started.», у сервера сообщества — «Could not connect to Blender. Make sure the Blender addon is running.».
4. Проверить, что второй MCP-клиент не подключён к тому же Blender.
5. Сверить порт с двух сторон — раздел «Порт и хост» в [mcp-servers.md](mcp-servers.md).
6. ЕСЛИ сервер сообщества → аддон той же версии, что сервер (`get_addon_status` сравнивает `protocol_version` и `expected_protocol_version`, поле `up_to_date`, и называет команду обновления); ЕСЛИ клиент пишет `spawn uvx ENOENT` или не видит инструментов → в регистрации абсолютный путь из `which uvx`.
7. ЕСЛИ клиент — Claude Desktop → перезапустить его полностью, через меню приложения.
8. ЕСЛИ клиент — Claude Code и регистрация менялась → перезапустить сессию.
9. ЕСЛИ причина не найдена → посмотреть вывод Blender: раздел «Вывод и ошибки» в [command-line.md](command-line.md).

## Проблемы и решения

| Проблема | Сервер | Симптом | Решение |
|---|---|---|---|
| Сервер не того типа, что установленный аддон | оба | порт 9876 принимает соединение (`nc -z` успешен), но `claude mcp list` — `connection timed out after 30000ms`; у сервера сообщества `get_addon_status` — `Incomplete JSON response received` | открытый порт совместимость не доказывает. Тип сервера — по разделу «Условия выбора сервера» в [mcp-servers.md](mcp-servers.md); ЕСЛИ выбранному серверу нужен аддон, которого нет в Blender → установить его по [mcp-setup.md](mcp-setup.md); зарегистрировать выбранный сервер по сценарию его типа там же |
| `uv` не установлен | сообщество | `which uvx` ничего не находит | установить `uv` (macOS: `brew install uv`) |
| Клиент не находит `uvx` | сообщество | в терминале `which uvx` даёт путь, а клиент пишет `spawn uvx ENOENT` или не видит инструментов | клиент, запущенный из графической оболочки, не получает `PATH` терминала: в регистрации — абсолютный путь из `which uvx` |
| Расширение не запускает сервер | официальный | сообщение «Online access must be enabled in the system preferences» | разрешить доступ в интернет — последний абзац раздела «Порт и хост» в [mcp-servers.md](mcp-servers.md) |
| Порт занят | оба | сервер в Blender не стартует: у официального — ошибка запуска под кнопками в Preferences → Add-ons → MCP или в выводе Blender; у сообщества — в выводе Blender строка «BlenderMCP: <хост>:<порт> is already in use; auto-start skipped.» | сменить порт с двух сторон — раздел «Порт и хост» в [mcp-servers.md](mcp-servers.md), передача переменной — в [mcp-setup.md](mcp-setup.md) |
| Два клиента к одному Blender | оба | второй клиент не получает ответов | оставить один клиент |
| Первый вызов после подключения вернул ошибку соединения | оба | ошибка соединения на первом вызове | проверить шаг 3 порядка проверки и повторить вызов чтения сцены |
| Инструменты не видны | оба | коннектор пуст или в сессии нет `mcp__blender__*` | Claude Code — проверить имена среди отложенных инструментов, если их нет — перезапустить сессию; Claude Desktop — удалить и заново добавить сервер, перезапустить приложение |
| Видны удалённые инструменты (`get_viewport_screenshot`, `generate_hyper3d_model_via_images`) | сообщество | в списке есть инструменты, которых нет в перечне [mcp-servers.md](mcp-servers.md) | подключена версия ниже 2.1.5; обновить сервер и аддон (`uvx mcp-for-blender@latest update`) |
| Ошибка кода в ответе инструмента | оба | трассировка Python в ответе `execute_blender_code` или `status="error"` с `message` и `stderr` | это ошибка кода, а не канала: [python-api.md](python-api.md) — таблица ломающих изменений и раздел «Ограничения операторов `bpy.ops`» |
| Долгая операция | официальный | вызов `*_for_cli` оборвался | тайм-аут фонового Blender — 120 секунд; разбить работу на шаги или выполнить её в открытом Blender |
| Долгий рендер через инструмент | официальный | после `render_thumbnail_to_path` или `render_viewport_to_path` — «Blender connection timed out at <хост>:<порт>» | MCP-сервер перестал ждать, а рендер в Blender продолжается (абзац об отложенных инструментах в [mcp-servers.md](mcp-servers.md)): дождаться файла в `bpy.app.tempdir/blender_mcp/` (как узнать каталог — там же) и вызов не повторять; долгий рендер — командной строкой по [command-line.md](command-line.md) |
| Долгая генерация | сообщество | `generate_3d` или `generate_gaussian_world` вернул дескриптор задания | повторить вызов с `job` из ответа; ожидание за вызов задаёт `wait_seconds` (по умолчанию 50) |
| Сложная операция одним вызовом падает или обрывается | оба | ответ обрывается | разбить на шаги по [scene-workflow.md](scene-workflow.md) |
| Ответ обрезан | оба | предупреждение Claude Code о размере ответа, усечённый текст | сузить ответ или поднять лимит — [mcp-channel.md](mcp-channel.md) |
| Файл рендера не там, где указан путь | официальный | после `render_thumbnail_to_path` или `render_viewport_to_path` файла нет по `output_path` | путь записи — в строках этих инструментов в [mcp-servers.md](mcp-servers.md) |
| Библиотека ассетов выбирает не то | сообщество | импортирован случайный ассет | найти ассет `search_assets` и импортировать конкретный `import_asset(source, id)`; ЕСЛИ ассеты задаче не нужны → выключить интеграцию флажком Poly Haven на вкладке «MCP for Blender» (свойство `blendermcp_use_polyhaven`, по умолчанию выключено) |
| Интеграция Poly Haven выключена | сообщество | сообщение «PolyHaven integration is currently disabled» | включить флажок Poly Haven на вкладке «MCP for Blender» (по умолчанию выключен) и переподключить сервер аддона |
