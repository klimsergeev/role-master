# Доска мудборда в Figma

## Назначение

Процедура раскладки мудборда на доске в Figma: каркас доски через `use_figma`, картинки-референсы через `upload_assets`, проверка заливок, сводка, блок «Чего не нашлось», итерации по номерам карточек. Доска в Figma — выдача по умолчанию.

## Куда класть доску

- **По умолчанию — страница Figma Design.** Нужна ссылка на файл и страницу, куда класть доску; ЕСЛИ пользователь её не дал -> попросить
- **FigJam — если пользователь попросил.** Кладка и загрузка картинок проверены только на странице Figma Design: на FigJam первую группу проверить через `get_screenshot`, прежде чем строить остальные. Для `use_figma` в FigJam — дополнительно загрузить `/figma-use-figjam`
- **Копия вне Figma** — по запросу или если Figma недоступна: шаблон в [moodboard-templates.md](moodboard-templates.md), картинки — по разделу «Удаление локальных файлов» в [reference-capture.md](reference-capture.md)

## Предварительные требования

- **Remote MCP обязателен.** Запись на холст (`use_figma`, `upload_assets`) — только через Remote MCP, не Desktop
- **Право редактирования** целевого файла и место Full (не Viewer)
- fileKey и id страницы из ссылки пользователя

**Проверка доступа:**
- Вызвать `whoami` — подтверждение подключения, плана и места
- ЕСЛИ нет Remote MCP или нет права редактирования -> сообщить пользователю и предложить копию вне Figma

**Лимиты** вызовов Remote MCP и размера кода `use_figma` — в skill-figma-mcp. Собственных чисел лимитов эта процедура не задаёт: 12 карточек за вызов `use_figma` ниже — порция раскладки, а не лимит сервиса; граница в 60 картинок на вызов `upload_assets` — из схемы инструмента.

## Референсы на доске

Перед раскладкой готовы: одобренный список карточек с размерами из файлов (манифест), сводка, пункты «Чего не нашлось». Процедуры — в [moodboard-workflow.md](moodboard-workflow.md) и [reference-capture.md](reference-capture.md).

1. `whoami` — проверка доступа (раздел выше)
2. Загрузить `/figma-use` и следовать ему; `skillNames` указывать при вызове `use_figma`
3. **Каркас.** Построить доску шаблоном [scripts/figma-board.js](scripts/figma-board.js) через `use_figma`. Условие применимости: доска в Figma, право редактирования есть. Первый вызов — с `BOARD_ID = null`: создаётся доска с шапкой (тема, короткое описание, откуда картинки); `boardId` из ответа подставляется в следующие вызовы. Не больше 12 карточек за вызов; каждый следующий вызов сам находит колонки группы на доске и дочитывает их высоты. Колонки: направление — 4 по 300, коллекция — 3 по 360. Каждая карточка — пустой прямоугольник пропорций картинки (по размеру из файла) и подпись «номер · что взять» + «продукт · источник · метка» со ссылкой на страницу-источник. Код возвращает `map` — соответствие «номер карточки → id прямоугольника»; записать id в `figma_node_id` манифеста. Запасной путь, ЕСЛИ вызов упал: прочитать ошибку, уменьшить порцию карточек или исправить данные и повторить; ЕСЛИ Figma недоступна -> копия вне Figma
4. **Ссылки на загрузку.** Один вызов `upload_assets` на пачку до 60 картинок: `count` = число файлов, `nodeIds` — id прямоугольников в том же порядке, что файлы. Ссылки одноразовые и живут 10 минут — отправлять сразу после ответа
5. **Отправка.** `up.txt` — строки «файл uuid» в порядке `nodeIds`, uuid — из `submitUrl` ответа `upload_assets`. Пути файлов — без пробелов (временная папка сессии вне проекта): `xargs -n 2` делит строку по пробелам. Отправка — `curl` `multipart/form-data` (поле `file`) параллельно, с явным типом каждого файла: без явного `;type=image/webp` WebP получает HTTP 415

```bash
while read -r f u; do
  echo "$f;type=$(file -b --mime-type "$f") https://mcp.figma.com/mcp/upload/$u/submit?scaleMode=FILL&currentPageId=<id страницы>"
done < up.txt | xargs -P 8 -n 2 sh -c 'curl -sS -X POST -F "file=@$0" "$1" -o /dev/null -w "%{http_code}\n"' | sort | uniq -c
```

   Python `urllib` для отправки не использовать: в сборке Python с python.org без установленных корневых сертификатов он падает на проверке SSL-сертификата (`CERTIFICATE_VERIFY_FAILED`), а `curl` работает. ЕСЛИ часть ответов не 200 -> новый вызов `upload_assets` только для этих `nodeIds` и повторная отправка этих файлов
6. **Проверка заливок** чтением через `use_figma` — найти прямоугольники без заливки-картинки:

```javascript
const board = await figma.getNodeByIdAsync("<id доски>");
const rects = board.query("RECTANGLE[name^=img-]").toArray();
return { total: rects.length, empty: rects.filter(r => !r.fills.some(f => f.type === "IMAGE")).map(r => r.name) };
```

   ЕСЛИ `empty` не пуст -> перезалить эти прямоугольники (шаги 4–5 только для них). Чтение заливок надёжнее, чем осмотр скриншота
7. **Сводка и «Чего не нашлось».** Сводку — палитру плашками с hex, источником и методом, шрифты, слова настроения или визуальные константы и «делай / не делай» — добавить отдельным вызовом `use_figma` (раздел «Сводка на доске»). Блок «Чего не нашлось» — текстом в конце доски: массив `MISSING` в последнем вызове шаблона каркаса
8. **Скриншот доски.** `get_screenshot` доски — показать пользователю вместе с сообщением ревью из [moodboard-workflow.md](moodboard-workflow.md)
9. **Удаление.** Локальные файлы удалить по разделу «Удаление локальных файлов» в [reference-capture.md](reference-capture.md); манифест остаётся

## Структура доски: визуальное направление

```
Moodboard — [Проект] v[N]                ← доска, автолэйаут по вертикали
├── Шапка: тема, задача в одну-две фразы, откуда картинки
├── Группа «[смысловая группа]»          ← заголовок + кладка 4 колонки по 300
│   ├── Карточка 01: картинка + подпись «01 · что взять» / «продукт · источник · метка»
│   └── …
├── Группа «[следующая]»
├── Сводка: палитра (плашки с hex, источником, методом), шрифты (название, вес, метод), слова настроения
└── Чего не нашлось
```

## Структура доски: коллекция паттернов

```
Pattern Collection — [Тема] v[N]
├── Шапка: тема, сценарий и рынок, откуда картинки
├── Группа «[место в сценарии]»          ← заголовок + кладка 3 колонки по 360, 6–10 карточек
│   └── Карточки-картинки с подписями
├── Группа «[следующее место в сценарии]»
├── Визуальные константы: плашки цветов с hex, источником, методом; шрифты; иконография — с номерами карточек
├── Делай / не делай — с номерами карточек
└── Чего не нашлось
```

## Раскладка

- **Кладка (по умолчанию):** колонки одинаковой ширины, каждая следующая карточка — в самую короткую колонку. Высота карточки считается из пропорций картинки до загрузки, поэтому картинки встают без обрезки. Колонки выравниваются по высоте не идеально — это допустимо
- **Сетка — по запросу:** одинаковые ячейки; картинки обрезаются (`FILL`) или вписываются (`FIT`). Адаптировать шаблон каркаса: фиксированная высота прямоугольника вместо высоты по пропорции
- **Коллаж — по запросу:** 1–2 главных референса крупно (вдвое шире колонки), остальные мельче

## Сводка на доске

Палитра на доске — плашки с hex, источником и методом: это сводка значений, а не мокап. Код ниже — пример для `use_figma`; адаптировать под данные доски при каждом вызове и добавить секцию в доску (`board.appendChild`), затем снова поставить блок «Чего не нашлось» последним.

```javascript
await figma.loadFontAsync({ family: "Inter", style: "Regular" });
await figma.loadFontAsync({ family: "Inter", style: "Semi Bold" });

const board = await figma.getNodeByIdAsync("<id доски>");
const colors = [ { role: "Background", hex: "#08090A", rgb: { r: 0.031, g: 0.035, b: 0.039 }, src: "№01", method: "точно" } ];

const palette = figma.createFrame();
palette.name = "Палитра";
palette.layoutMode = "VERTICAL";
palette.itemSpacing = 24;
palette.fills = [];
palette.primaryAxisSizingMode = "AUTO";
palette.counterAxisSizingMode = "AUTO";

const title = figma.createText();
title.fontName = { family: "Inter", style: "Semi Bold" };
title.fontSize = 26;
title.characters = "Палитра";
palette.appendChild(title);

const row = figma.createFrame();
row.name = "Colors Row";
row.layoutMode = "HORIZONTAL";
row.itemSpacing = 16;
row.fills = [];
row.primaryAxisSizingMode = "AUTO";
row.counterAxisSizingMode = "AUTO";
palette.appendChild(row);

for (const c of colors) {
  const block = figma.createFrame();
  block.name = c.role + " " + c.hex;
  block.layoutMode = "VERTICAL";
  block.itemSpacing = 8;
  block.fills = [];
  block.primaryAxisSizingMode = "AUTO";
  block.counterAxisSizingMode = "AUTO";
  const swatch = figma.createRectangle();
  swatch.resize(120, 120);
  swatch.cornerRadius = 12;
  swatch.fills = [{ type: "SOLID", color: c.rgb }];
  block.appendChild(swatch);
  const label = figma.createText();
  label.fontName = { family: "Inter", style: "Regular" };
  label.fontSize = 13;
  label.characters = c.role + "\n" + c.hex + "\n" + c.src + " · " + c.method;
  block.appendChild(label);
  row.appendChild(block);
}
board.appendChild(palette);
const miss = board.children.find(n => n.name === "Чего не нашлось");
if (miss) board.appendChild(miss);
return { paletteId: palette.id };
```

Шрифты в сводке — текстом: название, вес, метод, номер карточки. Если шрифт источника недоступен в Figma, образец набирается Inter, а название шрифта пишется в подписи.

## Итерация доски

Правки — точечно, по номерам карточек; доску целиком не пересоздавать.

| Реакция | Что сделать на доске |
|---|---|
| Убрать N | Удалить карточку N (узел карточки — родитель прямоугольника `img-N`); остальные карточки колонки поднимутся сами |
| Ещё таких, как N | Новые карточки — тем же шаблоном каркаса с `BOARD_ID` доски и `title` группы карточки N: группа продолжится, высоты колонок дочитаются; затем шаги 4–6 раздела «Референсы на доске» |
| Уточнить подпись N | Правка текста подписи; ссылку на источник поставить заново на тот же диапазон (домен источника во второй строке) |
| Пересобрать группу | Удалить узел группы и построить её заново шаблоном каркаса; затем шаги 4–6; блок «Чего не нашлось» вернуть в конец |
| Правка сводки | Правка значений плашек и подписей сводки |

После каждой итерации — проверка заливок (шаг 6) и `get_screenshot`; номер версии в названии доски и `board.version` в манифесте растут.

## Что НЕ делать

- НЕ рисовать мокапы, паттерны, схемы и бейджи — ни через `use_figma`, ни через HTML: на доску идут только картинки-референсы, сводка значений и текст
- НЕ вызывать `use_figma` без загрузки `/figma-use`
- НЕ создавать доску через Desktop MCP — запись только через Remote
- НЕ предполагать право редактирования — проверять через `whoami`
- НЕ строить всю доску одним вызовом `use_figma` — не больше 12 карточек за вызов
- НЕ отправлять файлы без явного типа и НЕ отправлять через Python `urllib`
- НЕ откладывать отправку после `upload_assets`: ссылки одноразовые и живут 10 минут
- НЕ принимать доску по скриншоту без чтения заливок
- НЕ оставлять картинки на диске после проверки доски, кроме копии вне Figma по запросу или при недоступной Figma
