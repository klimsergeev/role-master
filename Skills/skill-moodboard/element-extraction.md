# Извлечение дизайн-элементов

## Назначение

Справочник по извлечению визуальных элементов из разных типов источников. Описывает, что извлекать, как извлекать, и что делать, если извлечение не удалось.

## Категории элементов

### Цвета

Что извлекать:
- **Primary** — основной цвет бренда/интерфейса (кнопки, ссылки, акценты)
- **Secondary** — дополнительный цвет (hover-состояния, иконки, второстепенные элементы)
- **Accent** — яркий акцент для CTA и выделения
- **Background** — фон страницы
- **Surface** — фон карточек, модалок, приподнятых элементов
- **Text Primary** — основной текст и заголовки
- **Text Secondary** — подписи, мета-информация, приглушённый текст

Формат: hex-код (#RRGGBB) + название цвета + описание роли.

### Типографика

Что извлекать:
- **Headline font** — шрифт для заголовков (название, если идентифицируется)
- **Body font** — шрифт для основного текста
- **Weight** — используемые начертания (Regular, Medium, Bold, и т.д.)
- **Размерные наблюдения** — крупные/мелкие заголовки, плотный/свободный текст
- **Spacing/tracking** — межстрочный интервал, трекинг (плотный, стандартный, разреженный)

Формат: название шрифта + вес + наблюдения.

### UI-паттерны

Что извлекать:
- **Навигация** — тип (горизонтальная, боковая, бургер), фиксированная или нет, фон (прозрачный, solid, blur)
- **Карточки** — скруглённость, тень, бордер, отступы
- **Кнопки** — форма (rounded, pill, square), стиль (solid, outline, ghost), размеры
- **Секции лейаута** — full-width или contained, чередование фонов, hero-блок
- **Декоративные элементы** — градиенты, паттерны, иллюстрации, анимации
- **Формы** — стиль инпутов, лейблов, валидации

Формат: название паттерна + конкретное описание + источник.

### Настроение / атмосфера

Что извлекать:
- **Ключевые слова** — 4-6 слов, описывающих ощущение (минималистичный, тёплый, технологичный, игривый)
- **Эмоциональный отклик** — какое чувство вызывает (доверие, энергия, спокойствие)
- **Черты характера бренда** — если просматриваются (дружелюбный, экспертный, премиальный)

Формат: список ключевых слов + краткое описание.

## Методы извлечения по типу источника

### Из URL сайта (WebFetch)

**Инструменты:** WebFetch для получения HTML/CSS.

**Процедура:**
- Загрузить главную страницу через WebFetch
- Найти CSS-переменные (`--color-*`, `--font-*`) или Tailwind-классы в HTML
- Извлечь hex-коды из CSS (background-color, color, border-color)
- Найти font-family в CSS
- Проанализировать HTML-структуру для UI-паттернов (nav, card, button классы)

**Ограничения:**
- Динамические стили (загружаемые JS) могут не попасть в HTML
- CSS-in-JS не виден через WebFetch
- Шрифты через Google Fonts видны в `<link>` или `@import`

**ЕСЛИ CSS недоступен или сайт SPA:**
- Попробовать найти файл стилей по ссылкам в HTML
- ЕСЛИ не удалось -> пометить «CSS недоступен, элементы определены визуально» и описать на основе HTML-структуры

### Из Figma-макета (Figma MCP)

**Инструменты:** Figma MCP — get_screenshot, get_design_context.

**Процедура:**
- **get_screenshot** — визуально оценить макет, определить общее направление
- **get_design_context** — получить конкретные значения: цвета, шрифты, размеры, spacing
- Извлечь цвета из полученных стилей
- Извлечь типографику из text styles
- Проанализировать компоненты для UI-паттернов

**Преимущества:** самый точный метод — данные берутся из исходных файлов дизайна.

**Ограничения:**
- Нужна ссылка с fileKey и nodeId
- Rate limits на Remote MCP (см. skill-figma-mcp)

### Из скриншота / изображения

**Инструменты:** Read (для просмотра изображения).

**Процедура:**
- Просмотреть изображение
- Описать доминирующие цвета, типографические решения, UI-паттерны
- Ключевые слова настроения — на основе визуального впечатления

**Ограничения:**
- Hex-коды определяются приблизительно — пометить «определено визуально, приблизительный hex»
- Шрифты могут быть неидентифицируемы — описать стиль (гротеск, антиква, моноширинный)

### Из текстового описания (fallback)

**Инструменты:** не требуются.

**Процедура:**
- Извлечь ключевые слова настроения из описания пользователя
- Подобрать элементы по таблице fallback-значений (см. ниже)
- Все элементы маркировать: «предложено на основе описания»

## Правила извлечения

- **Конкретность.** Не «синий» — а `#2563EB`. Не «гротеск» — а «Inter». Не «карточки» — а «карточки с радиусом 12px, тенью и внутренним отступом 24px»
- **Источник обязателен.** Для каждого извлечённого элемента — откуда он взят (URL, Figma-нода, скриншот, описание пользователя)
- **Честность при неопределённости.** Если hex приблизительный — пометить. Если шрифт не идентифицирован — описать стиль и предложить аналог
- **Не додумывать.** Если из источника видны только цвета, но не типографика — записать цвета, а для типографики явно указать «не извлечено из этого источника»
