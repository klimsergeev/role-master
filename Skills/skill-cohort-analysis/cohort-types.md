# Типы когорт

## Назначение

Справочник типов когорт: acquisition, behavioral, segment. Содержит определения, критерии выбора, типичные применения и ограничения каждого типа.

## Acquisition когорты

Группировка пользователей по дате присоединения (регистрации, первого визита, установки).

**Когда использовать:**
- Базовый анализ retention -- "становится ли продукт лучше со временем?"
- Сравнение новых когорт со старыми -- "Jan cohort vs Feb cohort"
- Отслеживание влияния продуктовых релизов на retention

**Типичные периоды группировки:**

| Частота использования продукта | Период когорты | Retention-периоды |
|---|---|---|
| Ежедневное (мессенджер, соцсеть) | Неделя | Day 1, 3, 7, 14, 30 |
| Несколько раз в неделю (таск-трекер) | Неделя | Day 1, 7, 14, 30, 60 |
| Еженедельное (e-commerce) | Месяц | Week 1, 2, 4, 8, 12 |
| Ежемесячное (SaaS billing) | Месяц | Month 1, 2, 3, 6, 12 |

**Ограничения:**
- Не объясняют ПОЧЕМУ retention растёт/падает -- только фиксируют тренд
- Сезонность может искажать результаты (январская когорта vs летняя)
- Не учитывают поведение внутри когорты -- все пользователи месяца "одинаковы"

## Behavioral когорты

Группировка пользователей по совершённому действию (использование фичи, прохождение onboarding, выполнение ключевого события).

**Когда использовать:**
- Поиск activation metric -- "какое поведение предсказывает retention?"
- Оценка влияния фичи -- "пользователи Feature X удерживаются лучше?"
- Валидация гипотез -- "onboarding действительно влияет на retention?"

**Примеры behavioral когорт:**

| Продукт | Поведение | Когорта |
|---|---|---|
| Мессенджер | Отправил 5+ сообщений в первый день | "Active Day 1" |
| E-commerce | Добавил товар в избранное | "Wishlist users" |
| SaaS | Пригласил коллегу | "Inviters" |
| Фитнес-приложение | Завершил 3 тренировки за неделю | "Committed week 1" |

**Методология сравнения:**
1. Определить поведение-кандидат
2. Разделить пользователей: выполнившие действие vs не выполнившие
3. Построить retention-кривые для обеих групп
4. Разница retention = "предсказательная сила" поведения

**Ограничения:**
- Корреляция != причинность -- активные пользователи и так бы остались
- Нужен достаточный размер обеих групп для значимого сравнения
- Осторожно с self-selection bias: пользователи, использующие фичу, могут быть заведомо более вовлечены

## Segment когорты

Группировка пользователей по атрибуту: размер компании, тарифный план, канал привлечения, география, устройство.

**Когда использовать:**
- Определение ICP (Ideal Customer Profile) -- "кто удерживается лучше всех?"
- Оптимизация маркетинга -- "какой канал даёт качественный трафик?"
- Продуктовые решения -- "для какого сегмента строить фичи?"

**Типичные сегментации:**

| Атрибут | Примеры сегментов | Бизнес-вопрос |
|---|---|---|
| Канал привлечения | organic, paid, referral, direct | Какой канал даёт лучший retention? |
| Тарифный план | free, basic, pro, enterprise | Какой план удерживает лучше? |
| Размер компании | 1-10, 11-50, 51-200, 200+ | Кто наш ICP? |
| География | US, EU, APAC, CIS | Где продукт работает лучше? |
| Устройство | iOS, Android, Web | Какая платформа удерживает? |

**Ограничения:**
- Сегменты должны быть достаточного размера (минимум 100 пользователей)
- Не объясняют причину различий -- только фиксируют
- Могут маскировать внутрисегментные различия (Simpson's paradox)

## Выбор типа когорты

```
Какой вопрос задаёт пользователь?
│
├─ "Продукт становится лучше?" ──────────> Acquisition
├─ "Что предсказывает retention?" ───────> Behavioral
├─ "Кто наш лучший клиент?" ────────────> Segment
├─ "Почему retention падает?" ───────────> Acquisition + Behavioral
└─ Не ясно ─────────────────────────────> Начать с Acquisition
```

## Комбинирование типов

Часто один тип когорты недостаточен. Типичные комбинации:

| Этап анализа | Тип когорты | Цель |
|---|---|---|
| 1. Обзор | Acquisition | Увидеть общий тренд retention |
| 2. Углубление | Segment | Найти, какой сегмент проседает |
| 3. Причины | Behavioral | Найти, какое поведение влияет |
