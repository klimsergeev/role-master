# Kling: неудачный результат

## Назначение

Таблицы «симптом в результате → причина → что изменить» для Kling VIDEO 3.0, VIDEO 3.0 Omni, Kling 4.0 и 4.0 Flash, отдельно — наблюдения пользователей модели, опубликованные разработчиком.

Состояние на 2026-11-16.

## Kling 4.0 и 4.0 Flash

| Симптом в результате | Причина | Что изменить |
|---|---|---|
| в видео субтитры или фоновая музыка, которых не просили | модель может добавить их по умолчанию | прямо запретить: `No subtitles.`, `No background music.` |
| ошибок больше при многих запретах | отрицательные указания повышают вероятность ошибок | переписать запреты прямыми описаниями того, что должно быть в кадре; оставить только два необходимых отрицания; не перечислять исключения, не относящиеся к задаче |
| результат не совпал с ожиданием | в промпте абстрактные слова (вид «премиально», «кинематографично») | проверить в первую очередь: заменить абстракции видимыми деталями — свет, фактура, предметы (таблица в [../prompt-elements.md](../prompt-elements.md)) |
| материал использован не так, как задумано | роль материала не названа | назвать роль каждого материала, границы роли и то, что брать не нужно (в [references.md](references.md)) |
| вместо правки получилось новое видео по референсу | в промпте `Reference @Video1` | писать `Edit @Video1` |
| правка изменила лишнее | не сказано, что сохранить | добавить перечень сохраняемого и `Keep everything else unchanged.` |
| в видео попали сетка, плашки заголовков или пометки с листа раскадровки | не сказано, что нужны готовые кадры | прямо попросить готовые кадры без сетки и пометок |
| анимация смешалась с фотореалистичной фактурой | фотореализм не исключён | при анимационном стиле прямо исключить фотореализм |
| повторение чужого ролика не похоже на задуманное | референс далёк от цели по темпу и структуре планов | взять референс ближе к целевому ролику по темпу и планам |
| в приложении не совместить референсы и ключевые кадры | входы Omni Reference и Keyframes в одной задаче не совмещаются, Keyframes не принимает референсы | разделить задачу или совместить ключевые кадры и референсы в адресе API `/omni-video/kling-4.0` |
| фоновую музыку или эффекты не загрузить | загрузить можно только голосовые профили | описать музыку и эффекты в блоке `[Audio]` |
| видеоэлемент не добавляется после пяти видео-референсов | общий лимит видео-референсов, видео для правки и видеоэлементов — 5 клипов и 30 с | сократить число видео |
| у 4.0 Flash не принимается 1080p, длительность больше 20 с, последний или промежуточные кадры | ограничения Flash | `720p`, до 20 с, только первый кадр |
| 4K в API, 10-битный HDR или продление до 2 минут недоступны | помечены как «скоро» | сообщить пользователю; значений не подставлять |
| API отказывает в доступе к Kling 4.0 | нет пакета Flagship и положительного денежного баланса | условие доступа — в [surfaces.md](surfaces.md) |
| запрос к image-to-video Kling 4.0 отклонён или соотношение не то | передан `aspect_ratio`, которого у адреса нет | убрать `aspect_ratio`, соотношение задаёт первый кадр |

## Kling VIDEO 3.0 и VIDEO 3.0 Omni

| Симптом в результате | Причина | Что изменить |
|---|---|---|
| один план вместо нескольких | в режиме Multi-Shot модель сочла, что сцене подходит один план; или `multi_shot: false` при мультикадровом промпте | Custom Multi-Shot с заданными планами в приложении; в API — формат `shot n, m, words;` и `multi_shot: true` |
| планы склеились или разбились не там | точка с запятой внутри текста плана, сумма длительностей не равна `duration` или планов больше 6 | убрать точки с запятой из текста планов, выровнять сумму, сократить число планов (в [prompt-anatomy.md](prompt-anatomy.md)) |
| реплика прозвучала по-английски | язык реплики вне пяти поддерживаемых — модель переводит её на английский | предупредить пользователя или выбрать поддерживаемый язык (в [../speech.md](../speech.md)) |
| ссылка сработала не на тот элемент | имена элементов вложены друг в друга или совпадают с текстом промпта | переименовать элементы по правилам имён (в [references.md](references.md)) |
| задача по последнему кадру не принимается | последний кадр без первого не поддерживается | добавить первый кадр |
| у VIDEO 3.0 Omni нет звука при видео на входе | с `feature_video` звук только `off`, с `base_video` нельзя `native`, в приложении нативный звук при видео на входе пока не поддерживается | сообщить пользователю об ограничении; `audio: native` с видео на входе не передавать |
| голос не тот или двоится | голос задан в промпте, хотя у элемента голос уже привязан | убрать описание голоса из промпта |
| персонаж нестабилен при движении камеры | элемент не привязан к кадру | привязать элемент к изображению; элемент должен быть в первом кадре |

## Наблюдения пользователей модели

Строки ниже — наблюдения пользователей модели, опубликованные разработчиком, а не спецификация.

| Модель | Симптом | Что изменить |
|---|---|---|
| Kling 4.0, 4.0 Flash | анимация правильная, но слишком спокойная, когда промпт описывает ситуацию | описывать каждый такт действия с первого кадра |
| Kling 4.0 | тайминг видео-референса повторяется слишком буквально | брать референс с нужным таймингом или не брать тайминг из видео |
| Kling 4.0 | согласованность персонажей и пространства между генерациями | планировать дубли по 10–15 с на одну локацию вместо 30 с за раз; писать промпт списком планов: время, крупность, движение камеры, действие, реплика и что движется на фоне |
| Kling 4.0 | мультикадровая генерация добавляет планы и кадрирование сверх задания | задать планы явно: число, отрезки времени, крупность каждого |

## Примеры

### Пример 1: лишние субтитры в Kling 4.0

**Вход:** «Kling 4.0 добавил субтитры, хотя я их не просил».

**Результат:** в блок `[Audio]` добавлено `No subtitles.`; другие запреты, если они есть, переписаны прямыми описаниями.

### Пример 2: русская реплика стала английской в Kling VIDEO 3.0

**Вход:** «Kling 3: героиня должна говорить по-русски, а говорит по-английски».

**Результат:** русского нет среди пяти языков речи VIDEO 3.0, и модель переводит такую реплику на английский; пользователю сообщается об этом, промпт не меняется в обход ограничения.
