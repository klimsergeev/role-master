# Kling: модели

## Назначение

Какие модели Kling покрывает скилл — VIDEO 3.0, VIDEO 3.0 Omni, Kling 4.0 и 4.0 Flash, — как названия из запроса соответствуют официальным, адреса API, сравнение возможностей, отметки «скоро», непокрытые модели и расхождения сведений.

Состояние на 2026-11-16.

## Соответствие названий

| Название в запросе | Официальное название | Новые адреса API | Старые адреса API |
|---|---|---|---|
| «Kling 3», «Kling 3.0» | Kling VIDEO 3.0 | `/text-to-video/kling-3.0`, `/image-to-video/kling-3.0` | `model_name: kling-v3` в `/v1/videos/text2video` и `/v1/videos/image2video` |
| «Kling Omni 3», «Kling 3.0 Omni» | Kling VIDEO 3.0 Omni | `/omni-video/kling-3.0-omni` | `model_name: kling-v3-omni` в `/v1/videos/omni-video` |
| «Kling 4», «Kling 4.0» | Kling 4.0 | `/text-to-video/kling-4.0`, `/image-to-video/kling-4.0`, `/omni-video/kling-4.0` | нет |
| «Kling 4 Omni», «Kling 4.0 Omni» | вход Omni Reference модели Kling 4.0 — отдельной модели с таким названием нет | `/omni-video/kling-4.0` | нет |
| «Kling 4 Flash», «Kling 4.0 Flash» | Kling 4.0 Flash | `/text-to-video/kling-4.0-flash`, `/image-to-video/kling-4.0-flash`, `/omni-video/kling-4.0-flash` | нет |

- Происхождение: VIDEO 3.0 — обновление VIDEO 2.6; VIDEO 3.0 Omni — обновление VIDEO O1; Kling 4.0 — новое поколение; Kling 4.0 Flash — быстрый режим семейства 4.0.
- У Kling 4.0 два основных входа: Omni Reference (референсы) и Keyframes (ключевые кадры).
- На входе Omni Kling 4.0 модель сама классифицирует намерение промпта и направляет задачу в нужный конвейер; у входов из текста и из изображения такой классификации нет.
- Хост, тело запроса и различие новой и старой схемы — в [surfaces.md](surfaces.md).

## Сравнение возможностей

| Что | Kling VIDEO 3.0 | Kling VIDEO 3.0 Omni | Kling 4.0 | Kling 4.0 Flash |
|---|---|---|---|---|
| Длительность | 3–15 с | 3–15 с | 3–30 с | 3–20 с |
| Разрешение | приложение: 720p, 1080p; API: `720p`, `1080p`, `4k` | приложение: 720p, 1080p; API: `720p`, `1080p`, `4k` | API: `720p`, `1080p`; 4K — расхождение ниже | `720p`, 8-битный SDR |
| Соотношение сторон | `16:9`, `9:16`, `1:1` | `16:9`, `9:16`, `1:1` | API: `21:9`, `16:9`, `9:16`, `1:1`, `4:3`, `3:4`; приложение — расхождение ниже | как у Kling 4.0 в API |
| Вход | текст; первый кадр; первый и последний кадр; до 3 элементов | текст, изображения, элементы, одно видео, элементы с голосом | до 15 материалов: до 10 изображений, до 5 видео, до 7 элементов, до 3 голосов | текст; первый кадр; Omni без голосов, последнего и промежуточных кадров |
| Ключевые кадры | первый; первый и последний | первый; первый и последний | первый, последний, первый и последний, промежуточные — до 10 изображений | только первый |
| Правка видео | нет | есть, как у VIDEO O1 (`base_video`) | есть, один `base_video` | `base_video` в адресе Omni |
| Мультикадровость | переключатели Multi-Shot и Custom Multi-Shot; до 6 планов | то же; до 6 планов | включена по умолчанию, переключателя нет | не установлено |
| Звук | нативный звук включается и выключается | `native`, `original`, `off` | всегда синхронный стереозвук; у Omni `native` или `original` | у Omni `native` или `original` |
| Языки речи | китайский, английский, японский, корейский, испанский | те же | те же и португальский, немецкий, французский, хинди | не названы |
| Длина промпта | до 3072 символов, рекомендовано до 2500 | то же | до 8000 токенов | как у Kling 4.0 |
| Ссылка на материал | приложение: `@` и имя элемента; новые адреса API: `@xxx`, соответствие не установлено (в [references.md](references.md)) | приложение: `@` и имя элемента, `@Image`, запись видео не установлена; новый адрес: `@xxx`, соответствие не установлено (в [references.md](references.md)); старый адрес: `<<<image_1>>>` | `@id` (в приложении — по порядку загрузки: `@Image1`, `@Video1`) | `@id` |

Подробности: длительность, разрешение, звук и лимиты по адресам — в [parameters.md](parameters.md); входы и ссылки — в [references.md](references.md).

## Доработка простого промпта

- Kling 4.0 расширяет и уточняет простой промпт сам: из одной фразы модель дописывает сюжет, мизансцену и движения камеры. Если описание уже достаточно ясное, модель следует ему без собственных добавлений.

## Что у Kling 4.0 помечено «скоро»

- 10-битный HDR в 1080p и 4K.
- 4K в API.
- Многократное продление видео, до 2 минут.

ЕСЛИ задача требует одного из этих пунктов -> сообщить, что на дату среза он объявлен, но не доступен; значений для него не подставлять.

## Не покрываются

- Kling 3.0 Turbo — есть только в API, параметров и правил промпта в скилле нет.
- VIDEO O1 как модель; его шаблоны правки используются для VIDEO 3.0 Omni (в [editing.md](editing.md)).
- VIDEO 2.6, 2.5 Turbo и более ранние модели.

## Расхождения

| Предмет | Одна позиция | Другая позиция |
|---|---|---|
| 4K у Kling 4.0 | в приложении — 720p, 1080p, 4K | в API 4K объявлен как «скоро», значения `resolution` — только `720p` и `1080p`, по умолчанию `1080p`; функции приложения определяются его фактическим интерфейсом |
| Соотношения сторон Kling 4.0 в приложении | 21:9, 16:9, 1:1, 9:16 и автоматический выбор | те же и 4:3, 3:4, которые тоже есть в рабочем пространстве; значения API — по API |
| Ключевые кадры у Kling 4.0 Flash | вход Keyframes у Flash назван среди поддерживаемых | первый и последний кадр и промежуточные кадры у Flash не поддерживаются; адрес image-to-video Flash принимает только первый кадр — разрешено так: у Flash из ключевых кадров есть только первый |
| 4K у VIDEO 3.0 и 3.0 Omni | по состоянию на 06.02.2026 — 720p и 1080p | с 23.04.2026 для серии 3.0 есть 4K, значение `4k` есть в API — разрешено по датам: 4K доступен |

## Примеры

### Пример 1: название не совпадает с официальным

**Вход:** «промпт для Kling Omni 3 с видео-референсом».

**Результат:** «Kling Omni 3» — Kling VIDEO 3.0 Omni; новый адрес — `/omni-video/kling-3.0-omni`; видео подаётся как `feature_video`; правила промпта — раздел VIDEO 3.0 Omni в [prompt-anatomy.md](prompt-anatomy.md).

### Пример 2: модель вне охвата

**Вход:** «промпт для Kling 3.0 Turbo через API».

**Результат:** Kling 3.0 Turbo скиллом не покрыта — скилл сообщает об этом и параметры Kling VIDEO 3.0 за параметры Turbo не выдаёт.
