# Prompt Video

## Назначение

Процедуры и справочные значения для составления и правки промптов к двум семействам моделей генерации видео: Seedance (серии 2.0 и 2.5) и Kling (VIDEO 3.0, VIDEO 3.0 Omni, Kling 4.0 и 4.0 Flash).

## Принципы

1. Скилл работает с моделью, названной в запросе, и модель под задачу не выбирает.
2. Синтаксис, параметры и значения берутся только из файлов папки названного семейства и из строк названной модели в общих файлах [speech.md](speech.md) и [text-in-video.md](text-in-video.md), и только для названной версии и поверхности; между семействами, версиями и поверхностями они не переносятся.
3. Значения в файлах датированы строкой «Состояние на …»; версия или поверхность, которых нет в `models.md` и `surfaces.md` семейства, скиллом не покрыта.
4. Промпт пишется на английском для обоих семейств и при любом языке запроса. Реплика пишется дословно на том языке, на котором её должны произнести; текст в кадре — дословно на том языке, на котором он должен появиться, в записи, заданной для модели.
5. Где сведения расходятся, скилл даёт все позиции.
6. Неустановленное значение называется неустановленным; значение другой версии или догадка вместо него не подставляются.

## Таблица маршрутизации

> Читай файлы под задачу, а не скилл целиком. Колонка «Обязательно» — открыть до начала работы. Колонка «Читать, если» — открыть, когда условие выполнено; условие проверяется по задаче, а не по желанию. Файлы с пометкой `(справочник)` устроены как таблицы для точечного поиска — в них допустим поиск нужной строки вместо чтения целиком.

## Рабочий процесс

### Шаг 1: Определить модель, версию, вариант и поверхность

- ЕСЛИ модель не названа или названа не Seedance и не Kling -> сообщить, что скилл модель не выбирает, и перечислить покрываемые модели.
- ЕСЛИ названо семейство без версии («Seedance», «Kling») -> спросить версию: у версий разные длительность, запись времени и синтаксис ссылок на материалы.
- ЕСЛИ названа серия без варианта (Seedance 2.5 без указания flash, Seedance 2.0 без указания fast или mini) -> писать по правилам, общим для серии, без параметров, которые у вариантов различаются; вариант спросить, когда такой параметр нужен.
- ЕСЛИ название в запросе не совпадает с официальным («Seedance 2», «Kling 3», «Kling Omni 3», «Kling 4 Omni») -> сопоставить по таблице соответствия в `models.md` семейства.
- ЕСЛИ поверхность не названа -> спросить: приложение или API; для API — площадку (у Seedance) или адрес (у Kling).
- ЕСЛИ названа версия или поверхность, которых нет в `models.md` и `surfaces.md` семейства -> сообщить, что она не покрыта; синтаксис соседней версии не подставлять.

### Шаг 2: Определить тип задачи

- Типы: видео из текста, по первому кадру, по первому и последнему кадру, по референсам, по ключевым кадрам или раскадровке, правка, продление, склейка, повторение чужого ролика.
- ЕСЛИ входы задачи названная модель не принимает (видео на входе у Kling VIDEO 3.0, последний кадр без первого у Kling VIDEO 3.0 и 3.0 Omni, промежуточные кадры у Kling 4.0 Flash, только аудио у Seedance 2.0) -> сообщить, что модель этот вход не принимает и какая покрываемая модель его принимает; модель не подменять.

### Шаг 3: Открыть файлы

Открыть файлы строки семейства из таблицы маршрутизации: все из колонки «Обязательно» и те из колонки «Читать, если», чьё условие выполнено.

### Шаг 4: Разобрать задачу по элементам

Пройти элементы из [prompt-elements.md](prompt-elements.md): что задано в запросе, что нужно по назначению видео, что остаётся модели.

### Шаг 5: Составить текст промпта

- Форма, порядок, запись времени и планов, длина — по `prompt-anatomy.md` семейства.
- Ссылки на входные материалы — по `references.md` семейства.
- Реплики, закадровый голос и пение — по [speech.md](speech.md) и `audio.md` семейства.
- Текст в кадре и субтитры — по [text-in-video.md](text-in-video.md) и разделу «Текст в кадре» `prompt-anatomy.md` семейства.
- ЕСЛИ в файлах семейства есть предупреждение для этой задачи (язык реплик вне перечня, неустановленное поведение ссылок, ограничение модели) -> привести его рядом с промптом.

### Шаг 6: Добавить параметры

Добавить параметры и настройки поверхности по `surfaces.md` и `parameters.md` семейства.

### Шаг 7: Проверить

Пройти раздел «Проверка перед выдачей» из `prompt-anatomy.md` семейства до последнего пункта.

### Шаг 8: Оформить результат

Оформить результат в форме поверхности из раздела «Форма готового результата» `surfaces.md` семейства.

## Что НЕ делать

- Не переносить синтаксис между семействами и версиями: спецсимволы звука Seedance в промпт Kling; формат `shot n, m, words;` в промпт Seedance; таймкоды в промпт Seedance 2.0; поле `negative_prompt` и ссылки `<<<image_1>>>` в новые адреса API Kling; `voice_list`, `<<<voice_1>>>` и `negative_prompt` в старый адрес `/v1/videos/omni-video`; `audio: off` в Kling 4.0 и 4.0 Flash; `aspect_ratio` в адрес image-to-video Kling 4.0 и 4.0 Flash; `--ar` и другие флаги генераторов изображений.
- Не писать в тексте промпта Seedance идентификатор ассета (`asset://…`, `asset-…`) вместо `Image N`, `Video N`, `Audio N`.
- Не передавать поля с неустановленной поддержкой: `seed` у Seedance 2.x, `cfg_scale` и `camera_control` у `kling-v3` и `kling-v3-omni`.
- Не называть параметр или значение, которых нет в `parameters.md` семейства, и не называть значения по памяти вместо файлов скилла.
- Не выбирать и не подменять модель вместо названной в запросе.
- Не воспроизводить официальные примеры промптов Seedance и Kling — ни дословно, ни близким пересказом, ни их сюжетами.

## Примеры

### Пример 1: сцена с репликой в Seedance 2.5

**Запрос:** «промпт для Seedance 2.5 через BytePlus: 15 секунд, флорист собирает букет, одна реплика покупательницы».

**Маршрут:** обязательные файлы строки «Промпт для Seedance»; плюс [speech.md](speech.md) и [seedance/audio.md](seedance/audio.md), потому что выполнилось условие «в видео есть реплики», и [seedance/parameters.md](seedance/parameters.md), потому что задаются поля запроса.

**Результат:** промпт по четырёхчастной структуре 2.5 с таймкодами целыми секундами без разрывов, реплика покупательницы в `{}` с языком перед ней; «Seedance 2.5» — серия, поэтому вариант для поля `model` спрашивается у пользователя; после ответа «Seedance 2.5» — `model` `dreamina-seedance-2-5-260628`, `duration` — `15`; пройдена проверка перед выдачей Seedance 2.5.

### Пример 2: три плана в Kling VIDEO 3.0 через API

**Запрос:** «Kling 3 через API, три плана: рыбак на рассвете вытаскивает сеть в лодку».

**Маршрут:** [kling/models.md](kling/models.md) сопоставляет «Kling 3» с Kling VIDEO 3.0; обязательные файлы строки «Промпт для Kling»; плюс [kling/parameters.md](kling/parameters.md), потому что задаются поля запроса.

**Результат:** промпт в формате `shot n, m, words;` из трёх планов, `multi_shot: true`, сумма длительностей планов равна `duration`; тело запроса к `/text-to-video/kling-3.0`.

### Пример 3: «Kling 4 Omni» с двумя изображениями

**Запрос:** «Kling 4 Omni, два референса: воздушный змей и девочка».

**Маршрут:** [kling/models.md](kling/models.md) сопоставляет запрос со входом Omni Reference модели Kling 4.0 — отдельной модели нет; обязательные файлы строки «Промпт для Kling»; плюс [kling/references.md](kling/references.md), потому что на входе изображения.

**Результат:** промпт из блоков `[Asset Roles]`, `[Overall Settings]`, `[Sequence of Events]`, `[Audio]`, где роль каждого изображения названа явно; тело запроса к `/omni-video/kling-4.0` с `id` у каждого изображения.

### Пример 4: секунды в Seedance 2.0

**Запрос:** «Seedance 2.0, раздели видео на 0–3 и 3–8 секунд».

**Маршрут:** обязательные файлы строки «Промпт для Seedance»; условие колонки «Читать, если» не выполнено.

**Результат:** по [seedance/prompt-anatomy.md](seedance/prompt-anatomy.md) отрезки для 2.0 записываются номерами планов (`Shot 1`, `Shot 2`) без секунд; рядом с промптом — пометка, что источники расходятся о таймкодах у 2.0.

### Пример 5: русские реплики в Seedance 2.5

**Запрос:** «реплики героев по-русски в Seedance 2.5».

**Маршрут:** обязательные файлы строки «Промпт для Seedance»; плюс [speech.md](speech.md) и [seedance/audio.md](seedance/audio.md), потому что в видео есть реплики.

**Результат:** промпт на английском, реплики дословно кириллицей в `{}` с пометкой языка перед ними; рядом — предупреждение, что русского нет в перечнях языков ни 2.0, ни 2.5 и поведение модели на русской речи не установлено.
