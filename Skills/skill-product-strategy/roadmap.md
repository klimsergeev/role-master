# Roadmap: стратегические фокусы и дорожная карта

Методология Раздела 6 (Стратегические фокусы) и Раздела 7 (Дорожная карта). Превращает выбранный вижин в план исполнения по этапам.

---

## Раздел 6: Стратегические фокусы

Три этапа. Горизонты — ориентир, подстрой под горизонт стратегии пользователя (6 / 12 / 18 мес).

### Этап 1 (ранний): быстрые победы

Приоритеты с быстрым ROI без переделки продукта. Типовые направления (адаптируй под продукт):
- Починить монетизацию / paywall / pricing (из [product-as-is.md](product-as-is.md)).
- Устранить топ технических болей (из отзывов, [ai-customer-dev.md](ai-customer-dev.md)).
- Довести момент ценности («aha») в онбординге.

### Этап 2 (средний): дифференциация + retention

- Умная персонализация (контент/шаблоны/рекомендации под сегмент).
- Интеллект данных (тренды, инсайты, специфичные для ниши/гео).
- Механики удержания (streaks, milestones, циклы возврата).
- Локализация приоритетных рынков.

### Этап 3 (поздний): масштаб и moat

- Углубление ключевой AI/автоматизации.
- Community / сеть / эффекты платформы.
- B2B / Pro tier / расширение монетизации.

### Формат каждого фокуса

Карточка: Фаза + Название + Описание + Ожидаемый эффект. Эффект привязывается к бенчмарку — цифра берётся свежим поиском с источником, не хардкодится.

## Раздел 7: Дорожная карта

Визуальный timeline с 3 фазами (в HTML — цветные точки; в Markdown — таблица по периодам).

Для каждого пункта:

| Период | Инициатива | Что делаем | KPI / Target | Источник бенчмарка |
|---|---|---|---|---|

- **Период** — Мес 1, Мес 1–2 и т.д. (в рамках горизонта пользователя).
- **KPI / Target** — целевая метрика (согласована с [metrics.md](metrics.md)).
- **Источник бенчмарка** — свежий, с датой; если Target — экспертная оценка, помечать как допущение, а не факт.
