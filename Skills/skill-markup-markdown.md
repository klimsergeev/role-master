# Markdown / MultiMarkdown / MDC

## Назначение

Справочник синтаксиса трёх связанных языков разметки: базового Markdown, расширенного MultiMarkdown и MDC (Markdown Components). Применяется при создании документации, статей, README-файлов и контента для CMS на базе Nuxt/Vue.

---

## Самопроверка при подключении

При подключении вывести:

**Markdown Markup подключён**
Доступные диалекты:
- Markdown (CommonMark) — базовый синтаксис
- MultiMarkdown — таблицы, сноски, метаданные, цитаты
- MDC — Vue-компоненты в Markdown

---

## Часть 1: Markdown (CommonMark)

### Заголовки

```markdown
# Заголовок 1
## Заголовок 2
### Заголовок 3
#### Заголовок 4
##### Заголовок 5
###### Заголовок 6
```

**Альтернативный синтаксис (setext):**
```markdown
Заголовок 1
===========

Заголовок 2
-----------
```

### Форматирование текста

| Синтаксис | Результат |
|-----------|-----------|
| `**жирный**` или `__жирный__` | **жирный** |
| `*курсив*` или `_курсив_` | *курсив* |
| `***жирный курсив***` | ***жирный курсив*** |
| `~~зачёркнутый~~` | ~~зачёркнутый~~ |
| `` `код` `` | `код` |

### Списки

**Маркированный список:**
```markdown
- Пункт 1
- Пункт 2
  - Вложенный пункт
  - Ещё вложенный
- Пункт 3
```

Альтернативные маркеры: `*` или `+`

**Нумерованный список:**
```markdown
1. Первый
2. Второй
   1. Вложенный 2.1
   2. Вложенный 2.2
3. Третий
```

**Список задач (GFM):**
```markdown
- [x] Выполненная задача
- [ ] Невыполненная задача
```

### Ссылки

| Синтаксис | Описание |
|-----------|----------|
| `[текст](https://example.com)` | Inline-ссылка |
| `[текст](https://example.com "подсказка")` | Ссылка с title |
| `[текст][ref]` + `[ref]: https://example.com` | Reference-ссылка |
| `<https://example.com>` | Автоматическая ссылка |
| `<email@example.com>` | Email-ссылка |

### Изображения

| Синтаксис | Описание |
|-----------|----------|
| `![alt](image.png)` | Inline-изображение |
| `![alt](image.png "подсказка")` | С title |
| `![alt][ref]` + `[ref]: image.png` | Reference-изображение |

### Цитаты

```markdown
> Это цитата.
> Продолжение цитаты.

> Вложенная цитата:
>> Второй уровень
```

### Код

**Inline-код:**
```markdown
Используйте `console.log()` для отладки.
```

**Блок кода (отступ 4 пробела):**
```markdown
    function hello() {
        console.log("Hello");
    }
```

**Fenced code block:**
````markdown
```javascript
function hello() {
    console.log("Hello");
}
```
````

### Горизонтальная линия

```markdown
---
***
___
```

### Таблицы (GFM)

```markdown
| Заголовок 1 | Заголовок 2 | Заголовок 3 |
|-------------|:-----------:|------------:|
| Слева       | По центру   | Справа      |
| Ячейка      | Ячейка      | Ячейка      |
```

Выравнивание: `:---` (лево), `:---:` (центр), `---:` (право)

### Экранирование

```markdown
\* \_ \` \# \[ \] \( \) \{ \} \. \! \| \\
```

## Часть 2: MultiMarkdown

MultiMarkdown расширяет стандартный Markdown дополнительными возможностями.

### Метаданные (Front Matter)

```markdown
---
Title: Название документа
Author: Имя Автора
Date: 2026-02-15
Keywords: markdown, документация
CSS: styles.css
---
```

Или без разделителей:
```markdown
Title: Название документа
Author: Имя Автора

Текст документа начинается после пустой строки.
```

**Использование переменных:**
```markdown
Title: Мой документ

Этот документ называется "[%Title]".
```

### Расширенные таблицы

**Объединение колонок:**
```markdown
| Заголовок 1 | Заголовок 2 | Заголовок 3 |
|-------------|-------------|-------------|
| Ячейка на 2 колонки      || Ячейка 3    |
| Ячейка 1    | Ячейка 2    | Ячейка 3    |
```

**Группировка заголовков:**
```markdown
|             | Группа      ||
| Заголовок 1 | Заголовок 2 | Заголовок 3 |
|-------------|-------------|-------------|
| Данные 1    | Данные 2    | Данные 3    |
```

**Подпись таблицы:**
```markdown
| Колонка 1 | Колонка 2 |
|-----------|-----------|
| Данные    | Данные    |
[Подпись таблицы][label]
```

### Сноски

**Inline-сноска:**
```markdown
Текст с inline-сноской.[^Это текст сноски]
```

**Reference-сноска:**
```markdown
Текст со сноской[^1].

[^1]: Это текст сноски. Может быть многострочным
    с отступом для продолжения.
```

### Цитаты с источником

```markdown
> Цитата из книги.
> 
> -- Автор, *Название книги*
```

### Перекрёстные ссылки

**Ссылка на заголовок:**
```markdown
## Введение

См. раздел [Введение].
```

**Ссылка с кастомным label:**
```markdown
## Введение [intro]

См. раздел [intro].
```

### Аббревиатуры

```markdown
HTML — это язык разметки.

*[HTML]: HyperText Markup Language
```

### Списки определений

```markdown
Термин 1
:   Определение термина 1

Термин 2
:   Определение термина 2
:   Альтернативное определение
```

### Глоссарий (для LaTeX)

```markdown
[?термин]: Определение термина в глоссарии.

Использование [?термин] в тексте.
```

### Математика

**Inline:**
```markdown
Формула: \\(E = mc^2\\)
```

**Block:**
```markdown
\\[ \int_{-\infty}^{\infty} e^{-x^2} dx = \sqrt{\pi} \\]
```

### Transclusion (включение файлов)

```markdown
{{другой-файл.md}}
```

## Часть 3: MDC (Markdown Components)

MDC позволяет использовать Vue-компоненты внутри Markdown в Nuxt Content.

### Front Matter (YAML)

```markdown
---
title: 'Заголовок страницы'
description: 'Описание для meta'
navigation: true
---
```

### Inline-компоненты

**Базовый синтаксис:**
```markdown
Текст с :icon{name="star"} иконкой.
```

**С текстовым содержимым:**
```markdown
Привет, :badge[Новинка]!
```

**С пропсами:**
```markdown
:button{color="primary" size="lg"}
```

### Block-компоненты

**Базовый синтаксис:**
```markdown
::alert
Содержимое алерта с **Markdown** форматированием.
::
```

**С пропсами:**
```markdown
::card{title="Заголовок" icon="star"}
Содержимое карточки.
::
```

**Пустой компонент:**
```markdown
::divider
::
```

### Слоты

**Default и named слоты:**
```markdown
::hero
Основной контент (default slot)

#title
Заголовок героя

#description
Описание героя
::
```

### Вложенные компоненты

```markdown
::container
  :::card{title="Карточка 1"}
  Содержимое первой карточки.
  :::

  :::card{title="Карточка 2"}
  Содержимое второй карточки.
  :::
::
```

Каждый уровень вложенности добавляет `:`.

### Inline-атрибуты

**Для любых элементов:**
```markdown
[красный текст]{style="color: red"}

**жирный**{.highlight}

_курсив_{#special-text}

![изображение](/img.png){width="300"}

[ссылка](https://example.com){target="_blank"}

`код`{style="color: blue"}
```

**Синтаксис атрибутов:**
| Синтаксис | Описание |
|-----------|----------|
| `{.class}` | CSS-класс |
| `{#id}` | CSS id |
| `{key="value"}` | Атрибут |
| `{key=value}` | Атрибут (без пробелов) |
| `{booleanProp}` | Boolean prop |

### YAML-пропсы в компонентах

```markdown
::chart
---
type: bar
data:
  labels: ["A", "B", "C"]
  values: [10, 20, 30]
---
::
```

### JSON-пропсы

```markdown
::dropdown{:items='["Vue", "React", "Angular"]'}
Выберите фреймворк
::
```

### Binding переменных

```markdown
---
color: blue
---

Цвет: {{ $doc.color || 'red' }}
```

### Span-элементы

```markdown
Обычный текст [выделенный текст]{.highlight} продолжение.
```

## Правила

- ЕСЛИ нужен GFM (GitHub Flavored Markdown) -> используй таблицы с `|`, списки задач `- [ ]`, зачёркивание `~~`
- ЕСЛИ нужны сноски, метаданные, расширенные таблицы -> используй MultiMarkdown
- ЕСЛИ нужны Vue-компоненты в Markdown -> используй MDC
- ЕСЛИ компонент без содержимого -> можно использовать сокращённый синтаксис `:component` на отдельной строке
- ВСЕГДА закрывай block-компоненты MDC: `::component ... ::`
- ВСЕГДА добавляй пустую строку после front matter
- НИКОГДА не смешивай синтаксис разных диалектов без проверки совместимости парсера

## Примеры

### Пример 1: README с GFM

**Вход:** Создать README для npm-пакета.

**Выход:**
```markdown
# my-package

> Краткое описание пакета

## Установка

```bash
npm install my-package
```

## Использование

```javascript
import { myFunction } from 'my-package';

myFunction();
```

## API

| Метод | Описание | Параметры |
|-------|----------|-----------|
| `myFunction()` | Основная функция | `options?: object` |

## Лицензия

MIT
```

### Пример 2: Документ MultiMarkdown

**Вход:** Академический документ с метаданными и сносками.

**Выход:**
```markdown
---
Title: Исследование эффективности
Author: И. Иванов
Date: 2026-02-15
Keywords: исследование, анализ
---

# Введение

Данное исследование посвящено анализу эффективности[^1].

## Методология

Использовался метод A, описанный в [Введение].

| Параметр | Значение | Примечание |
|----------|----------|------------|
| Выборка  | 100      | Случайная  |
[Таблица 1: Параметры исследования]

## Заключение

Результаты подтверждают гипотезу.

[^1]: Подробнее см. работу Петрова (2025).
```

### Пример 3: Страница Nuxt Content с MDC

**Вход:** Landing page с компонентами.

**Выход:**
```markdown
---
title: 'Добро пожаловать'
description: 'Главная страница сайта'
---

::hero{background="gradient"}
#title
Создавайте быстрее

#description
Современный фреймворк для веб-разработки

#actions
  :::button-group
  :button{to="/docs" color="primary"}[Документация]
  :button{to="/examples" color="secondary"}[Примеры]
  :::
::

::features
  :::feature{icon="lightning"}
  #title
  Быстрый

  #description
  Оптимизирован для производительности
  :::

  :::feature{icon="shield"}
  #title
  Безопасный

  #description
  Встроенная защита от уязвимостей
  :::
::
