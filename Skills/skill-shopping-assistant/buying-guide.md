# Руководство для покупки (Фаза 6)

## Назначение

Шаблон финального руководства для агента-покупателя. Документ пишется ДЛЯ buyer-агента (или человека, который пойдёт покупать), но читаем и самостоятельно.

## Структура руководства

### 1. Параметры пользователя

Что искали -- краткая сводка всех параметров из опроса:

```
- Товар: [тип]
- Бюджет: [диапазон]
- Маркетплейсы: [список]
- Назначение: [для чего]
- Ограничения: [что НЕ нужно]
- Размер/параметры: [если применимо]
```

### 2. Стилевой / функциональный профиль

**Для товаров с визуальным компонентом** -- стилевой профиль:
- Что нравится (паттерны из "да"-ответов)
- Что НЕ нравится (паттерны из "нет"-ответов)
- Одним абзацем: если buyer-агенту нужно искать замену, он поймёт, что искать

**Для товаров без визуального компонента** -- функциональный профиль:
- Что важно (приоритеты из опроса)
- Что НЕ важно
- Критерии для выбора замены

### 3. Шорт-лист в приоритетном порядке

**Топ-приоритет** -- явные "да" с самого начала (фаза 4):

Для каждой модели -- карточка:
- Название + бренд
- Цена (распродажная / обычная)
- Ссылки на маркетплейсы (2-3)
- Ключевые цитаты отзывов
- Минусы
- Рекомендация по размеру/параметрам (если применимо)

**Средний приоритет** -- "да" на дожиме (фаза 5):

Те же карточки, но с пометкой "подтверждено на дожиме".

### 4. Сводная таблица

```
| # | Модель | Цена | Маркетплейс | Приоритет |
|---|--------|------|-------------|-----------|
| 1 | ...    | ...  | ...         | Топ       |
| 2 | ...    | ...  | ...         | Топ       |
| 3 | ...    | ...  | ...         | Средний   |
```

### 5. Предупреждения для агента-покупателя

Обязательные разделы:
- Риски контрафакта по категории (из [anti-counterfeit.md](anti-counterfeit.md))
- Нюансы размерной сетки / параметров
- Особенности конкретных маркетплейсов
- Что делать, если нужной модели нет в наличии (предложить альтернативу из шорт-листа)

### 6. "Нет"-модели

Отдельный список моделей, получивших "нет". Нужен для прозрачности и чтобы buyer-агент не предлагал их как замену.

```
Не предлагать как замену:
- [Модель A] -- причина отказа (если известна)
- [Модель B]
```

## Адаптация по типу товара

**Без визуального отбора** (has_visual_component = false):
- Нет стилевого профиля, вместо него -- функциональный профиль
- Нет разделения на "топ" и "средний" приоритет
- Шорт-лист ранжирован по соотношению цена/характеристики

**Услуги:**
- "Модели" = исполнители
- Мошенничество вместо контрафакта
- Нет "нет"-моделей (исполнители не показывались визуально)

**Билеты:**
- Время вместо "модели" (рейс, сеанс, дата)
- Бронирование вместо покупки
- Сроки действия цен

## Правила

- Документ пишется ДЛЯ buyer-агента, но читаем человеком
- ВСЕГДА включать предупреждения по контрафакту
- ВСЕГДА включать "нет"-модели отдельным списком
- ЕСЛИ buyer-агенту нужно искать замену -> стилевой/функциональный профиль даёт ориентир
- ЕСЛИ визуальный отбор был пропущен -> структура адаптируется (нет профиля, нет приоритетов)

## Примеры

### Пример 1: Руководство для кроссовок

**Вход:** 10 моделей "да" (4 топ + 6 средний), 8 моделей "нет"

**Результат:**
```
## Параметры
- Товар: кроссовки мужские
- Бюджет: до 20 000 руб.
- Маркетплейсы: Ozon, WB, Lamoda
- Размер: 43
- Ограничения: без замши, тёмный цвет, не для бега

## Стилевой профиль
Нравится: технологичный вид с видимой структурой подошвы,
сетчатый верх. Не нравится: ретро-массивные силуэты (9060, NYC),
замша, Y2K-стиль.

## Шорт-лист
[10 карточек с приоритетами]

## Предупреждения
- Nike/Adidas: проверять значок "Оригинал" на WB/Ozon
- NB 1080: узкая колодка, +0.5 размера
- ЕСЛИ модели нет в наличии: искать аналог по стилевому профилю

## Отклонённые модели
- NB 9060 -- не понравился ретро-массивный силуэт
- ASICS Gel-NYC -- Y2K-стиль
- On Cloudmonster -- слишком технологичный вид
```
