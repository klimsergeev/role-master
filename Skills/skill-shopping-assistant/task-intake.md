# Приёмка задачи (Фаза 0)

## Назначение

Чеклист извлечения параметров из первого сообщения пользователя и определение маршрута выполнения.

## Чеклист извлечения параметров

Из первого сообщения пользователя извлечь:

| Параметр | Описание | Обязательный |
|---|---|---|
| Тип товара | Физический / цифровой / услуга / билеты | Да |
| Бюджет | Диапазон или "без ограничений" | Нет |
| Маркетплейсы | Где планируется покупка | Нет (спросить в survey.md) |
| Назначение | Для чего нужен товар | Да |
| Ограничения | Что НЕ нужно (явно сказанное) | Нет |
| Доказательная база | Нужны ли отзывы, ссылки | Нет |

## Определение типа товара

На основе извлечённых параметров определить:

**1. Категория товара** (для адаптации процесса):

- Одежда, обувь, аксессуары
- Электроника с дизайном (наушники, часы, телефоны)
- Функциональный товар (батарейки, шурупы, расходники)
- Мебель и декор
- Еда и напитки
- Услуги (Авито, фриланс)
- Билеты (кино, поезд, концерт)
- Цифровые товары / подписки

**2. Флаг `has_visual_component`:**

- `true` -- одежда, обувь, аксессуары, мебель, электроника с дизайном, цветы, подарки
- `false` -- батарейки, шурупы, расходники, еда (без дизайна упаковки), услуги, билеты, цифровые товары

Этот флаг определяет, будут ли выполняться фазы 4-5 (визуальный отбор).

**3. Проверка short-circuit:**

- ЕСЛИ пользователь называет конкретную модель/бренд/артикул -> пропустить фазы 0-5, перейти сразу к ресёрчу одной модели + руководство + браузерный шоппинг

## Определение релевантных маркетплейсов

ЕСЛИ пользователь НЕ указал маркетплейс в первом запросе:

1. На основе определённой категории товара выполнить WebSearch:
   - Запрос: `[категория товара] купить лучшие магазины 2026`
   - Пример: `кошачий корм купить лучшие магазины 2026`, `ламинат купить лучшие магазины 2026`
2. Из результатов поиска определить топ-3-5 популярных площадок для данной категории
3. Сохранить список найденных площадок как `recommended_marketplaces` -- он передаётся в survey.md для формирования вопроса о маркетплейсе

ЕСЛИ пользователь указал маркетплейс -> пропустить этот шаг.

## Дополнительные вопросы

Задавать ТОЛЬКО если не указано в запросе:

1. **Маркетплейс** -- с рекомендациями из `recommended_marketplaces` (определяются через WebSearch на предыдущем шаге)
2. **Действие** -- корзина / избранное / оба
3. **Браузерный шоппинг** -- нужен ли (требует Chrome MCP)

## Правила

- НИКОГДА не спрашивать "кому предназначен результат"
- НИКОГДА не уходить сразу в поиск -- базовых параметров недостаточно, критичные ограничения всплывают при уточнении
- ЕСЛИ маркетплейс не указан -> ОБЯЗАТЕЛЬНО выполнить WebSearch для определения релевантных площадок ПЕРЕД переходом к survey.md
- ЕСЛИ параметров достаточно для старта -> переходить к survey.md
- ЕСЛИ пользователь пришёл с конкретной моделью -> short-circuit: сразу research.md

## Примеры

### Пример 1: Полный запрос

**Вход:** "Хочу найти кроссовки. Важно чтобы продавались на Ozon/WB/Lamoda. Повседневная обувь, не для бега. До 20 тыс руб."

**Результат:**
- Тип: физический (обувь)
- Категория: одежда/обувь/аксессуары
- Бюджет: до 20 000 руб.
- Маркетплейсы: Ozon, WB, Lamoda
- Назначение: повседневная
- Ограничения: не для бега
- `has_visual_component`: true
- Short-circuit: нет
- Следующий шаг: survey.md

### Пример 2: Минимальный запрос (маркетплейс не указан)

**Вход:** "Нужен кошачий корм"

**Результат извлечения:**
- Тип: физический (еда)
- Категория: еда и напитки
- Бюджет: не указан
- Маркетплейсы: не указаны
- Назначение: кормление кошки
- `has_visual_component`: false
- Short-circuit: нет

**WebSearch для определения маркетплейсов:**
- Запрос: `кошачий корм купить лучшие магазины 2026`
- Результат: `recommended_marketplaces` = [Ozon, Wildberries, Яндекс Маркет, "Четыре лапы", Petshop.ru]

**Следующий шаг:** survey.md (уточнить бюджет, маркетплейс из найденных, тип корма, породу/возраст)

### Пример 3: Нишевая категория (маркетплейс не указан)

**Вход:** "Нужен ламинат в коридор, водостойкий"

**Результат извлечения:**
- Тип: физический (стройматериалы)
- Категория: мебель и декор (ближайшая)
- Бюджет: не указан
- Маркетплейсы: не указаны
- Назначение: пол в коридоре
- Ограничения: водостойкий
- `has_visual_component`: true
- Short-circuit: нет

**WebSearch для определения маркетплейсов:**
- Запрос: `ламинат купить лучшие магазины 2026`
- Результат: `recommended_marketplaces` = [Леруа Мерлен, Петрович, OBI, Ozon, Яндекс Маркет]

**Следующий шаг:** survey.md (уточнить бюджет, маркетплейс из найденных, класс износостойкости, толщину)

### Пример 4: Short-circuit

**Вход:** "Хочу Nike Air Max 90, чёрные, 43 размер"

**Результат:**
- Short-circuit: да (конкретная модель)
- Следующий шаг: research.md (ресёрч одной модели)
