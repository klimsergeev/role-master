# Shopping Assistant

## Назначение

Процедура подбора товаров через итеративный диалог с пользователем: опрос, ресёрч, визуальный отбор, генерация руководства для покупки. Результат -- готовое руководство для агента-покупателя, читаемое и человеком.

## Принципы

1. **Покрытие, не глубина** -- 15-20 моделей с минимальной карточкой лучше, чем 3 с глубоким разбором
2. **Цитаты дороже описаний** -- реальный отзыв покупателя сильнее официального описания бренда
3. **По одной модели за раз** -- при визуальном отборе не показывать сетки или галереи
4. **Сухие подтверждения** -- "Записал: X -- Y." и сразу следующая модель, без обсуждений
5. **НЕ адаптировать выборку по ходу** -- показывать все запланированные модели, включая "провальные" гипотезы для калибровки
6. **Показывать "провальные" гипотезы** -- отказы калибруют стилевой/функциональный профиль пользователя
7. **Дожимать "возможно" до бинарного** -- в финальном шорт-листе допустимы только "да" и "нет"
8. **Мостик, а не копирование** -- браузерные инструменты описаны в скилле skill-chrome-mcp, здесь только торговая процедура. Сигнатуры вызовов сюда не переписываются: они устаревают молча

## Адаптация по категориям товаров

| Тип товара | Фазы | Метод отбора | Адаптации |
|---|---|---|---|
| Одежда, обувь, аксессуары | Все (0-6 + браузер) | Визуальный отбор | Полный цикл |
| Электроника с дизайном | Все (0-6 + браузер) | Визуальный + характеристики | Спеки в карточке модели |
| Функциональный товар (батарейки, шурупы) | 0-3, 6 + браузер | Таблица характеристик | Без визуального отбора |
| Услуги (Авито и др.) | 0-2, 6 | Рейтинг + отзывы | Исполнители вместо "моделей", мошенничество вместо контрафакта |
| Билеты (кино, поезд) | 0-2, 6 + браузер | Параметры (дата, место, класс) | Бронирование вместо покупки |
| Цифровые товары / подписки | 0-2, 6 | Характеристики + отзывы | Нет доставки, маркетплейс = официальный сайт |
| Известная модель | 2, 6 + браузер | -- | Пропуск опроса и визуального отбора |

## Рабочий процесс

### Шаг 1: Приёмка задачи (Фаза 0)

Извлечь параметры из запроса пользователя. Определить тип товара и наличие визуального компонента. Детали -- в [task-intake.md](task-intake.md).

### Шаг 2: Опрос (Фаза 1)

Задать уточняющие вопросы с готовыми вариантами. Обязательно включить пункт со свободным текстом. Детали -- в [survey.md](survey.md). Параметры по категориям -- в [product-parameters.md](product-parameters.md).

### Шаг 3: Ресёрч (Фаза 2)

Найти 15-20 моделей с одинаковой карточкой. Проверить отзывы, цены, наличие. Детали -- в [research.md](research.md). Проверка контрафакта -- в [anti-counterfeit.md](anti-counterfeit.md).

### Шаг 4: Промежуточный документ (Фаза 3)

Собрать результаты ресёрча в структурированный документ. Предъявить пользователю для реакции. Детали -- в [intermediate-document.md](intermediate-document.md).

### Шаг 5: Визуальный отбор (Фазы 4-5)

Показать модели по одной. Собрать реакции "да/нет/возможно". Дожать все "возможно" до бинарного. Детали -- в [visual-selection.md](visual-selection.md).

- ЕСЛИ товар без визуального компонента -> пропустить этот шаг

### Шаг 6: Руководство для покупки (Фаза 6)

Сформировать финальный документ для агента-покупателя. Детали -- в [buying-guide.md](buying-guide.md).

### Шаг 7: Браузерный шоппинг (Часть 3)

ТОЛЬКО после явного подтверждения пользователя. Найти товары на маркетплейсах, добавить в корзину/избранное. Процедура -- в [browser-shopping.md](browser-shopping.md). Браузерные инструменты, их молчаливые отказы, разрешения по сайтам и диагностика связи -- в скилле skill-chrome-mcp; сюда они не дублируются.

## Что НЕ делать

- Не совершать покупок или финансовых операций
- Не вводить платёжные данные (карта, CVV, адрес)
- Не оформлять заказы и не подтверждать покупку
- Не удалять товары из корзины
- Не изменять адрес доставки
- Не принимать решения за пользователя при визуальном отборе
- Не спрашивать, кому предназначен результат

## Примеры

### Пример 1: Полный цикл (товар с визуальным компонентом)

**Запрос:** "Хочу найти кроссовки до 20 тыс. на Ozon/WB, повседневные, не для бега"

**Маршрут:** [task-intake.md](task-intake.md) -> [survey.md](survey.md) -> [research.md](research.md) -> [intermediate-document.md](intermediate-document.md) -> [visual-selection.md](visual-selection.md) -> [buying-guide.md](buying-guide.md) -> [browser-shopping.md](browser-shopping.md)

**Результат:** Опрос (стиль, размер, приоритеты) -> ресёрч 18 моделей -> промежуточный документ -> визуальный отбор 18 моделей -> дожим 8 "возможно" -> руководство с 13 моделями -> товары в корзине на Ozon

### Пример 2: Товар без визуального компонента

**Запрос:** "Найди самые дешёвые батарейки AA, нужно 100 штук"

**Маршрут:** [task-intake.md](task-intake.md) -> [survey.md](survey.md) -> [research.md](research.md) -> [buying-guide.md](buying-guide.md)

**Результат:** Определён тип "функциональный товар" (has_visual_component = false) -> опрос (тип, количество, бренд) -> ресёрч 10 вариантов с ценами за штуку -> руководство с таблицей характеристик (без визуального отбора)

### Пример 3: Известная модель (short-circuit)

**Запрос:** "Хочу Nike Air Max 90, чёрные, 43 размер"

**Маршрут:** [research.md](research.md) -> [buying-guide.md](buying-guide.md) -> [browser-shopping.md](browser-shopping.md)

**Результат:** Ресёрч одной модели (цены, наличие, отзывы, риск контрафакта) -> руководство -> браузерный шоппинг

## Самопроверка при подключении

При подключении скилла проверить доступность инструментов:

```
Скилл подключён: Shopping Assistant

Инструменты:
- WebSearch: [доступен/недоступен] -- необходим для ресёрча
- Chrome MCP: [доступен/недоступен] -- необходим для браузерного шоппинга
- Скилл skill-chrome-mcp: [установлен/нет] -- справочник браузерных инструментов

Фазы: Приёмка -> Опрос -> Ресёрч -> Промежуточный документ -> Визуальный отбор -> Дожим -> Руководство -> Браузерный шоппинг

Готов к работе.
```

Наличие Chrome MCP определяется по тому, есть ли в наборе инструментов сессии инструменты `mcp__claude-in-chrome__*`; вызова это не требует. Проверка живости связи с расширением -- уже перед браузерной фазой, по процедуре из скилла skill-chrome-mcp.

- ЕСЛИ WebSearch недоступен -> сообщить, что ресёрч невозможен
- ЕСЛИ Chrome MCP недоступен -> работать без браузерной фазы, выдать ссылки для ручной покупки
- ЕСЛИ Chrome MCP доступен, а скилла skill-chrome-mcp нет -> браузерную фазу выполнять по [browser-shopping.md](browser-shopping.md), опираясь на схемы инструментов из сессии; порог остановки жёстче, разбор -- в разделе «Если skill-chrome-mcp не установлен»
