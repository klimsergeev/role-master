# Параметры товаров по категориям

## Назначение

Универсальный фреймворк параметров для разных типов товаров. Используется в [survey.md](survey.md) для формирования вопросов и в [research.md](research.md) для адаптации карточек.

## Сквозные параметры (для всех категорий)

| Параметр | Описание | Когда спрашивать |
|---|---|---|
| Бюджет | Верхняя граница или диапазон | Всегда (если не указан) |
| Маркетплейс | Где покупать | Всегда (если не указан) |
| Назначение | Для чего товар | Всегда |
| Количество | Сколько единиц | Если неочевидно (1 шт.) |
| Срочность | Когда нужен товар | Если влияет на доставку |

## Категорийные параметры

### Обувь и одежда

| Параметр | Тип | Required / Optional |
|---|---|---|
| Размер | Число / диапазон | Required |
| Пол | М / Ж / Унисекс | Required |
| Стиль | Варианты с примерами моделей | Optional |
| Цвет | Текст / палитра | Optional |
| Материал | Текст (что НЕ нужно: замша, кожа) | Optional |
| Сезон | Лето / зима / демисезон / всесезон | Optional |
| Приоритеты | Комфорт / вид / износостойкость | Optional |

**Decision factors:** силуэт, материал, комфорт при ходьбе, стиль

### Электроника

| Параметр | Тип | Required / Optional |
|---|---|---|
| Тип устройства | Категория | Required |
| Совместимость | С чем должно работать | Required (если применимо) |
| Ключевые характеристики | Зависят от устройства | Required |
| Батарея / автономность | Часы / мАч | Optional |
| Цвет / дизайн | Текст | Optional |

**Decision factors:** характеристики, автономность, экосистема, цена/качество

### Еда и напитки

| Параметр | Тип | Required / Optional |
|---|---|---|
| Тип продукта | Категория | Required |
| Диетические ограничения | Аллергии, веган, халяль и т.д. | Required |
| Вес / объём | Число + единица | Optional |
| Бренд | Конкретный или "любой" | Optional |
| Срок годности | Минимальный | Optional |
| Для кого | Порода/возраст (корм) | Required (для кормов) |

**Decision factors:** состав, цена за кг/литр, отзывы, срок годности

### Услуги

| Параметр | Тип | Required / Optional |
|---|---|---|
| Тип услуги | Описание | Required |
| Локация | Город / район / онлайн | Required |
| Объём работы | Описание задачи | Required |
| Сроки | Когда нужно выполнить | Optional |
| Бюджет | Верхняя граница | Optional |

**Decision factors:** рейтинг исполнителя, отзывы, портфолио, цена

### Билеты

| Параметр | Тип | Required / Optional |
|---|---|---|
| Тип билета | Кино / поезд / концерт / самолёт | Required |
| Дата | Конкретная или диапазон | Required |
| Количество | Число | Required |
| Место / класс | Ряд, ярус, класс вагона | Optional |
| Направление | Откуда-куда (для транспорта) | Required (для транспорта) |

**Decision factors:** время, цена, удобство, наличие

### Мебель и декор

| Параметр | Тип | Required / Optional |
|---|---|---|
| Тип мебели | Категория | Required |
| Размеры | Ш x Г x В (или ограничения) | Required |
| Стиль | С примерами | Optional |
| Материал | Дерево / металл / ткань и т.д. | Optional |
| Цвет | Текст / палитра | Optional |

**Decision factors:** размер, стиль, материал, цена, отзывы о сборке

### Цифровые товары и подписки

| Параметр | Тип | Required / Optional |
|---|---|---|
| Тип | Приложение / подписка / лицензия | Required |
| Платформа | iOS / Android / Windows / Web | Required |
| Срок | Месяц / год / бессрочно | Optional |
| Функциональность | Что должно уметь | Required |

**Decision factors:** функциональность, цена, отзывы, аналоги

## Для неизвестной категории

ЕСЛИ товар не попадает ни в одну категорию:
1. Использовать сквозные параметры
2. Спросить у пользователя: "Какие параметры важны для выбора [товара]?"
3. Сформировать карточку по аналогии с ближайшей категорией
