# Промежуточный документ (Фаза 3)

## Назначение

Шаблон промежуточного документа, который предъявляется пользователю после ресёрча и перед визуальным отбором. Самодостаточный -- человек может прочитать его без дополнительного контекста.

## Структура документа

### 1. Краткие выводы

3-5 предложений с главными находками ресёрча:
- Сколько моделей найдено
- Ценовой диапазон
- Основные тенденции (что доступно, чего не хватает)
- Неожиданные находки

### 2. Карточки моделей (ТОП-N)

Для каждой модели -- карточка из [research.md](research.md):
- Таблица параметров
- Цитаты отзывов
- Минусы
- Note агента (почему включена)

### 3. Сводная таблица

Быстрый обзор всех моделей в одной таблице:

```
| Модель | Цена | Рейтинг | Плюсы | Минусы |
|--------|------|---------|-------|--------|
| ...    | ...  | ...     | ...   | ...    |
```

### 4. Что не удалось найти / пробелы

Честное указание пробелов:
- Модели без отзывов на русском
- Модели без наличия на указанных маркетплейсах
- Категории, которые не удалось покрыть

### 5. Топ-3 рекомендации агента

Три модели, которые агент считает лучшими на основе критериев пользователя. С кратким обоснованием для каждой.

### 6. Предупреждения

- Риски контрафакта по категории (из [anti-counterfeit.md](anti-counterfeit.md))
- Нюансы размерной сетки (если применимо)
- Особенности конкретных маркетплейсов

### 7. Список источников

Нумерованный список, разделённый по типам:
- Маркетплейсы (Ozon, WB, Lamoda)
- Обзоры и рейтинги
- Отзовики

## Правила

- Документ самодостаточен для чтения человеком
- Предъявляется пользователю для реакции ПЕРЕД переходом к визуальному отбору
- НЕ является финальным -- руководство для покупки создаётся заново после визуального отбора
- Для товаров без визуального компонента -- этот документ может быть единственным перед руководством
- Предлагать пользователю вариативность по цвету/стилю -- не только один вариант, но и смежные

## Примеры

### Пример 1: Промежуточный документ для кроссовок

**Вход:** Результаты ресёрча 18 моделей кроссовок

**Результат:**
```
## Краткие выводы

на Ozon и WB. Три бренда доминируют: Nike, New Balance, ASICS. В сегменте
до 12 000 руб. выбор ограничен -- в основном прошлогодние коллекции.

## Карточки моделей
[18 карточек]

## Сводная таблица
[таблица]

## Пробелы
- Hoka Arahi 7 -- нет на WB, только Lamoda
- Mizuno Wave Rider 28 -- отзывов на русском мало

## Топ-3 рекомендации
1. NB Fresh Foam 1080 -- лучший комфорт (подтверждён отзывами)

## Предупреждения

- NB 1080: узкая колодка, рекомендуется +0.5 размера
```
