# Ресёрч (Фаза 2)

## Назначение

Процедура поиска товаров с покрытием категории: 15-20 моделей с одинаковой минимальной карточкой, реальными отзывами и ссылками на маркетплейсы.

## Принцип: покрытие, не глубина

15-20 моделей с базовой проверкой каждой лучше, чем 3 модели с глубоким разбором. На следующей фазе пользователь сократит список сам.

## Стандартизированная карточка модели

Для каждой найденной модели собрать одинаковый минимум:

| Поле | Описание | Обязательное |
|---|---|---|
| Название + бренд | Полное название модели | Да |
| Цена | Распродажная / обычная | Да |
| Ссылки на маркетплейсы | 2-3 ссылки на указанные пользователем маркетплейсы | Да |
| Цитаты отзывов | 3-5 цитат от реальных покупателей (с указанием источника) | Да |
| Минусы | 1-2 минуса, подтверждённые отзывами | Да |
| Доступность | В нужном цвете/размере/конфигурации | Да |
| Риск контрафакта | Из [anti-counterfeit.md](anti-counterfeit.md) | Да |
| Note агента | Почему модель включена в выборку (собственная рекомендация, аналогия) | Да |

### Адаптация карточки по типу товара

**Товар с визуальным компонентом** -- добавить:
- Стилевой профиль силуэта (1-2 предложения)
- Доступные расцветки
- Предупреждение по материалам конкретных расцветок (если актуально)

**Функциональный товар** -- добавить:
- Ключевые характеристики (ёмкость, мощность, вес и т.д.)
- Цена за единицу (штуку, кг, литр)

**Услуга** -- адаптировать:
- "Модель" = исполнитель/компания
- Рейтинг исполнителя, количество выполненных заказов
- Цена за услугу (не за товар)

## Поисковые стратегии

Эффективные паттерны запросов:

| Цель | Паттерн запроса |
|---|---|
| Маркетплейс + отзывы | `[модель] [параметры] ozon отзывы` |
| Сравнение цен | `[модель] купить ozon wildberries` |
| Обзоры и рейтинги | `лучшие [товар] для [функция] [год]` |
| Расширение выборки | `аналоги [модель] [ценовой диапазон]` |
| Изображения (для визуального отбора) | `[модель] [пол] [цвет] side view` |

## Правила

- ВСЕГДА включать собственные рекомендации агента (не только популярное)
- ВСЕГДА проверять материалы конкретных расцветок (одна модель может иметь текстильные и замшевые варианты)
- ВСЕГДА учитывать риск контрафакта для каждой модели
- ВСЕГДА использовать цитаты из отзывов, а не описания с официальных сайтов
- ЕСЛИ модель не найдена на указанных маркетплейсах -> не включать в выборку
- ЕСЛИ отзывов нет или мало -> отметить в карточке
- ЕСЛИ цена значительно ниже рыночной -> отметить риск контрафакта

## Примеры

### Пример 1: Карточка товара с визуальным компонентом

```
### New Balance Fresh Foam 1080v13

**Стиль:** Технологичный беговой силуэт, массивная подошва Fresh Foam X.
**Цвет:** Чёрный/серый, тёмно-синий, белый
**Цена:** 14 990 руб. (Ozon), 15 200 руб. (WB)

**Цитаты отзывов:**
- "Прошёл 42 км, в ногах ощущение как после спа" (newbalance.ru, мужские 43)
- "Мягкие, но не разваливаются через 3 месяца" (Ozon, мужские 44)
- "Узковаты в носке, берите на полразмера больше" (WB, мужские 42)

**Минусы:** Узковатая колодка. Цена на верхней границе бюджета.
**Контрафакт:** Средний риск (популярный бренд). Проверять значок "Оригинал".
**Note агента:** Включена как лидер по комфорту в сегменте -- подтверждено отзывами о длительной ходьбе.
```

### Пример 2: Карточка функционального товара

```
### Duracell AA Optimum

**Характеристики:** 1.5V, щелочная, до 200% энергии vs обычных
**Цена за шт:** 32 руб. (Ozon, упаковка 12 шт.), 35 руб. (WB, упаковка 8 шт.)

**Цитаты отзывов:**
- "В пульте работают 8 месяцев, до этого меняли каждые 3" (Ozon)
- "Дороже обычных, но хватает надолго" (WB)

**Минусы:** Цена выше конкурентов на 30-40%.
**Контрафакт:** Низкий риск (массовый товар, но встречаются подделки).
**Note агента:** Включена как вариант "цена за срок службы" -- дороже за штуку, но дешевле в пересчёте на месяц.
```
