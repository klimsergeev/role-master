# Браузерный шоппинг (Часть 3)

## Назначение

Процедура поиска товаров на маркетплейсах через Chrome MCP и добавления в корзину/избранное. Выполняется ТОЛЬКО после явного подтверждения пользователя.

## Условие выполнения

1. Пользователь явно подтвердил необходимость браузерного шоппинга
2. Chrome MCP доступен (проверить при подключении скилла)
3. Руководство для покупки (buying-guide.md) уже сформировано

## Перед началом

1. **Повторно уточнить список маркетплейсов** -- даже если он указан в руководстве
2. **Уточнить действие:** корзина / избранное / оба
3. **Проверить Chrome MCP:** вызвать `tabs_context_mcp(createIfEmpty: true)`

- ЕСЛИ Chrome MCP недоступен -> сообщить пользователю, предложить ручную покупку по ссылкам из руководства

## Алгоритм

### Шаг 1: Инициализация

```
tabs_context_mcp(createIfEmpty: true) -> получить tabId
```

### Шаг 2: Навигация на маркетплейс

```
navigate(url: [URL маркетплейса], tabId: [tabId])
computer(action: "wait", duration: 3, tabId: [tabId])
```

### Шаг 3: Проверка авторизации

```
read_page(tabId: [tabId], filter: "interactive") -> искать кнопки входа/регистрации
```

- ЕСЛИ не залогинен -> остановиться, попросить пользователя залогиниться вручную
- ПОСЛЕ подтверждения логина -> продолжить

### Шаг 4: Поиск товара

```
find(query: "поле поиска", tabId: [tabId]) -> ref поля
form_input(ref: [ref], value: "[название модели]", tabId: [tabId])
find(query: "кнопка поиска", tabId: [tabId]) -> ref кнопки
computer(action: "left_click", ref: [ref], tabId: [tabId])
computer(action: "wait", duration: 3, tabId: [tabId])
```

### Шаг 5: Чтение результатов

```
get_page_text(tabId: [tabId]) -> извлечь цены, названия
computer(action: "screenshot", tabId: [tabId]) -> скриншот для подтверждения
```

### Шаг 6: Подтверждение пользователем

Показать скриншот + данные. Спросить: "Это нужный товар? [Да / Нет / Другой вариант]"

- ЕСЛИ нет -> уточнить и повторить поиск
- ЕСЛИ да -> перейти к действию

### Шаг 7: Действие (корзина / избранное)

```
find(query: "добавить в корзину" / "добавить в избранное", tabId: [tabId]) -> ref кнопки
computer(action: "left_click", ref: [ref], tabId: [tabId])
computer(action: "wait", duration: 2, tabId: [tabId])
computer(action: "screenshot", tabId: [tabId]) -> подтверждающий скриншот
```

### Шаг 8: Верификация

```
read_network_requests(tabId: [tabId], urlPattern: "/cart") -> проверить успех
```

Сообщить пользователю результат: "[Модель] добавлена в [корзину/избранное] на [маркетплейс]."

### Шаг 9: Следующий товар

Повторить шаги 4-8 для каждой модели из шорт-листа. Между товарами -- `computer(action: "wait", duration: 1)`.

### Шаг 10: Финальный лог (Action Audit)

После обработки всех товаров вывести итоговый лог:

```
## Результаты браузерного шоппинга

| # | Товар | Маркетплейс | Действие | Статус | Цена |
|---|-------|-------------|----------|--------|------|
| 1 | NB 1080v13 | Ozon | Корзина | Добавлен | 14 990 руб. |
| 2 | ASICS Cumulus 26 | WB | Избранное | Добавлен | 12 500 руб. |
| 3 | Hoka Clifton 9 | Ozon | Корзина | Не найден | -- |

Итого: X товаров добавлено, Y не найдено.
```

## Edge-cases

- **Товар не найден** -> сообщить, предложить альтернативу из шорт-листа
- **Цена изменилась** -> показать текущую цену, спросить "продолжать?"
- **Нужный размер/цвет не в наличии** -> сообщить, предложить другой вариант
- **Браузер не отвечает** -> остановиться, предложить ручную покупку по ссылкам
- **Всплывающее окно / капча** -> сделать скриншот, попросить пользователя разобраться вручную
- **Маркетплейс требует авторизацию повторно** -> остановиться, попросить пользователя

## Запрещённые действия (Safety Rules)

- НИКОГДА не нажимать "Купить" / "Оплатить" / "Оформить заказ"
- НИКОГДА не вводить платёжные данные (карта, CVV, адрес)
- НИКОГДА не подтверждать покупку
- НИКОГДА не удалять товары из корзины
- НИКОГДА не изменять адрес доставки
- НИКОГДА не логиниться за пользователя
- ТОЛЬКО разрешённые действия: поиск, просмотр, корзина, избранное
- КАЖДОЕ действие -- только после подтверждения пользователем

## Chrome MCP: справочник инструментов

| Задача | Инструмент |
|---|---|
| Получить табы | `tabs_context_mcp` |
| Создать таб | `tabs_create_mcp` |
| Навигация | `navigate(url, tabId)` |
| Клик / ввод / скролл / скриншот / ожидание | `computer(action, tabId, ...)` |
| Найти элемент по описанию | `find(query, tabId)` |
| Заполнить поле формы | `form_input(ref, value, tabId)` |
| Прочитать текст страницы | `get_page_text(tabId)` |
| Прочитать структуру (DOM) | `read_page(tabId, filter)` |
| Выполнить JS | `javascript_tool(action, text, tabId)` |
| Проверить сетевые запросы | `read_network_requests(tabId, urlPattern)` |

## Примеры

### Пример 1: Успешное добавление в корзину

**Вход:** Шорт-лист из 3 моделей, маркетплейс Ozon, действие: корзина

**Результат:**
```
1. tabs_context_mcp -> tabId: "abc123"
2. navigate("https://ozon.ru") -> загрузка
3. read_page -> пользователь залогинен
4. Поиск "NB 1080v13 мужские чёрные 43"
5. Screenshot -> "Это нужный товар?" -> Да
6. Клик "В корзину" -> screenshot -> "Добавлен"
7. Повтор для следующих моделей
8. Финальный лог: 2 добавлено, 1 не найден
```

### Пример 2: Пользователь не залогинен

**Вход:** Навигация на WB

**Результат:**
```
1. navigate("https://wildberries.ru")
2. read_page -> кнопка "Войти" найдена
3. "Вы не залогинены на Wildberries. Залогиньтесь и подтвердите."
4. Ожидание подтверждения -> продолжение
```
