# Agent Teams — Стоимость токенов

Справочник по расходу токенов Agent Teams и способам его снижать. Факты — из официальной доки Claude Code (costs.md).

## Сколько это стоит

- Agent Teams спавнят несколько инстансов Claude Code, каждый со своим контекстным окном. Расход растёт с числом активных тиммейтов и длительностью работы каждого.
- Дока даёт конкретику: агентские команды используют **приблизительно 7x больше токенов**, чем обычная сессия, **когда тиммейты работают в plan mode** — потому что каждый тиммейт держит собственное контекстное окно и запускается как отдельный инстанс Claude.
  - Дословно: «Agent teams use approximately 7x more tokens than standard sessions when teammates run in plan mode, because each teammate maintains its own context window and runs as a separate Claude instance».
- Токен-расход примерно **пропорционален размеру команды**: каждый тиммейт — своё контекстное окно.

## Как держать стоимость под контролем

- **Использовать Sonnet для тиммейтов** — баланс возможностей и цены для координационных задач.
- **Держать команду небольшой** — расход примерно пропорционален размеру команды. Ориентир: 3-5 тиммейтов.
- **Держать spawn-промпты фокусными** — тиммейты и так автоматически грузят CLAUDE.md, MCP-серверы и skills; всё, что дописано в spawn-промпт, добавляется к их контексту с самого старта.
- **Выключать тиммейтов по завершении работы** — каждый активный тиммейт продолжает тратить токены, пока не выйдет или пока не закончится сессия. Завершать естественным языком по имени (см. SKILL.md, Шаг 5).
- **Держать задачи маленькими и самодостаточными**, чтобы ограничить расход на одного тиммейта.

## Когда команда оправдана

- Для research, review и работы над новыми фичами дополнительные токены обычно оправданы.
- Для рутинных, последовательных задач или правок одного файла обычная одиночная сессия (или субагенты) дешевле и эффективнее.
