# Итоговый документ поездки

## Назначение

Шаблон-образец итогового документа поездки: таблицы (маршрут по дням, бюджет, экстренные номера, обычаи/безопасность), цены с провенансом и датой (только из travel-API) и, где уместно, ссылка «где смотреть». Грузится на финальной упаковке. Бронирование не описывается — процесс брони вне роли.

## Структура документа

### 1. Шапка

Направление, даты, число путешественников, ключевые ограничения (например, «без музеев»).

### 2. Маршрут по дням

| День | Город/зона | Активности | Часы/примечания (с источником) |
|---|---|---|---|
| 1 | … | … | часы — веб-поиск, дата |
| 2 | … | … | … |

Времязависимые факты (часы, дни закрытия) — со ссылкой и датой (протокол — в [verification.md](verification.md)).

### 3. Бюджет

| Статья | Сумма | Источник цены | Дата снимка | Пометка |
|---|---|---|---|---|
| Перелёт | … | travel-API (Duffel/Travelpayouts) | ГГГГ-ММ-ДД | live / «ориентировочно, по кэшу, проверить» |
| Жильё | … | travel-API (LiteAPI/Travelpayouts) | ГГГГ-ММ-ДД | … |

**Цены — только из travel-API, каждая с провенансом и датой** (см. [price-sources.md](price-sources.md), [verification.md](verification.md)). Кэш-цена — с пометкой «ориентировочно, проверить актуальную». Без провенанса цена в документ не попадает. Нет подключённого API → в бюджете честно «цену дать не могу», а не выдуманное число.

### 4. Экстренные номера

| Служба | Номер | Примечание |
|---|---|---|
| Полиция / скорая / пожарные | … | местные, проверить веб-поиском |
| Консульство/посольство | … | ИИ не заменяет консульство (см. [risk-practices.md](risk-practices.md)) |

### 5. Обычаи и безопасность

| Тема | Что учесть |
|---|---|
| Местные нормы | чаевые, дресс-код, этикет |
| Безопасность | районы, риски, сезонные факторы |

### 6. Где смотреть (не бронь)

Где уместно — ссылка «где смотреть цену / купить». Это указатель, а НЕ бронирование: процесс брони роль не выполняет и не описывает как флоу.

## Что НЕ включать

- НЕ описывать процесс бронирования (book/prebook/order, хендофф брони).
- НЕ ставить цену без провенанса и даты.
- НЕ ставить цену из памяти или веб-поиска.

## Примеры

### Пример 1: Готовый документ

**Вход:** проверенный план на 7 дней с ценами из travel-API.

**Результат:** документ с таблицей дней (часы со ссылками), таблицей бюджета (цены с источником и датой), экстренными номерами, обычаями; где уместно — «где смотреть». Брони нет.

### Пример 2: Цена недоступна

**Вход:** ценовой API не подключён.

**Результат:** в таблице бюджета — честная пометка «цену дать не могу / нужен подключённый источник» вместо числа; остальной документ (маршрут, часы, экстренные номера) заполнен на веб-поиске с провенансом.
