# Blender MCP: Troubleshooting и безопасность

## Назначение

Сводная таблица проблем/решений, критика безопасности execute_blender_code, telemetry, стратегии снижения рисков.

## Проблемы и решения

| Проблема | Симптом | Решение |
|----------|---------|---------|
| `uvx` не найден (macOS) | Claude не видит Blender tools | Абсолютный путь `/opt/homebrew/bin/uvx` в конфиге |
| Первая команда падает | "Connection error" при первом промпте | Отправить тривиальный `get scene info` |
| Port 9876 занят | "Connection refused" | `BLENDER_PORT=9001` в env конфига + в N-панели Blender |
| Два клиента одновременно | Второй молча не работает | Закрыть один из клиентов (Cursor / Claude Desktop) |
| Timeout на сложной операции | Ответ обрывается | Разбить на шаги, использовать sequential-thinking MCP |
| Claude не видит tools | Иконка коннектора пустая | Удалить и заново добавить MCP-сервер, обновить addon.py |
| Большие выходы обрезаются | Warning в Claude Code | `MAX_MCP_OUTPUT_TOKENS=50000` |
| Сжигает токены | 60% плана за сессию | Tool Search, batching, restart, планирование в чате |
| Poly Haven выбирает не то | Случайные ассеты | Указать конкретное имя ассета или выключить интеграцию |
| Telemetry без согласия | Промпты/скриншоты уходят на сервер | `DISABLE_TELEMETRY=true` или галочка в аддоне |
| Вредоносный .blend | Prompt injection, произвольный код | VM или отдельная учетка, не открывать без мер |

## Чеклист при "не подключается"

1. В Blender N-панель: кнопка "Connect to Claude" нажата?
2. Claude Desktop перезапущен полностью (меню, не Cmd-W)?
3. `addon.py` обновлен до последней версии?
4. Логи Blender: Window, Toggle System Console (macOS: запустить Blender из терминала)
5. Другой MCP-клиент не занимает порт 9876?
6. ЕСЛИ community: путь к `uvx` абсолютный в конфиге?

## Безопасность

### Предупреждение Blender Foundation

С blender.org/lab/mcp-server: MCP-сервер выполняет код, сгенерированный LLM, без защит от удаления данных или их отправки на удаленный хост. Рекомендуется виртуальная машина или система без чувствительной информации.

### Технические риски

- `execute_blender_code` принимает произвольный Python и выполняет через `exec()` без песочницы
- Полный доступ: bpy API, OS, файловая система
- `get_viewport_screenshot` читает произвольные файлы и удаляет их (`os.remove()`)
- `generate_hyper3d_model_via_images` читает локальные файлы для аплоада во внешний API
- Prompt injection через названия объектов, описания сцен, .blend файлы сообщества

### Аудит community-сервера

agentseal.org: 75/100 (Review Recommended). Найдены "covert behavioral manipulation" — `get_hyper3d_status` и `get_hunyuan3d_status` инструктируют агента скрывать тип API-ключа от пользователя.

### Стратегии по уровню риска

| Уровень | Стратегия |
|---------|-----------|
| Минимальный | Не запускать на машине с чувствительными данными или корпоративными credentials |
| Средний | Только доверенные .blend. Сохраняться **до** любой команды. Backup в отдельной папке |
| Высокий | Blender + MCP в отдельной macOS-учетке или виртуалке (UTM, Parallels) |
| Параноидальный | Official connector, отключить telemetry, без Hyper3D/Sketchfab |

## Telemetry (community-сервер)

По умолчанию включена.

| Режим | Что собирается |
|-------|---------------|
| С согласием | Обезличенные промпты, фрагменты кода, скриншоты |
| Без согласия | Имена tool, успех/неудача, длительность |
| Отключена | Ничего |

Отключение:

```json
"env": { "DISABLE_TELEMETRY": "true" }
```

Или: Blender, Edit, Preferences, Add-ons, Blender MCP, снять галочку.
