# Local Permissions

## Назначение

Скилл настраивает локальные разрешения проекта в `.claude/settings.local.json`, чтобы Claude Code не запрашивал подтверждение на типовые операции (файловые операции, веб-поиск, MCP-вызовы). Применяется при первоначальной настройке проекта или когда нужно расширить набор разрешений.

---

## Самопроверка при подключении

При подключении:

1. Прочитать файл `.claude/settings.local.json` в корне проекта
2. Вывести результат:

```
**Local Permissions подключён**

Текущие разрешения (.claude/settings.local.json):
- [перечислить текущие allow-записи или "файл не найден / разрешения не настроены"]
```

## Пресеты разрешений

### Базовый (base)

Файловые операции + веб-доступ:

```json
[
  "Read",
  "Write",
  "Edit",
  "Bash(ls:*)",
  "Bash(cat:*)",
  "Bash(mkdir:*)",
  "Bash(cp:*)",
  "Bash(mv:*)",
  "Bash(rm:*)",
  "Bash(git:*)",
  "Bash(npm:*)",
  "Bash(npx:*)",
  "Bash(node:*)",
  "WebSearch",
  "WebFetch"
]
```

### Расширенный (extended)

Базовый + Figma MCP + другие MCP:

```json
[
  "Read",
  "Write",
  "Edit",
  "Bash(ls:*)",
  "Bash(cat:*)",
  "Bash(mkdir:*)",
  "Bash(cp:*)",
  "Bash(mv:*)",
  "Bash(rm:*)",
  "Bash(git:*)",
  "Bash(npm:*)",
  "Bash(npx:*)",
  "Bash(node:*)",
  "WebSearch",
  "WebFetch",
  "mcp__figma__*",
  "mcp__ide__*"
]
```

## Алгоритм

### Шаг 1: Чтение текущих настроек

1. Прочитать файл `.claude/settings.local.json` в корне проекта
2. ЕСЛИ файл не существует -> запомнить: текущие настройки = пустой объект `{}`
3. ЕСЛИ файл существует -> распарсить JSON, извлечь `permissions.allow` (массив строк)

### Шаг 2: Выбор пресета

Спросить пользователя через AskUserQuestion:

> Какой пресет разрешений применить?
>
> 1. **Базовый** (base) — файловые операции, Bash, веб-поиск
> 2. **Расширенный** (extended) — базовый + Figma MCP + IDE MCP
> 3. **Свой набор** — укажите разрешения вручную
>
> Также можете указать дополнительные разрешения к пресету (например: `Bash(docker:*)`, `mcp__slack__*`).

### Шаг 3: Формирование списка разрешений

1. Взять массив разрешений из выбранного пресета
2. Добавить дополнительные разрешения, указанные пользователем
3. Объединить с существующими разрешениями из файла (union, без дубликатов)
4. Отсортировать массив для читаемости

### Шаг 4: Запись файла

1. Сформировать итоговый JSON:

```json
{
  "permissions": {
    "allow": [
      // объединённый список разрешений
    ]
  }
}
```

2. ЕСЛИ в текущем файле есть другие ключи (кроме `permissions.allow`) -> сохранить их
3. Записать файл `.claude/settings.local.json`
4. Убедиться, что директория `.claude/` существует; если нет -> создать

### Шаг 5: Подтверждение

Вывести итоговый список разрешений:

```
Разрешения записаны в .claude/settings.local.json

Итоговый список:
- Read
- Write
- Edit
- Bash(ls:*)
- ...
```

---

## Правила

- ЕСЛИ файл `.claude/settings.local.json` не существует -> создать директорию `.claude/` (если нужно) и файл
- ЕСЛИ файл существует и содержит другие настройки (не только permissions) -> сохранить все существующие ключи, обновить только `permissions.allow`
- ЕСЛИ в существующем `allow` уже есть часть разрешений -> не дублировать, добавить только новые
- ВСЕГДА показывать пользователю итоговый список перед записью или сразу после
- ВСЕГДА сохранять валидный JSON с отступами в 2 пробела
- НИКОГДА не удалять существующие разрешения из `allow` (только добавлять)
- НИКОГДА не трогать `permissions.deny`, если он присутствует в файле

---

## Формат выдачи

После выполнения скилл выводит:

```
Разрешения записаны в .claude/settings.local.json

Пресет: [base / extended / custom]
Добавлено новых: [N]
Итого разрешений: [M]

Список:
- [разрешение 1]
- [разрешение 2]
- ...
```

## Примеры

### Пример 1: Первая настройка проекта (типовой сценарий)

**Выход:**
```

Пресет: extended
Добавлено новых: 16
Итого разрешений: 16

Список:
- Bash(cat:*)
- Bash(cp:*)
- Bash(git:*)
- Bash(ls:*)
- Bash(mkdir:*)
- Bash(mv:*)
- Bash(node:*)
- Bash(npm:*)
- Bash(npx:*)
- Bash(rm:*)
- Edit
- Read
- WebFetch
- WebSearch
- Write
- mcp__figma__*
- mcp__ide__*
```

### Пример 2: Добавление разрешений к существующим (edge-case)

**Вход:** Файл уже содержит:
```json
{
  "permissions": {
    "allow": ["Read", "Write", "Edit"],
    "deny": ["Bash(rm -rf:*)"]
  }
}
```
Пользователь выбирает пресет "базовый".

**Выход:**
```
Разрешения записаны в .claude/settings.local.json

Пресет: base
Добавлено новых: 12
Итого разрешений: 15

Список:
- Bash(cat:*)
- Bash(cp:*)
- Bash(git:*)
- Bash(ls:*)
- Bash(mkdir:*)
- Bash(mv:*)
- Bash(node:*)
- Bash(npm:*)
- Bash(npx:*)
- Bash(rm:*)
- Edit
- Read
- WebFetch
- WebSearch
- Write

Примечание: permissions.deny сохранён без изменений.
```

## Что НЕ входит в scope

- Настройка глобальных разрешений (`~/.claude/settings.json`)
- Управление `permissions.deny`
- Настройка MCP-серверов (для этого есть `skill-figma-mcp`)
- Настройка хуков и других секций settings
