# Internal Linking

## Назначение

Справочник стратегии внутренней перелинковки — типы ссылок, правила, pillar-cluster модель, аудит.

## Зачем внутренние ссылки

- Распределение PageRank между страницами
- Помощь в индексации (краулинг)
- Улучшение UX (навигация)
- Снижение bounce rate

## Типы внутренних ссылок

| Тип | Где размещается | Цель |
|-----|-----------------|------|
| **Навигационные** | Меню, footer, sidebar | Структура сайта |
| **Контекстные** | Внутри текста | Углубление в тему |
| **Related/Recommended** | Блоки «Похожие», «Читайте также» | Удержание, cross-sell |
| **Breadcrumbs** | Над контентом | Иерархия, навигация |

## Правила внутренней перелинковки

1. **Анкоры** — описательные, с ключевыми словами (не «нажмите сюда»)
2. **Релевантность** — ссылка должна быть полезна читателю
3. **Количество** — 3-5 внутренних ссылок на 1000 слов (ориентир)
4. **Глубина** — важные страницы доступны в 3 клика от главной
5. **Без nofollow** — внутренние ссылки без nofollow (если не спам)
6. **Обновление** — при создании новой страницы добавлять ссылки со старых релевантных

## Pillar-Cluster модель

```
Pillar Page: «Гид по театрам Москвы» (широкая тема)
    +-- Cluster: «Драматические театры Москвы»
    +-- Cluster: «Детские спектакли в Москве»
    +-- Cluster: «Музыкальные театры Москвы»
    +-- Cluster: «Как выбрать места в театре»

Все cluster-страницы ссылаются на pillar и друг на друга.
```

## Аудит внутренних ссылок

- **Orphan pages** (страницы без входящих ссылок) — найти и связать
- **Broken internal links** — исправить или удалить
- **Redirect chains** — убрать цепочки редиректов
- **Link equity distribution** — важные страницы получают больше ссылок

## Внутренняя перелинковка и AI/краулинг

- Логичная перелинковка помогает AI-ботам (GPTBot, Google-Extended, PerplexityBot) глубже обходить сайт
- Pillar-cluster модель усиливает topical authority — сигнал для AI Overviews
- Анкоры с естественным языком (не exact match) лучше воспринимаются AI
