# Нефункциональные требования (NFR)

## Назначение

Справочник нефункциональных требований для PRD: что спросить у команды и что указать в документе по каждой категории.

## Производительность

**Что спросить:**
- Допустимое время загрузки страницы?
- Есть ли требования к Core Web Vitals?
- Сколько одновременных пользователей ожидается?

**Что указать в PRD:**

| Метрика | Целевое значение (типовое) |
|---|---|
| Время ответа сервера (TTFB) | < 200 мс |
| First Contentful Paint (FCP) | < 1.8 сек |
| Largest Contentful Paint (LCP) | < 2.5 сек |
| Cumulative Layout Shift (CLS) | < 0.1 |
| Interaction to Next Paint (INP) | < 200 мс |

ЕСЛИ нагрузка критична -> указать пиковую нагрузку и допустимую деградацию.

## Безопасность

**Что спросить:**
- Какие данные обрабатываются? (персональные, платёжные, медицинские)
- Есть ли требования к сертификации? (PCI DSS, GDPR, 152-ФЗ)
- Какие роли и уровни доступа?

**Что указать в PRD:**
- Аутентификация: способы входа, MFA, сброс пароля
- Авторизация: роли, права, матрица доступа
- Защита: XSS, CSRF, SQL-injection, rate limiting
- Данные: шифрование at rest / in transit, срок хранения, политика удаления

## Доступность (a11y)

**Что спросить:**
- Какой уровень WCAG требуется? (A, AA, AAA)
- Есть ли пользователи с особыми потребностями?
- Нужна ли поддержка screen readers?

**Что указать в PRD:**
- Уровень WCAG (обычно AA)
- Клавиатурная навигация: все интерактивные элементы доступны с клавиатуры
- Screen readers: семантическая разметка, aria-атрибуты, alt-тексты
- Контраст: минимум 4.5:1 для текста, 3:1 для крупного текста
- Фокус: видимый индикатор фокуса для всех интерактивных элементов

## Совместимость

**Что спросить:**
- Какие браузеры поддерживаем?
- Мобильные устройства -- только веб или нативное приложение?
- Минимальное разрешение экрана?

**Что указать в PRD:**

| Параметр | Типовое значение |
|---|---|
| Браузеры | Chrome, Safari, Firefox (2 последние версии) |
| Мобильные ОС | iOS 16+, Android 12+ |
| Разрешения | от 320px (mobile) до 1920px (desktop) |
| Адаптивность | Mobile-first, breakpoints: 768px, 1024px, 1440px |

## Локализация

**Что спросить:**
- Какие языки нужны сейчас и в перспективе?
- Есть ли RTL-языки?
- Нужна ли локализация форматов (даты, валюта, числа)?

**Что указать в PRD (если применимо):**
- Поддерживаемые языки
- Формат дат и чисел для каждой локали
- Длина строк: учесть расширение текста при переводе (до +40% для немецкого)
- Отображение валюты

## Правила использования

- ЕСЛИ функциональность простая (внутренний инструмент, прототип) -> NFR можно опустить
- ЕСЛИ продукт для конечных пользователей -> минимум: производительность + совместимость
- ЕСЛИ обрабатываются персональные данные -> обязательно: безопасность
- ЕСЛИ публичный продукт -> рекомендовано: доступность (WCAG AA)
- НИКОГДА не копировать все NFR бездумно -- выбрать релевантные для конкретной задачи
