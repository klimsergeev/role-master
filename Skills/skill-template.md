## Самопроверка при подключении (ОБЯЗАТЕЛЬНО)

При загрузке скилла агент ДОЛЖЕН продемонстрировать, что он прочитал и понял содержимое. Это гарантирует, что скилл действительно применяется, а не просто упоминается.

**Выбери один из двух вариантов:**

### Вариант A: Активная проверка

Агент выполняет действие и показывает результат.

```
При подключении:
1. [Какое действие выполнить — например, прочитать директорию, найти файлы]
2. Вывести результат в формате:

   **[Название скилла] подключён**
   [Результат действия — например, список найденных файлов]
```

**Пример** (skill-agent-orchestration):
```
При подключении:
1. Прочитать директорию .claude/agents/
2. Вывести список агентов:

   **Оркестрация агентов подключена**
   Найдено агентов: 3
   - role-frontend-developer.md
   - role-ux-writer.md
   - role-research-analyst.md
```

### Вариант B: Статичная проверка

Агент выводит ключевые принципы или правила из скилла.

```
При подключении вывести:

**[Название скилла] подключён**
Ключевые принципы:
- [Принцип 1]
- [Принцип 2]
- [Принцип 3]
```

**Пример** (skill-editorial-guidelines):
```
При подключении вывести:

**Редполитика UX-текстов подключена**
Ключевые принципы:
- Говорим с пользователем на «вы»
- Избегаем канцелярита и штампов
- Пишем коротко: одна мысль — одно предложение
```
