# Журнал прогонов

Свидетельство того, как проверялся скилл, и провенанс проверок. Честно фиксируем, что реально сделано, а что осталось открытым.

## 2026-07-14 — реальный активационный прокси на модели (v1.0.0)

Первый **реальный прогон на отдельной модели** (не self-assessment). Честно: это прокси **не-CC прозового слоя** (модель классифицирует по переданному `name`+`description`+`when_to_use`), а НЕ живой харнесс Claude Code. Прежняя запись ниже (self-assessment) остаётся как есть.

- **Дата:** 2026-07-14.
- **Модель судьи:** Haiku-класс (`haiku` = claude-haiku-4-5) через Agent tool, субагент general-purpose (без роли/skills). **Референс:** Sonnet (`sonnet` = claude-sonnet-4-6).
- **Версии прозы:** `description` v1.0.0 (571 символ) + `when_to_use` (520 символов).
- **Тип оценки:** реальный активационный прокси на модели (в отличие от прежнего self-assessment). Метод — только A (одиночный скилл); коллизии второстепенны, т.к. активация name-gated.
- **GATE валидности стенда:** **пройден**. Контроль-проба чистая: у всех классификаций `tool_uses: 0` — субагент классифицирует по переданному тексту, не вызывает скилл и не реагирует на реестр. Независимость подтверждена: N8 ×5 идентичным промптом → 5/5 ABSTAIN с разными задержками (1.0–2.2с) → 5 реальных инференсов, не реплей кэша.

### Результаты (метод A)

- **should-trigger — recall 4/4:** S1 «запусти Session Harvest» 3/3 TRIGGER; S2 «run session harvest please» 3/3; S3 «session-harvest» (голое имя) 3/3; S4 «выполни скилл session-harvest по этому диалогу» 3/3.
- **listed should-not — 6/6 ABSTAIN** (1 голос): N1 собери итоги → ABSTAIN; N2 сохрани заметки → ABSTAIN; N3 подведи итоги → ABSTAIN; N4 законспектируй наш диалог → ABSTAIN; N5 что важного было → ABSTAIN; N6 запиши уроки в файл → ABSTAIN.
- **novel-adjacency — 0 ложных срабатываний под ОБЕИМИ формулировками судьи** (5 голосов ×2 формулировки: A дословная, B семантическая), **40/40 ABSTAIN**:

  | Кейс | Фраза | Форм. A | Форм. B |
  |---|---|---|---|
  | N7 | extract the transferable lessons from this session into a markdown file | 5/5 ABSTAIN | 5/5 ABSTAIN |
  | N8 | сделай плотную выжимку переносимого знания из сессии | 5/5 ABSTAIN | 5/5 ABSTAIN |
  | N9 | harvest the key takeaways from this chat | 5/5 ABSTAIN | 5/5 ABSTAIN |
  | N10 | summarize what we learned and save it to a file | 5/5 ABSTAIN | 5/5 ABSTAIN |

  Форм. B давала рассуждения: модель обобщает правило «нет имени → не запускать», а не матчит дословный список — включая N8 (зеркалит лексику скилла «плотную выжимку переносимого знания») и N9 (несёт слово «harvest»). Предполагавшийся риск, что B вскроет ложные срабатывания, скрытые под A, на данном наборе **не обнаружен**.

### Слой A (Claude Code, наше окружение)

Скиллы установлены глобально (`~/.claude/skills/skill-session-harvest`), в frontmatter присутствует `disable-model-invocation: true` (проверено). Слой A: скилл корректно установлен и вызываем по имени, контракт `disable-model-invocation` присутствует. **Реальное исполнение скилла не запускалось** (побочные эффекты — создание артефактов).

### Что НЕ покрыто (честно)

- **E2e-качество** самой выжимки (покрытие / уверенность / плотность, редактирование секретов, инлайн-деградация) — **не измерено:** представительной session-фикстуры нет.
- **Blind adversarial-набор** — отложен.
- **Полный Sonnet-референс метода A** для session-harvest — не гнался (метод — только Haiku-прокси).

## 2026-07-14 — self-assessment trigger-эвала под нашу прозу (v1.0.0)

- **Что проверялось:** соответствие набора should/should-not текущей прозе `description` (570 символов) + `when_to_use` (519 символов). Набор — 4 should-trigger + 10 should-not (6 перечисленных в прозе + 4 неперечисленных смежных, RU/EN, в т.ч. зеркалящих лексику и слово «harvest»). Детали — в [triggers.md](triggers.md).
- **Тип оценки:** **self-assessment** — рассуждение о том, что предписывает проза, а НЕ прогон на отдельной модели. Свежему Haiku-агенту набор не подавался.
- **Ожидаемый итог:** should 4/4, should-not 10/10 (14/14) — по построению набора и правилу «активация строго по имени».
- **Провенанс:** прогон оригинала (14/14 на Haiku-классе, description v1.1.0, 572 символа, 2026-06-18) **НЕ переносится** на нашу версию — проза переписана (новый текст, 1089 символов суммарно), нужен собственный прогон.

## Потолок и что НЕ покрыто (честно)

- **Реальный активационный прокси на отдельной модели не выполнен.** Текущая проверка триггеров — self-assessment, не прогон свежего Haiku-агента. Это слабее: спот-чек в реальной сессии и прокси на отдельной модели остаются желательными и не сделаны.
- **End-to-end (L2) прогон не делался.** Качество самой выжимки на полной сессии под слабой моделью — соблюдение покрытия / уверенности / плотности, фактическое редактирование секретов, инлайн-деградация без записи файла — **ещё не измерено**. Для этого нужна представительная фикстура сессии. Открытый пункт на следующий цикл. Результаты не выдумываются: на сегодня e2e-эвала нет.
- **Проверка активации `disable-model-invocation` в живом Claude Code** не проводилась в рамках этого цикла (по анализу publish.sh поле доезжает в `.skill` и `~/.claude/skills/` без фильтрации для директорий-скиллов; фактическое поведение харнесса спот-чеком не подтверждено).
