# Jira Formatting Notation

Синтаксис Jira Text Formatting Notation для описаний задач, комментариев и документации в Jira.

---

## Краткий справочник

| Элемент | Синтаксис | Результат |
|---------|-----------|-----------|
| Заголовок 1 | `h1. Текст` | Заголовок уровня 1 |
| Заголовок 2 | `h2. Текст` | Заголовок уровня 2 |
| Жирный | `*текст*` | **текст** |
| Курсив | `_текст_` | _текст_ |
| Зачёркнутый | `-текст-` | ~~текст~~ |
| Подчёркнутый | `+текст+` | подчёркнутый |
| Моноширинный | `{{текст}}` | `текст` |
| Цвет | `{color:red}текст{color}` | цветной текст |
| Маркированный список | `* пункт` | маркер |
| Нумерованный список | `# пункт` | 1. пункт |
| Ссылка | `[текст\|url]` | гиперссылка |
| Изображение | `!image.png!` | изображение |
| Цитата (строка) | `bq. текст` | цитата |
| Цитата (блок) | `{quote}текст{quote}` | блок цитаты |
| Код | `{code:java}...{code}` | блок кода |
| Упоминание | `[~username]` | @username |
| Ссылка на задачу | `PROJ-123` | автоссылка |

## Полный справочник синтаксиса

### Заголовки

```
h1. Заголовок уровня 1
h2. Заголовок уровня 2
h3. Заголовок уровня 3
h4. Заголовок уровня 4
h5. Заголовок уровня 5
h6. Заголовок уровня 6
```

### Форматирование текста

| Синтаксис | Описание |
|-----------|----------|
| `*жирный*` | Жирный текст |
| `_курсив_` | Курсивный текст |
| `-зачёркнутый-` | Зачёркнутый текст |
| `+подчёркнутый+` | Подчёркнутый текст |
| `{{моноширинный}}` | Моноширинный (inline code) |
| `^верхний индекс^` | Надстрочный текст |
| `~нижний индекс~` | Подстрочный текст |

**Комбинирование:**
```
*_жирный курсив_*
+*подчёркнутый жирный*+
```

### Цвет текста

```
{color:red}красный текст{color}
{color:blue}синий текст{color}
{color:#00FF00}зелёный (HEX){color}
```

Поддерживаемые имена цветов: red, blue, green, yellow, orange, purple, black, white, gray.

### Списки

**Маркированный список:**
```
* Первый пункт
* Второй пункт
** Вложенный пункт
** Ещё вложенный
* Третий пункт
```

**Нумерованный список:**
```
# Первый пункт
# Второй пункт
## Вложенный пункт
## Ещё вложенный
# Третий пункт
```

**Смешанный список:**
```
# Нумерованный
#* Маркированный внутри
#* Ещё один
# Продолжение нумерации
```

### Ссылки

```
[Текст ссылки|https://example.com]
[Текст ссылки|https://example.com|Подсказка при наведении]
[mailto:email@example.com]
```

**Якоря:**
```
{anchor:section1}
[Перейти к секции|#section1]
```

### Изображения

```
!image.png!
!image.png|width=300!
!image.png|width=300,height=200!
!image.png|thumbnail!
!https://example.com/image.png!
```

**Параметры изображений:**
- `width` — ширина в пикселях
- `height` — высота в пикселях
- `thumbnail` — миниатюра
- `align` — выравнивание (left, right, center)

### Таблицы

```
||Заголовок 1||Заголовок 2||Заголовок 3||
|Ячейка 1|Ячейка 2|Ячейка 3|
|Ячейка 4|Ячейка 5|Ячейка 6|
```

**Форматирование в таблицах:**
```
||*Жирный заголовок*||_Курсивный заголовок_||
|Обычная ячейка|{color:red}Цветная ячейка{color}|
```

### Цитаты

**Однострочная цитата:**
```
bq. Это цитата на одну строку.
```

**Многострочная цитата:**
```
{quote}
Это многострочная цитата.
Она может содержать несколько абзацев.
{quote}
```

### Блоки кода

**Блок кода с подсветкой синтаксиса:**
```
{code:java}
public class Hello {
    public static void main(String[] args) {
        System.out.println("Hello!");
    }
}
{code}
```

**Поддерживаемые языки:**
java, javascript, python, sql, xml, html, css, bash, ruby, php, go, swift, kotlin, typescript, json, yaml, и другие.

**Блок кода с заголовком:**
```
{code:title=Пример кода|language=python}
def hello():
    print("Hello!")
{code}
```

**Блок без форматирования:**
```
{noformat}
Текст без форматирования.
Сохраняет   пробелы   и
переносы строк.
{noformat}
```

### Панели

**Простая панель:**
```
{panel}
Содержимое панели.
{panel}
```

**Панель с параметрами:**
```
{panel:title=Заголовок панели|borderStyle=solid|borderColor=#ccc|titleBGColor=#f0f0f0|bgColor=#ffffff}
Содержимое панели с настройками.
{panel}
```

**Параметры панели:**
- `title` — заголовок
- `borderStyle` — стиль границы (solid, dashed)
- `borderColor` — цвет границы
- `titleBGColor` — фон заголовка
- `bgColor` — фон панели

### Специальные элементы Jira

**Упоминание пользователя:**
```
[~username]
[~accountid:5b10a2844c20165700ede21g]
```

**Автоссылки на задачи:**
```
PROJ-123
ABC-456
```
Jira автоматически преобразует в кликабельные ссылки.

**Статусы (Jira Server/Data Center):**
```
{status:colour=Green|title=Done}
{status:colour=Yellow|title=In Progress}
{status:colour=Red|title=Blocked}
{status:colour=Blue|title=New}
```

### Разделители и спецсимволы

**Горизонтальная линия:**
```
----
```

**Спецсимволы:**
| Синтаксис | Результат |
|-----------|-----------|
| `--` | короткое тире |
| `---` | длинное тире |
| `(c)` | копирайт |
| `(r)` | registered |
| `(tm)` | trademark |

**Экранирование:**
```
\*не жирный\*
\{не блок\}
\\обратный слеш
```

### Разрыв строки

```
Первая строка\\
Вторая строка (принудительный перенос)
```

---

## Правила

- ЕСЛИ нужен код в одну строку -> использовать `{{код}}`
- ЕСЛИ нужен многострочный код -> использовать `{code}...{code}`
- ЕСЛИ нужна цитата в одну строку -> использовать `bq. текст`
- ЕСЛИ нужна многострочная цитата -> использовать `{quote}...{quote}`
- ВСЕГДА закрывать парные теги ({code}, {quote}, {panel}, {color})
- ВСЕГДА использовать двойные вертикальные черты `||` для заголовков таблиц
- НИКОГДА не оставлять незакрытые фигурные скобки в блочных элементах

## Примеры

### Пример 1: Описание задачи

**Запрос:** Оформить описание багрепорта с шагами воспроизведения.

**Результат:**
```
h2. Описание проблемы

При нажатии на кнопку *«Сохранить»* возникает ошибка.

h3. Шаги воспроизведения

# Открыть страницу {{/settings}}
# Изменить любое поле
# Нажать кнопку *«Сохранить»*

h3. Ожидаемый результат

Данные сохраняются, появляется сообщение {color:green}«Успешно сохранено»{color}.

h3. Фактический результат

Появляется ошибка:
{code:none}
Error 500: Internal Server Error
{code}

h3. Окружение

||Браузер||Версия||
|Chrome|120.0.6099|
|Firefox|121.0|
```

### Пример 2: Комментарий с упоминанием и ссылкой

**Запрос:** Написать комментарий, упомянуть коллегу, сослаться на связанную задачу.

**Результат:**
```
[~ivanov], посмотри пожалуйста.

Связано с задачей PROJ-456.

{panel:title=Важно|borderColor=#ff0000|titleBGColor=#ffcccc}
Этот фикс влияет на API, нужно обновить документацию.
{panel}
```

### Пример 3: Документация API-метода

**Запрос:** Описание API-метода с параметрами и примером.

**Результат:**
```
h2. Метод: getUserById

Возвращает информацию о пользователе по ID.

h3. Параметры

||Параметр||Тип||Обязательный||Описание||
|id|integer|Да|ID пользователя|
|fields|string|Нет|Список полей через запятую|

h3. Пример запроса

{code:bash}
curl -X GET "https://api.example.com/users/123?fields=name,email" \
  -H "Authorization: Bearer token"
{code}

h3. Пример ответа

{code:json}
{
  "id": 123,
  "name": "Иван Иванов",
  "email": "ivan@example.com"
}
{code}
```
