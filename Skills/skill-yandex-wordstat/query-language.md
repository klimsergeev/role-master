# Язык поисковых запросов: операторы и стоп-слова

## Назначение

Операторы, которые допустимы в поле `phrase`, карта их поддержки по методам, правила обращения Яндекса со стоп-словами и ограничения на длину фразы.

## Поддержка операторов по методам

Дословно:

> Wordstat поддерживает все операторы в методах `GetRegionsDistribution` и `GetTop`. Метод `GetDynamics` поддерживает все операторы при детализации по дням, при детализации по неделям и месяцам — только оператор `+`.

Таблицей:

| Метод | Операторы |
|---|---|
| `GetTop` | все |
| `GetRegionsDistribution` | все |
| `GetDynamics`, `PERIOD_DAILY` | все |
| `GetDynamics`, `PERIOD_WEEKLY` / `PERIOD_MONTHLY` | **только `+`** |
| `GetRegionsTree` | не принимает фразу |

Фраза с операторами проходит валидацию без замечаний — символы `- ! + " [ ] ( ) |` в поле `phrase` допустимы (проверено живым вызовом 25.08.2026). Работают ли операторы фактически, без валидного ключа не наблюдаемо; документация утверждает, что работают, и называет Wordstat поимённо.

## Полная таблица операторов

| Оператор | Что делает | Пример | Когда покажем |
|---|---|---|---|
| `-` | Исключает слова из запроса | `доставка -цветы` | доставка еды, доставка на дом; не доставка цветов |
| `!` | Фиксирует форму слова (число, падеж, время) | `купить !собаку` | купить собаку; не купить корм для собак, не купить собак |
| `+` | Фиксирует стоп-слова | `работа +на дому` | работа на дому; не работа по дому, не работа дома |
| `" "` | Фиксирует количество слов | `"купить автомобиль"` | купить автомобиль, автомобиль купить; не купить красный автомобиль |
| `[]` | Фиксирует порядок слов, учитывая словоформы и стоп-слова | `билеты [из москвы в париж]` | билеты из москвы в париж, билеты на самолет из москвы в париж; не билеты из парижа в москву |
| `()` и `\|` | Группируют слова | `заказать (роллы\|пицца)` | заказать роллы, заказать пицца |

## Стоп-слова

Дословно: «При поиске Яндекс использует только значимые слова во введенной поисковой фразе, опуская стоп-слова — предлоги, союзы и местоимения, которые не меняют смысла ключевой фразы. Например, во фразе "как и когда путешествовать на Марс" учитываются только "путешествовать" и "Марс". Однако если стоп-слова меняют смысл фразы, например "это по дружбе", Яндекс автоматически зафиксирует их и включит в искомую фразу. […] **При этом в статистике такие показы учитываются как пословное соответствие, так как задействованы все слова из заданной фразы.**»

Последнее предложение — прямо про интерпретацию чисел, которые вернёт API.

**Минус-фразы:** «слова или словосочетания, при наличии которых в поисковом запросе пользователя результат не включается в выдачу. […] Если минус-фраза содержит стоп-слова, система автоматически фиксирует его.»

## Ограничения на длину фразы

- 400 символов — жёстко, отвергается валидацией с текстом `phrase: Length must be less than or equal to 400` (проверено 25.08.2026, [errors.md](errors.md)).
- Общесервисный лимит «максимальное количество слов в запросе — 40 слов» **на уровне валидации Wordstat не действует**: фраза из 41 слова, укладывающаяся в 400 символов, проходит проверку тела (проверено 25.08.2026). Срабатывает ли этот лимит дальше, под валидным ключом, не проверялось — на длинных фразах держись сорока слов, а результат сверяй, а не считай гарантированным.
