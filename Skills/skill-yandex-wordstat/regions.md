# Регионы: коды и дерево

## Назначение

Справочник идентификаторов регионов Яндекса, устройство дерева `GetRegionsTree`, ловушки при работе с ним и практика кэширования.

## Формат идентификаторов

Числовые по виду, но **передаются и возвращаются строками**: `"regions": ["213"]`, `RegionInfo.id` и `RegionInfo.region` объявлены как `string`. Число вместо строки отвергается: `regions[0]: invalid value 213 for type TYPE_STRING` (проверено 25.08.2026).

## Что представляет собой дерево регионов

Характеристики фактического ответа `GetRegionsTree` (посчитаны обходом опубликованной Яндексом кассеты SDK, пересчитано 25.08.2026):

- Узлов: **1103**
- Глубина: **6 уровней, считая корень.** Самая длинная ветка: Россия → Северо-Запад → Санкт-Петербург и Ленинградская область → Санкт-Петербург → Колпинский район → Колпино
- Корней верхнего уровня: **8**
- Повторяющихся `id`: **0**
- Размер тела ответа: **58 299 байт** компактного JSON в UTF-8 (около 105 КБ, если сервер экранирует кириллицу как `\uXXXX`)

Корни:

|---|---|---|
| 225 | Россия | 9 |
| 166 | СНГ (исключая Россию) | 11 |
| 111 | Европа | 32 |
| 183 | Азия | 27 |

| 10002 | Северная Америка | 8 |

**Дерево охватывает весь мир,** а не только Россию: справочник `GetRegionsDistribution` так и говорит — «globally by region».

## Ловушки при работе с деревом

- **Названия не уникальны, идентификаторы уникальны.** Неуникальных меток ровно пять, каждая на двух узлах: «Пушкинский район» (`98604` — Россия → Центр → Москва и область; `20297` — Россия → Северо-Запад → Санкт-Петербург и Ленинградская область → Санкт-Петербург), «Троицк», «Ленинский район», «Железногорск», «Алжир». Поиск по названию должен возвращать список, а не одно значение — так и сделано в SDK (`search_by_label` возвращает кортеж, [sdk.md](sdk.md)).
- **Идентификаторы `1` и `2` означают не то, что подсказывает интуиция.** `1` = «Москва и область» (уровень Центра), `2` = «Санкт-Петербург» (город), а «Санкт-Петербург и Ленинградская область» — это `10174`.
- **Поле названия называется `label`.**

## Практика

Дерево запрашивается бесплатно, но это 1103 узла и около 57 КБ. Кэшировать локально, обходить в глубину, строить словарь `id → label` один раз. Пример кода — в [python-reference.md](python-reference.md).

Расшифровка ответов `GetRegionsDistribution` без кэша означала бы обход дерева на каждую строку, а строк там сотни ([methods.md](methods.md)).
