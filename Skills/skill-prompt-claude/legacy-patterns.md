# Каталог устаревших приёмов

## Назначение

Справочник приёмов, которые официальная документация называет устаревшими, вредными или ненужными для текущих моделей Claude: по какому признаку их найти, на чём основан вывод и чем заменить. Используется при аудите, проверке готового промпта и переносе на другую версию модели.

## Как читать таблицу

- «Что искать» — примеры формулировок для поиска (`grep -n -i`, `rg -i`). Совпадение — повод прочитать место целиком, а не вывод: та же фраза может стоять внутри официального блока, вставленного дословно, или в цитате.
- «Модели» — для каких моделей источник это утверждает. Строка, относящаяся к одной модели, на другой переносится только с проверкой на тестах ([prompt-debugging.md](prompt-debugging.md)).
- «Замена» ссылается на блоки из [official-blocks.md](official-blocks.md) по их заголовкам.
- Источники: Best practices — https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/claude-prompting-best-practices; CC best practices — https://code.claude.com/docs/en/best-practices; гайды моделей — ссылки в [models.md](models.md). Сверено 2026-11-09.
